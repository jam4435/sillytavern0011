# NBA2K16 生涯模拟角色卡（v3）

仿 `角色卡/金庸群侠传` 的复合结构，但比赛采用更强的前端确定性模拟。玩法与系统设计见 [设计文档.md](./设计文档.md)，前端架构见 [`src/nba2k/架构.md`](../../src/nba2k/架构.md)。

## 目录

| 路径 | 内容 |
| ---- | ---- |
| `index.yaml` | 卡声明：首条消息、世界书挂载、正则矩阵、脚本库矩阵 |
| `世界书/` | 输出提示词、变量指导、cot、比赛规则、叙事风格、球队/球星资料、场外叙事规则与赛历参考 |
| `正则/游戏页面.txt` | loader：把楼层显示替换为 `dist/nba2k/index.html` 的 iframe |
| `脚本/` | 隐藏楼层.js、ERA变量框架-魔改.js |
| `头像.png` | 占位头像 |

## 核心玩法

- **单动作判定**：43项能力、体型、协防、战术、体力、徽章与热区进入 `resolveAction`。
- **完整 CPU 回合**：`PossessionEngine` 选择发起人、战术动作、配合与终结，并自动处理失误、罚球、篮板、助攻、时钟和球权。
- **三种比赛节奏**：全回合 / 精简比赛 / 关键时刻共用同一比赛引擎，只改变玩家介入频率。
- **赛季系统**：固定可重算的82场简化赛历、30队战绩、其他比赛低精度模拟、季后赛七场四胜与晋级。
- **场下系统**：交易、合同、代言履约、伤病恢复、球队关系与奖项采用各自的专用 Manager；只把满足条件的话题作为 StoryHook 交给 AI 演出。

## 使用步骤

1. 构建前端：`pnpm build:src:fast`。
2. 以仓库根目录启动静态服务监听 `localhost:5500`，确认 `http://localhost:5500/dist/nba2k/index.html` 可访问。
3. `node tavern_sync.mjs bundle nba2k` 打包角色卡，或 `node tavern_sync.mjs push nba2k` 推送到酒馆。
4. 酒馆中开启酒馆助手，新建聊天发送「【开始游戏】」。

## 注意

- loader 正则的 `run_on_edit` 应保持关闭。
- 深度世界书目前仍通过 `{{ERA:$ALLDATA}}` 注入完整 `stat_data`；后续可继续优化成按比赛/场外场景组装的紧凑上下文。
- 一次生成采用回合事务：先取得隐藏楼层锁，再以 `refresh:none` 持久化 user/assistant，等待 ERA 写入完成后释放锁并同步最终楼层。
- 玩家手动比赛动作由前端生成 `SettlementContract`；AI只提交合法 `NBASettlement`，非法时一次修复，仍非法则 fallback。
- CPU 模拟完全由前端执行；AI只把已经确定的一个或多个 possession 压缩成现场叙事，不能重掷或重算。
- 联盟赛程、战绩、季后赛、伤病恢复等属于前端只读状态，AI不得修改。
- 自建球员支持2K16/自由模拟两种模式、身高/体重/臂展、43项能力、10组非线性成长、24枚动态徽章与14区热区。
- `stat_data.版本` 保持3；新增的联盟字段允许为空，非法存档仍进入错误恢复页。
- 373名球员当前仍以19项估值种子确定性展开成43项；真实2K tendency/ratings 数据仍是后续校准方向。
