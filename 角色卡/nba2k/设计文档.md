# NBA2K16 生涯模拟角色卡 · v3设计

## 玩法定位

玩家在2015-16赛季只控制生涯主角。比赛世界由前端数值引擎持续运行，玩家只在自己的决策节点介入；AI负责现场解说、人物互动与场外叙事，不负责重新判定已经由前端确定的篮球结果。

## 球员模型

- 身体保存身高、体重、臂展。2K16模式按位置限制，自由模拟模式采用更宽体型边界。
- 能力包含23项进攻、7项防守、9项运动、3项心理和潜力，共43项；总评按位置权重派生。
- 自建使用100点分配10个能力组，创建等级4–14，新秀总评70–76、潜力88。
- 生涯能力组最高20级，采用非线性成长曲线；升级花费 `1+floor(level/4)`，潜力控制等级上限。
- 主角维护动态动作族倾向、24枚徽章与14区热区。
- CPU 球员在43项能力之上派生行为倾向（usage、持球、传球、篮下、中投、三分、背身、挡拆、定点、无球等）；倾向只控制决策概率，不改变能力值。

## 动作判定

动作面板按主角情境提供持球、无球、防守、篮板及替补席动作。突破与挡拆等动作拆为多个阶段，每阶段1d100，最终分大成功、成功、部分成功、失败、大失败。

计算输入包括动作能力、攻防稳定性、主防、附近协防、双方体型、队友空间、结构化战术、体力、徽章和热区。投篮使用篮下/油漆/中投/三分基准命中率，通过 logistic 模型叠加能力、防守与情境因素并限制在合理区间。

## PossessionEngine

完整 CPU possession 不由 AI 决定：

```text
当前进攻
→ usage / 战术 / 阵容决定发起人
→ 选择单打、挡拆、传导、背身等动作
→ 调用与玩家完全相同的 resolveAction
→ 若只创造优势则继续传导并寻找终结者
→ 最多1～3个动作阶段
→ 投篮 / 失误 / 犯规
→ 罚球 / 篮板
→ 更新比分、个人统计、助攻、时钟、体力与球权
```

因此“传球成功”不再等于回合停止；队友会真正完成后续出手。玩家在板凳时，对手和队友同样能够正常得分和产生技术统计。

## 比赛节奏

三种模式只改变中断策略，数值模拟完全一致：

| 模式 | 玩家介入 |
| ---- | -------- |
| 全回合 | 主角在场时保持高频、细粒度决策 |
| 精简比赛 | 主角作为发起人、配合人或主要防守者时介入，其余回合自动模拟 |
| 关键时刻 | 主要在末节胶着、主角直接参与、犯规危机、火热状态或里程碑时介入 |

模式可在比赛中切换。CPU 连续模拟若干回合后，只把确定的摘要交给 AI 一次性演出，从而避免一场比赛产生上百次模型请求。

## AI边界结算

玩家手动动作由前端产生 `SettlementContract`，锁定阶段骰子、结果等级、合法篮球分支及柔性范围。AI只提交叙事与 `NBASettlement` 提案。

提案在 assistant 楼层创建前校验；非法时只请求一次修复，仍非法则使用前端参考分支。CPU possession 则完全不需要模型提案，直接使用同一动作/结算内核。两者最终都必须满足比分、投篮、篮板、犯规、球权、时钟等不变量。

## SeasonEngine

赛季采用固定赛历而不是通用事件系统：

- 玩家球队有82场可重算的简化常规赛赛历，覆盖2015-10-27至2016-04-13。
- 玩家比赛用高精度比赛引擎；其余球队比赛只用球队实力、主场与随机波动低精度生成结果。
- 联盟保存30队胜负、得失分与连胜状态。
- 常规赛结束按东西部战绩取前8，首轮按 1–8 / 4–5 / 2–7 / 3–6 配对。
- 季后赛采用七场四胜与2-2-1-1-1主场顺序；主角球队比赛继续真实游玩，其他系列赛低精度模拟。
- 晋级、淘汰与总冠军全部由代码结果决定。

目前赛历是固定算法生成的“简化赛程”，目的在于先建立完整赛季闭环；未来可无缝替换成真实2015-16赛程表。

## 场下系统

不建立万能 EventEngine。固定日期由 SeasonEngine 负责，各机制只维护自己的小状态机：

- **交易**：交易窗口、球队需求、能力/潜力、球队战绩与角色形成交易关注度；AI只演流言和谈判。
- **合同**：能力、赛季表现、声望等生成市场报价锚点；玩家决定谈判与签约。
- **代言履约**：按比赛间隔检查近期表现，满足条件时生成奖金/续约/警告入口。
- **伤病恢复**：伤病记录含受伤日期、预计复出日期与恢复状态，由日期推进。
- **球队关系**：连败、低队友好感、低教练信任等只产生“矛盾苗头”，具体互动由AI展开。
- **奖项**：个人数据和球队战绩形成奖项参考分，AI不能自行投票决定结果。

这些系统最终只向 `联盟.故事钩子` 写入轻量叙事入口。StoryHook 表示“这个话题现在值得出现”，不是预先写好的剧情。

## 状态与恢复

`stat_data.版本=3`，顶层为比赛 / 生涯 / 场外 / 联盟。

- **比赛**：当前单场高精度状态。
- **生涯**：主角能力、成长、动态表现和赛季统计。
- **场外**：资金、声望、经纪人、代言、合同、关系和当前日程投影。
- **联盟**：日期、阶段、30队战绩、伤病、StoryHook和季后赛系列赛。

联盟、赛程与比赛确定性结果属于前端只读状态。AI场外回合不能自行推进日期或下一场比赛。

## 数据与分发

内置373名球员保留19项估值种子，通过确定性适配器展开为43项并补体型。CPU tendency 目前主要由能力与位置自动推导，只对少量明星进行风格校正；未来最值得补充的数据是更准确的真实2K ratings、usage、动作倾向、轮换时间和投篮分布。
