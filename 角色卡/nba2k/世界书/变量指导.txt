# ERA 变量操作规则（NBA2K16 生涯模拟）

## 一、核心原则

你需要在每次回应的结尾判断剧情是否引起了变量变化，并生成正确的 ERA 指令来更新 stat_data。

1. 无变化则不操作 —— 剧情没有引起变量变化时，禁止生成任何指令块。
2. 思考先于行动 —— 分析写在 `<VariableThink>` 中，指令块只包含纯净 JSON。
3. 判定不可篡改 —— 用户消息中 `<行动判定>` 的判定等级由前端骰子系统产生，是最终裁决；变量结算必须与该等级一致。
4. 前端派生只读区 —— `比赛.站位` 之外由前端直写的初始化数据不要求你重建，但你必须在攻防转换后更新站位。
5. 正文与变量一致 —— 叙事说进了三分，比分就必须 +3；说体力透支，体力值就必须下降。

## 二、三大指令

### `<VariableInsert>` —— 新增数据
新代言、新关系、新徽章、新的球员状态条目。路径指到父级容器：

<VariableInsert>
{
  "场外.代言": [{ "品牌": "斯伯丁", "年薪": 800000, "要求": "场均12分", "状态": "谈判中" }]
}
</VariableInsert>

### `<VariableEdit>` —— 修改数据
比分、时间、体力、好感、资金等已有字段：

<VariableEdit>
{
  "比赛.比分.主": 57,
  "比赛.剩余秒数": 415,
  "比赛.球权": "客",
  "比赛.球员状态.Stephen Curry.得分": 21,
  "比赛.球员状态.Stephen Curry.体力": 79,
  "比赛.回合摘要": "库里借挡拆命中三分"
}
</VariableEdit>

### `<VariableDelete>` —— 删除数据
到期代言、破裂关系、结束的待办。路径指到节点，值为 `{}`。

## 三、字段总表

### 比赛（stat_data.比赛）
- 进行中: boolean — 开赛由前端置 true；第4节/加时终场你必须置 false 并做赛后结算
- 对阵: { 主队, 客队 } — 球队ID（GSW/LAL…），前端写入
- 节次: 1-4，加时 5、6…
- 剩余秒数: 单节 720、加时 300；每回合扣 8-24
- 比分: { 主, 客 }
- 球权: '主' | '客'
- 战术: { 主, 客 } — 基础/跑轰/内线/挡拆/人盯人/联防/全场紧逼
- 站位.主 / 站位.客: 数组[5]，元素 { 球员: 英文名key, x: 0-100, y: 0-100, 持球?: true }
  - x 轴 0→100 为左端线→右端线；持球标记全场唯一；攻守转换后必须更新为合理落位
- 球员状态.<key>: { 体力0-100, 得分, 篮板, 助攻, 抢断, 盖帽, 失误, 犯规, 手感:'热'|'平'|'冷' }
  - 连续命中2球→'热'；连续打铁2球→'冷'；其余回'平'
- 回合摘要: 一句话，前端展示

### 生涯（stat_data.生涯）
- 姓名 / 球队 / 位置 / 赛季 / 附身球员
- 赛程索引: 第几场，赛后 +1
- 能力: 主角属性（overall 与细项 0-99），仅训练/升级事件可改，单次训练单项至多 +2
- 徽章: string[]，达成条件追加（单场30+分得「得分机器」等）
- 赛季统计: { 场均得分, 场均篮板, 场均助攻, 出场数 }，每场赛后重算
- 成长点: 每场按表现结算（每10分/5篮板/5助攻各+1），训练消耗

### 场外（stat_data.场外）
- 资金 / 声望0-100 / 粉丝
- 经纪人: { 姓名, 好感, 等级1-5 } 或 null
- 代言: [{ 品牌, 年薪, 要求, 状态:'谈判中'|'履约中'|'违约'|'到期' }]
- 合同: { 球队, 年限, 年薪, 到期赛季 }
- 关系: [{ 姓名, 身份, 好感0-100, 阶段:'相识'|'暧昧'|'恋爱'|'稳定'|'破裂', 事件线 }]
  - 阶段门槛：相识→暧昧 好感≥40；暧昧→恋爱 好感≥65 且触发告白事件；恋爱→稳定 好感≥85
  - 单次互动好感 -10 ~ +8，重大事件至多 ±12
- 队友好感: { <key>: 0-100 } — 影响场上化学反应
- 日程: { 日期 YYYY-MM-DD, 下一场 'vs XXX'|'@ XXX', 待办: string[] } — 场外每轮推进 1-3 天，不得跳过比赛日

## 四、结算清单

比赛回合每轮至少更新：剩余秒数、（比分或球权）、行动者体力、回合摘要。
赛后结算：比赛.进行中=false、赛程索引+1、赛季统计重算、成长点结算、资金入账、日程推进并写好下一场对阵、体力清场。
场外回合：日期推进、涉及的资金/好感/代言/待办同步更新。
