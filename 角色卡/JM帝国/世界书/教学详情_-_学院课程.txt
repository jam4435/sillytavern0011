# 教学档案: 学院课程
name: 学院课程
制定方: 帝国女性教育局
description: 学院的课程体系旨在将女性塑造为既有基本文化知识，又具备高超服务技巧的合格奴隶。
required_courses:
  1. 现代性奴概论: 扭曲历史，灌输奴性思想的综合政治课。
  2. 妆容: 教授各类化妆技巧，强调时尚感与实践能力。
  3. 纪律与服从: 贯穿所有年级的核心洗脑课程，要求对帝国绝对效忠。
  4. 性爱理论与实践: 教授系统性爱技巧，考试包括笔试和现场操作，鼓励开发个人特色。
  5. 世界学: 基础文化课，包括语文、数理化等地，确保学生具备基本认知，区别于文盲奴隶。
elective_courses:
  - 数量与要求: 提供60种选修课，如舞蹈、性柔术、足交术、兽交技巧、孕交课、刑讯课等。每人至少选修10门。
  - 重要性: 选修课成绩比必修课更受金主看重，是决定学生未来身价的关键。

# 设备档案: 学院课桌
name: 监禁学院特制课桌
type: 学习与调教结合型家具
description: 学院的课桌经过特殊设计，旨在将性刺激与学习过程相结合，强化学生的忍耐力。
key_features:
  - 配重板: 桌体内部装有可调节的配重板，以增加整体重量。
  - 悬空固定: 桌子底部的固定装置会将学生的双腿抬起并固定，使其身体悬空这样女生的身体与课桌会一起下沉。
  - 下体承重: 课桌的桌腿并不能支持课桌。在悬空固定后，课桌和身体的全部重量由一根插入该女生下体的特殊器械承担（机械阳具），这样重量下炮机的每一次抽插都可以扩开子宫口直达深处。这种持续的压迫和刺激感会在整个上课期间伴随着学生。

# 设备档案: 辅助学习器
name: 辅助学习器
type: 强制性脑部学习辅助设备
primary_function: 确保学生在承受性刺激或痛苦时仍能专注于课堂学习。
components:
  - 额头电极: 固定在额头，用于监测脑电波。
  - 大脑探针: 直接插入大脑前额叶，通过电刺激强化记忆。
  - 耳机: 播放放大后的教师讲课内容。
  - 声带静音器: 防止学生发出声音干扰课堂。
  - 定位笔: 固定学生头部位置。
working_principle: 通过大脑探针直接刺激前额叶，将学习内容的信息刺激强度放大到足以覆盖任何肉体快感或痛感的程度，从而实现强制性的专注。
usage_protocol: 每节课持续30分钟，课间必须休息，以避免眼球充血、流鼻血、呼吸困难等严重副作用。
