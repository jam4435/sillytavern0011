# 红楼梦卡 · 前端功能与 UI 设计规格 v1

> 2026-07-27 与用户确认。工程目录规划：`src/红楼梦/`（React SPA，伪同层 iframe 内运行），构建产物 `dist/红楼梦/index.html`（单 HTML 内联）。
> 架构基座沿用金庸卡：主读链 `getAllVariables() → readGameDataPure() → GameState`、回合锁 ACK（`wuxia:` 前缀不改）、`refresh:'none'` 建楼、loader guard、三层正文剥离。

## 一、已确认的设计决策

| 项 | 决策 |
|---|---|
| 视觉基调 | **工笔重彩**为默认主题：胭脂、石绿、青金浓丽配色 + 工笔花鸟/园林纹样装饰带；另做**太虚幻境夜题**（黛青底 + 银线），复用武侠卡已验证的多主题架构（UiTheme / localStorage / data-theme 管线） |
| 主布局 | **双栏常驻**：桌面端右侧常驻侧栏（同场人物 / 附近传闻 / 后续线索）；手机端侧栏退化为抽屉 |
| 适配 | **手机优先兼顾桌面**：竖屏为主设计，桌面居中限宽如书页 |
| v1 模块 | 必选底座（开局建角 / 正文+选项 / 存档树 / 设置）+ **判词册**、**情缘面板**、**舆图移动**；纪事/传闻独立面板延后（传闻/线索以侧栏轻量形式先行） |
| 舆图层级 | **两府（荣/宁）为主**——院落房舍级细节；**城市（京城/金陵/扬州/姑苏）次之**；**城外再次**（太虚幻境等特殊场景单列） |

## 二、页面流转

```
start（判断存档）
 ├─ 无档 → splash（题名页：书名、入梦引子）→ setup（建角）→ game
 └─ 有档 → game（直接续读）
```

**setup 建角（原创角色入府）**：姓名 → 性别 → 入府缘由（投亲身份模板：远房表亲/世交子弟/陪读侍读…，决定初始身份与住处）→ 才艺初选（从 诗词/琴/棋/书画/女红/管家/医药 挑 1-2 项给初始造诣）→ 确认开局。写初始变量走 `era:insertByObject` → 等 `era:writeDone` → 发全局初始化信号。

## 三、游戏主界面（game）

```
┌─────────────────────────────────────────┐
│ 顶栏：纪年时节（第一年·玖月初十·酉时）    │
│       地点面包屑（荣国府›贾母院›正房）    │
│       图标组：判词册/情缘/舆图/存档/设置  │
├──────────────────────────┬──────────────┤
│ 正文卷轴区                │ 侧栏（桌面常驻│
│ （楷体、朱砂段首标记、     │  手机抽屉）：  │
│   行距 2.0、可回看本回合） │  · 同场人物   │
├──────────────────────────┤  · 附近传闻   │
│ 选项笺条（壹/贰/叁 朱字序）│  · 后续线索   │
├──────────────────────────┤              │
│ 自拟输入框 + 「遣词」按钮  │              │
└──────────────────────────┴──────────────┘
```

- 正文区：LLM 正文经三层剥离后渲染；选项从 `<option>` 解析；流式输出期间显示逐字浮现。
- 同场人物卡（侧栏）：头像位（首字圆章代替头像）+ 姓名 + 关系词/亲密度微条；点开跳情缘面板对应人物。
- 传闻/线索条目：丫鬟婆子闲话口吻原样展示（数据来自 `附近传闻` / `后续事件线索`，只读）。

## 四、v1 功能面板

### 1. 判词册（命运改写线主视觉，覆层册页）
- 数据源：`stat_data.前端变量.命运册`（脚本维护只读：`{人物:{判词,状态,批语}}`）。
- 形态：仿太虚幻境薄命司册页——正册/副册/又副册三卷分页；每页：人物名、**竖排判词**、状态**印章**（原定=朱文方印 / 偏离=石绿印 / 未知=灰印虚框）、批语一行小字。
- 未揭示人物（尚未登场/未入命运册）显示为空白笺"尚未翻开"。
- 交互：翻卷切换、点人物跳情缘档案。

### 2. 情缘面板（情感养成线主面板）
- 数据源：`角色数据.*.关系网`（对玩家的条目）+ 档案字段（外貌/性情/才艺/身份/状态/人物经历）。
- 列表页：按亲密度排序的人物卡，红线进度条（0-100），关系词 + 补注。
- 详情页：人物档案全览 + 与玩家的经历时间线（`人物经历` 中含玩家的条目）；命运人物顶部露判词一角（点击跳判词册）。

### 3. 舆图移动
- 数据源与写入：读地点树（前端内置静态地图数据），选中后写 `前端变量.周围地点`（供 `<可用地点>` 白名单）并由玩家发送移动意图。
- 层级组织（按用户指定的优先级做细节密度）：
  - **两府**（最详）：荣国府/宁国府平面示意——院落为区块（贾母院、荣禧堂、凤姐院、梨香院、外院、会芳园…），点院落展开房舍；大观园建成（第17回后）通过事件解锁新区块。
  - **城市**（次之）：京城/金陵/扬州/姑苏，列表式坊巷+要地。
  - **城外**（最略）：行路目的地列表；太虚幻境仅剧情可达、不入常规舆图。
- 形态：非写实地图，**界画式平面装饰图**（线描院落框 + 泥金地名题签），手机上可横向平移。

### 4. 底座模块
- **存档树**：沿用金庸树形存档（checkpoint 绑定），变量名换 `honglou_save_tree`；节点 label = `地点 · 纪年时节`。
- **设置**：主题切换（工笔重彩/太虚幻境）、字号、动效开关、调试入口（`window.honglouRegexDebug`）。

## 五、视觉系统

### 主题一「工笔重彩」（默认，data-theme="gongbi"）
- 底色：绢地暖白 `#F6EFE0`；面板绢黄 `#FBF6E9`；边框金褐 `#C9B891`。
- 主色：胭脂 `#9E3B32`（交互强调/印章/序号）、石绿 `#3E7A5E`（偏离态/成功态）、青金 `#2F4B6E`（链接/次强调）、泥金 `#B08D3E`（装饰线/题签）。
- 墨色文字：正文 `#40382C`、次要 `#6D5C39`、提示 `#8A7A58`。
- 字体：正文/选项 楷体（KaiTi/STKaiti 栈 + 内嵌子集化字体做兜底待定）；UI 小字系统 sans；判词竖排（writing-mode: vertical-rl）。
- 装饰带：顶栏下沿与面板边角用**工笔纹样**（缠枝莲、海棠、卷草）；印章、题签、册页签条为氛围件。
- 节制原则：纹样只出现在边带与空态，不垫正文底下；正文区永远素绢底，保浓丽而不抢字。

### 主题二「太虚幻境」（夜题，data-theme="taixu"）
- 底色黛青 `#1C2430`、面板 `#232E3D`、银线 `#9FB0C3`、月白文字 `#E8ECF1`、胭脂改暗朱 `#C05A50`、泥金改冷银。
- 判词册在此主题下是"本相"：夜题即薄命司视觉，册页发微光银边。

### 素材策略（关键工程约束）
- 发布产物是单 HTML 内联 bundle（金庸卡 255KB 参照）。工笔纹样**优先手绘 SVG（线稿+平涂，可随主题换色）**，位图仅限极小点缀并压缩为 WebP base64。
- 本仓库 webpack `css-loader url:false`：本地图片必须 `?url` 显式导入内联（沿用武侠卡素材管线的经验）；类名全部加 `hl-` 前缀避免与宿主/酒馆全局样式冲突。
- 内嵌字体若做楷体子集化，只子集化 UI 固定用字（判词、题签、按钮），正文楷体依赖系统字体栈降级。

## 六、响应式规则

- 手机（<720px）：单栏；侧栏与三大面板均为全屏覆层抽屉；顶栏图标收进"锦囊"菜单保留判词册/舆图两个直达；选项笺条全宽。
- 桌面（≥720px）：主区限宽 680-760px 居中，右侧栏 280px 常驻；面板改为居中覆层册页（非全屏）。
- 高度自适应用 `--TH-viewport-height`（酒馆注入变量），禁 100vh 裸用。
