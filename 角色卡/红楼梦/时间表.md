# 红楼梦卡 · 架空纪年时间表

纪年约定（D4）：**黛玉进府之年 = 第1年**；此前为第0年、负数年。简化历法：一年12月、每月30日、时辰用 0-23 整数。事件条目 `触发条件/事件结束时间` 全部使用本表纪年。

年龄换算：`年龄 = 世界信息.时间.年 - 出生年份`（提示词层自动换算）。参考锚点：黛玉出生年份 **-5**（进府时约六岁）、宝玉 **-6**、宝钗 **-8**、王熙凤 **-13** 左右，其余人物按原著相对年龄推算。

开局前事件（年 ≤ 0）在初始化时会被事件脚本按"过期事件"直接归档进世界历史，作为前史背景。
