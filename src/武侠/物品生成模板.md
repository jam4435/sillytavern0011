# 武侠物品生成模板

这份模板用于让其他 AI 为 `src/武侠/data/出身选项.json` 生成开局物品。数值公式以 `修为境界功法属性战斗的体系架构.txt` 第十一章为准。

## 使用方式

把下面“生成提示词”整段交给 AI，替换输入区内容。要求 AI 同时返回“可写入 JSON”和“设计审计”，只把前者写进 `items`。

## 生成提示词

```text
你正在为一个综武 RPG 生成开局物品。请严格遵守以下数据结构和数值规则，不得发明未实现的属性字段。

【输入】
出身名称：{{例如：武当记名弟子}}
出身描述：{{粘贴出身描述}}
开局境界：{{例如：三流中期}}
希望生成的物品数量：{{2~4}}
希望突出：{{门派身份 / 生存能力 / 江湖趣味 / 剧情钩子}}
必须包含：{{可留空}}
禁止包含：{{可留空}}

【合法类型】
只使用：装备、丹药、秘籍、杂物。
不要使用“兵器”作为类型；兵器统一写成“类型: 装备，部位: 武器”。

【合法品阶】
普通物品：凡品、精品、珍品、极品、绝品、神品。
秘籍在包裹里不自行编造品阶；它的粗浅、传家、上乘、镇派、绝世、传说由功法数据库提供。

【合法数值字段】
属性修正只能使用：臂力、根骨、机敏、洞察、气血上限、内力上限。
禁止使用：悟性、风姿、福缘、百分比、暴击、吸血、穿透、减伤，以及其他未列出的字段。
禁止同时使用“气血”和“气血上限”，禁止同时使用“内力”和“内力上限”；统一只写上限字段。

【数值计算】
境界系数：
- 不入流 1
- 三流 10
- 二流 100
- 一流 1000
- 宗师 10000
- 绝顶 50000
- 陆地神仙 100000

小境界系数：初期 1.0，中期 1.2，后期 1.4，圆满 1.6。
资源保底：不入流 0，三流 0.6，二流 2.0，一流 4.0，宗师 8.0，绝顶 15.0，陆地神仙 25.0。

B = 10 × 大境界系数 × 小境界系数
H = B × (1 + 资源保底)

装备归一化预算：
Σ(正战斗属性修正 / B) + Σ(正资源属性修正 / H)

品阶基础预算上限：
- 凡品 3%
- 精品 5%
- 珍品 7%
- 极品 10%
- 绝品 13%
- 神品 16%

部位只允许：武器、护甲、鞋履、饰品。
武器和护甲预算倍率为 1.0，鞋履和饰品为 0.7。
多属性共享同一预算，不能每项都吃满。负数修正不返还正数预算。

持续增益丹药的强度倍率：1回合 2.0，2回合 1.6，3回合 1.3，4回合 1.1，5~6回合 0.9。
丹药预算上限 = 同品阶装备预算上限 × 强度倍率。
有数值增益的开局丹药默认数量为 1，避免当前同名药效叠加失衡。

【类型规则】
1. 装备必须填写部位和属性修正，不填写持续时间；使用状态固定为空字符串。
2. 持续增益丹药填写属性修正和持续时间，不填写部位与使用状态。
3. 疗伤、解毒、补给类丹药不伪造气血上限/内力上限修正；只通过物品描述表达用途，可不写属性修正和持续时间。
4. 秘籍名称必须与已有功法数据库名称完全一致。秘籍只写持有信息，不写属性修正、部位、持续时间或参悟条件。
5. 杂物不写属性修正、部位、使用状态或持续时间。
6. 当前包裹以物品名为 key，不得生成同名不同词条物品。

【表现力规则】
- 凡品：寻常材料、实用、有磨损，不使用神异描述。
- 精品：工艺可靠，有一个明确优点或当地来历。
- 珍品：稀有材料、名匠或门派印记，有可辨识特征。
- 极品：大派珍藏，带独特异象、限制或使用门槛。
- 绝品：天下有名，有历史事件和江湖声望，但不是无条件万能。
- 神品：举世唯一，有重大因果和剧情后果，必须写清约束。

描述必须具体包含至少三项：材质或药材、感官细节、制作/流传痕迹、实际用途、限制或代价。不要只写“十分珍贵”“威力无穷”。

【出身组合规则】
生成 2~4 种物品：通常包含 1 件身份标志物或装备、1 种补给/工具、0~1 件剧情钩子物。普通出身以凡品和精品为主；珍品必须有明确来历或代价；极品以上默认不得作为常规开局物品。趣味差异来自用途、限制与来历，不靠单纯提高数值。

【输出一：可写入 JSON】
只输出 `items` 对象内部可直接使用的严格 JSON，不要注释，不要 Markdown。字段按类型选择，不能把审计字段写入 JSON。

装备格式：
"物品名": {
  "类型": "装备",
  "品阶": "精品",
  "物品描述": "具体描述",
  "数量": 1,
  "部位": "武器",
  "属性修正": { "洞察": 4 },
  "使用状态": ""
}

持续增益丹药格式：
"物品名": {
  "类型": "丹药",
  "品阶": "凡品",
  "物品描述": "具体描述",
  "数量": 1,
  "属性修正": { "内力上限": 6 },
  "持续时间": 2
}

叙事性丹药格式：
"物品名": {
  "类型": "丹药",
  "品阶": "凡品",
  "物品描述": "说明疗伤、解毒或补给用途，但不承诺固定回复数值",
  "数量": 2
}

秘籍格式：
"已有功法数据库中的功法名": {
  "类型": "秘籍",
  "品阶": "凡品",
  "物品描述": "仅描述载体形态；功法真实描述与品阶由数据库覆盖",
  "数量": 1
}

杂物格式：
"物品名": {
  "类型": "杂物",
  "品阶": "凡品",
  "物品描述": "具体用途、来历或剧情价值",
  "数量": 1
}

【输出二：设计审计】
在 JSON 后单独列出，不得混入 JSON：
- 每件数值物品的目标境界、B、H、预算上限和实际预算。
- 每件物品如何体现出身，而不是换皮通用物品。
- 秘籍名称是否已确认存在于功法数据库；无法确认时不要生成秘籍。
- 自检：字段合法、部位合法、无别名重复、无同名不同词条、无超预算。
```

## 三流中期开局速算

三流中期：`B = 120`，`H = 192`。

| 品阶 | 武器/护甲预算 | 鞋履/饰品预算 |
| ---- | ------------- | ------------- |
| 凡品 | 3% | 2.1% |
| 精品 | 5% | 3.5% |
| 珍品 | 7% | 4.9% |
| 极品 | 10% | 7% |
| 绝品 | 13% | 9.1% |
| 神品 | 16% | 11.2% |

例：精品武器只加一个战斗属性时约为 `+6`；精品护甲只加气血上限时约为 `+10`；精品鞋履只加机敏时约为 `+4`。实际生成时取整数，并保留物品风格，不必机械吃满预算。
