# 武侠物品与出身生成模板

这份模板用于让其他 AI 生成 `src/武侠/data/出身选项.json` 可用的出身物品，或直接生成完整出身选项。

当前模板以新物品方案为准：变量类型使用 `药品`，不再使用 `丹药` 作为物品大类；`属性修正` 和 `持续时间` 都写纯数字。前端负责把百分比换算成实际属性变化。

## 一、出身选项结构

完整出身选项是 JSON 数组中的一个对象：

```json
{
  "id": "wudang_outer",
  "name": "武当记名弟子",
  "icon": "☯️",
  "description": "武当山记名弟子，虽非入室传人，却也习得武当入门剑法与基础内功。心性沉稳，颇有道家风范。",
  "category": "江湖门派",
  "realm": "三流中期",
  "martial_arts": [
    {
      "name": "金雁功",
      "mastery": "初窥门径"
    }
  ],
  "items": {
    "青锋剑": {
      "类型": "装备",
      "品阶": "精品",
      "物品描述": "剑身薄直，护手留有武当外门的阴阳鱼錾纹，适合以轻灵剑路试探门户。",
      "数量": 1,
      "部位": "武器",
      "属性修正": {
        "机敏": 7,
        "洞察": 3
      },
      "使用状态": ""
    }
  }
}
```

必填字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 英文小写、数字、下划线，不能重复 |
| `name` | 展示给玩家的出身名称 |
| `icon` | 一个直观 emoji |
| `description` | 2~3 句背景描述，说明身份、能力来源和江湖钩子 |
| `category` | 只能是 `江湖门派 / 世家豪门 / 平民百姓 / 特殊身份 / 自定义` |
| `realm` | 初始境界 |

可选字段：

| 字段 | 说明 |
| --- | --- |
| `items` | 出身自带物品，key 是物品名 |
| `martial_arts` | 出身自带功法，功法名必须存在于功法数据库 |

推荐初始境界：

| 出身强度 | 推荐境界 |
| --- | --- |
| 平民、书生、商贾、渔家、孤儿 | `不入流` 或 `三流初期` |
| 门派外门、小门派、猎户、铁匠、卖艺人 | `三流初期` 或 `三流中期` |
| 镖师、世家子弟、退伍老兵、还俗僧人 | `三流中期` 或 `三流圆满` |
| 退隐侍卫、金盆洗手刺客、邪教叛逃者 | `三流圆满` 或 `二流初期` |
| 明确曾是高手但受限的特殊出身 | 最高到 `二流中期`，必须写清限制或代价 |

## 二、物品类型

只使用四种物品大类：

| 类型 | 用途 | 额外字段 |
| --- | --- | --- |
| `装备` | 穿戴后提供属性修正，不扣数量 | `部位`、`属性修正`、`使用状态` |
| `药品` | 使用后回复、临时增幅、永久增幅或触发特殊剧情效果 | `功效类型`，部分需要 `属性修正` 或 `持续时间` |
| `秘籍` | 持有某门功法的载体 | 不写数值字段 |
| `杂物` | 信物、材料、财货、工具、残页、地图、任务物品 | 不写数值字段 |

兵器也写成：

```json
"类型": "装备",
"部位": "武器"
```

叙事里可以称“丹药、药散、药酒、膏药、灵果、解药”，但变量里的大类统一写：

```json
"类型": "药品"
```

## 三、属性修正规则

`属性修正` 中的数字是百分比点：

```json
"属性修正": {
  "臂力": 10,
  "洞察": 5
}
```

含义是 `臂力 +10%`、`洞察 +5%`。不要写成 `"10%"`，不要写成 `0.1`，不要写成 `"百分之十"`。

允许的属性键只有：

```text
臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力
```

不要写：

```text
气血上限 / 内力上限 / 悟性 / 风姿 / 福缘 / 暴击 / 吸血 / 穿透 / 减伤
```

`气血`、`内力` 的解释由前端按物品行为决定：

| 场景 | `气血: 30` 的含义 |
| --- | --- |
| 回复药品 | 回复当前气血，上限的 30% |
| 临时增幅药品 | 临时提高气血根基或上限 30% |
| 永久增幅药品 | 永久提高气血根基或上限 30% |
| 装备 | 装备生效期间提高气血根基或上限 30% |

多属性共享总预算。例如精品装备可以写 `臂力: 7, 洞察: 3`，不要写两项各 `10`。负数修正允许出现，但不返还正向预算。

## 四、装备生成规则

装备字段：

```json
{
  "类型": "装备",
  "品阶": "精品",
  "物品描述": "具体描述材质、来历、用途或限制。",
  "数量": 1,
  "部位": "武器",
  "属性修正": {
    "机敏": 7,
    "洞察": 3
  },
  "使用状态": ""
}
```

装备部位只允许：

```text
武器 / 护甲 / 鞋履 / 饰品
```

装备数值表：

| 品阶 | 推荐总增幅 | 正向总上限 | 参照境界 |
| --- | ---: | ---: | --- |
| 凡品 | 3~5 | 5 | 不入流圆满 |
| 精品 | 6~10 | 10 | 三流圆满 |
| 珍品 | 11~18 | 18 | 二流圆满 |
| 极品 | 19~30 | 30 | 一流圆满 |
| 绝品 | 31~45 | 45 | 宗师圆满 |
| 神品 | 46~70 | 70 | 绝顶圆满 |

开局装备建议：

| 出身 | 常用装备品阶 |
| --- | --- |
| 平民、孤儿、渔家、农家 | 凡品 |
| 外门弟子、猎户、铁匠、镖师 | 凡品或精品 |
| 世家、将门、医药世家 | 精品，可少量珍品 |
| 特殊身份 | 精品或珍品；极品以上必须有强代价 |

## 五、药品生成规则

药品必须写 `功效类型`：

```text
回复 / 临时增幅 / 永久增幅 / 特殊
```

### 回复药品

用于当前气血或内力恢复。需要 `属性修正`，不写 `持续时间`。

```json
"金疮药": {
  "类型": "药品",
  "品阶": "精品",
  "功效类型": "回复",
  "物品描述": "外敷内服皆可的伤药，能止血生肌，对刀剑创口最有效。",
  "数量": 2,
  "属性修正": {
    "气血": 35
  }
}
```

回复药品数值表：

| 品阶 | 单项回复推荐 | 双项回复推荐 | 正向总上限 |
| --- | ---: | ---: | ---: |
| 凡品 | 10~20 | 10 / 10 | 20 |
| 精品 | 25~40 | 20 / 20 | 40 |
| 珍品 | 50~70 | 35 / 35 | 70 |
| 极品 | 80~100 | 50 / 50 | 100 |
| 绝品 | 100 | 75 / 75 | 150 |
| 神品 | 100 | 100 / 100 | 200 |

### 临时增幅药品

用于短时间爆发。需要 `属性修正` 和 `持续时间`，持续时间单位是“时”。

```json
"轻身丸": {
  "类型": "药品",
  "品阶": "精品",
  "功效类型": "临时增幅",
  "物品描述": "薄荷与鹤涎草炼成的小丸，入口清凉，短时间内使脚步更轻。",
  "数量": 1,
  "属性修正": {
    "机敏": 15
  },
  "持续时间": 2
}
```

临时增幅药品数值表：

| 品阶 | 推荐总增幅 | 正向总上限 | 推荐持续时间 |
| --- | ---: | ---: | ---: |
| 凡品 | 5~10 | 10 | 1 |
| 精品 | 10~18 | 18 | 2 |
| 珍品 | 18~30 | 30 | 2~3 |
| 极品 | 30~50 | 50 | 3 |
| 绝品 | 50~75 | 75 | 4 |
| 神品 | 75~110 | 110 | 5 |

### 永久增幅药品

用于洗髓、易筋、固本、扩充气海等根基变化。不生成凡品和精品版本。

| 品阶 | 单项永久增幅建议 | 多属性总预算建议 | 正向总上限 |
| --- | ---: | ---: | ---: |
| 珍品 | 8~12 | 12~18 | 18 |
| 极品 | 15~25 | 25~35 | 35 |
| 绝品 | 30~45 | 45~65 | 65 |
| 神品 | 50~80 | 80~120 | 120 |

普通开局不要发永久增幅药品。若特殊出身持有，必须写清无法轻易服用、牵涉因果、药力危险或剧情代价。

### 特殊药品

用于解毒、醒神、龟息、易容、假死、避瘴、镇痛、压制寒毒等效果。不写 `属性修正`，不写 `持续时间`。

```json
"解毒丹": {
  "类型": "药品",
  "品阶": "精品",
  "功效类型": "特殊",
  "物品描述": "可化解寻常毒伤，对奇毒只能暂时压制；若毒已入脏腑，仍需以内力逼毒或另寻名医。",
  "数量": 1
}
```

## 六、秘籍与杂物

秘籍：

```json
"金雁功抄本": {
  "类型": "秘籍",
  "品阶": "上乘",
  "物品描述": "记有金雁功入门到进阶要诀的抄本，纸页边角有武当弟子反复翻阅的油痕。",
  "数量": 1
}
```

秘籍规则：

- 秘籍名称或绑定功法名必须能对应功法数据库。
- 秘籍品阶使用 `粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说`。
- 不写 `属性修正`、`部位`、`使用状态`、`持续时间` 或参悟条件。
- 残页、拓片、线索如果不能直接学习，应写成 `杂物`，不要写成秘籍。

杂物：

```json
"丐帮竹符": {
  "类型": "杂物",
  "品阶": "珍品",
  "物品描述": "一枚刻有丐帮暗记的旧竹符，可在部分丐帮弟子面前证明来历，但若遇长老盘问仍需说清取得经过。",
  "数量": 1
}
```

杂物不参与属性结算。品阶体现稀有度、身份效力、交易价值和剧情通行能力。

## 七、品阶表现力

| 品阶 | 表现力 |
| --- | --- |
| 凡品 | 寻常材料、实用、有磨损，不使用神异描述 |
| 精品 | 工艺可靠，有一个明确优点或当地来历 |
| 珍品 | 稀有材料、名匠、药师或门派印记，有可辨识特征 |
| 极品 | 大派珍藏，带独特风格、限制、代价或使用门槛 |
| 绝品 | 天下有名，有历史事件和江湖声望，但不是无条件万能 |
| 神品 | 举世唯一，有重大因果和剧情后果，必须写清约束 |

普通出身以凡品和精品为主。珍品必须有明确来历、代价或数量限制。极品以上默认不作为常规开局物品。

## 八、单个出身物品生成提示词

```text
请根据给定出身生成 2~4 种综武 RPG 开局物品，并返回可直接放入 `items` 字段的严格 JSON 对象。

【输入】
出身名称：{{出身名称}}
出身描述：{{出身描述}}
出身类别：{{江湖门派 / 世家豪门 / 平民百姓 / 特殊身份}}
初始境界：{{不入流 / 三流初期 / 三流中期 / 三流圆满 / 二流初期 ...}}
希望突出：{{门派身份 / 生存能力 / 江湖趣味 / 剧情钩子}}
必须包含：{{可留空}}
禁止包含：{{可留空}}
可用功法名：{{如果要生成秘籍，列出允许使用的功法数据库名称；没有就写“无”}}

【输出格式】
只输出严格 JSON 对象，不要 Markdown，不要注释，不要解释。
对象的 key 是物品名，value 是物品数据。

【合法类型】
只使用：装备、药品、秘籍、杂物。
不要使用“丹药”作为类型；丹药只是叙事称呼，变量类型必须写“药品”。

【基础字段】
每个物品都必须有：
- 类型
- 品阶
- 物品描述
- 数量

【装备字段】
装备必须额外有：
- 部位：只能是 武器 / 护甲 / 鞋履 / 饰品
- 属性修正：只能用 臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力
- 使用状态：固定写空字符串 ""

装备数值：
- 凡品：总增幅 3~5，最高 5
- 精品：总增幅 6~10，最高 10
- 珍品：总增幅 11~18，最高 18
- 极品：总增幅 19~30，最高 30
- 绝品：总增幅 31~45，最高 45
- 神品：总增幅 46~70，最高 70

【药品字段】
药品必须有：
- 功效类型：回复 / 临时增幅 / 永久增幅 / 特殊

回复药品：写属性修正，不写持续时间。
临时增幅药品：写属性修正和持续时间，持续时间单位为“时”，只写数字。
永久增幅药品：只允许珍品以上，普通开局不要生成；写属性修正，不写持续时间。
特殊药品：不写属性修正，不写持续时间，只在物品描述里说明功效。

【属性修正】
属性修正数字是百分比点。10 表示 +10%，禁止写 0.1、"10%"、"百分之十"。
允许属性：臂力、根骨、机敏、洞察、气血、内力。
禁止属性：气血上限、内力上限、悟性、风姿、福缘、暴击、吸血、穿透、减伤。

【秘籍】
秘籍名称必须与可用功法名完全一致，或物品名清楚包含可用功法名。
秘籍品阶使用：粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说。
秘籍不写属性修正、部位、使用状态、持续时间或参悟条件。

【杂物】
杂物不写属性修正、部位、使用状态、持续时间。
杂物要有剧情用途，例如身份凭证、线索、地图、药方、残页、工具、材料。

【平衡】
普通出身以凡品和精品为主。
珍品必须有明确来历、代价或数量限制。
极品以上不要作为常规开局物品，除非输入明确要求，并写清后患。

【描述要求】
物品描述要具体体现材质、药材、感官细节、流传痕迹、实际用途、限制或代价。
不要只写“十分珍贵”“威力无穷”“效果很好”。
```

## 九、完整出身选项生成提示词

```text
请为综武 RPG 角色卡生成一组完整出身选项，输出可直接替换或追加到 `src/武侠/data/出身选项.json` 的严格 JSON 数组。

【目标】
生成 {{数量}} 个有趣、差异明显、适合开局选择的出身。
每个出身都要包含身份背景、初始境界、可选功法和 2~4 个开局物品。
出身要有江湖趣味和剧情钩子，不要只是“某门派弟子 + 普通药”。

【已有出身 id，禁止重复】
{{粘贴已有 id 列表}}

【可用功法数据库名称】
{{粘贴允许使用的功法名列表；没有就写“无”。只有列表里的功法才能写入 martial_arts 或秘籍。}}

【允许类别】
只能使用：
- 江湖门派
- 世家豪门
- 平民百姓
- 特殊身份

不要生成 `自定义`。

【单个出身 JSON 结构】
每个出身必须是：
{
  "id": "英文小写_下划线_唯一id",
  "name": "中文出身名",
  "icon": "一个emoji",
  "description": "2~3句背景描述，写出身份来源、能力来源、限制或剧情钩子。",
  "category": "江湖门派 / 世家豪门 / 平民百姓 / 特殊身份",
  "realm": "初始境界",
  "martial_arts": [
    { "name": "功法名", "mastery": "掌握程度" }
  ],
  "items": {
    "物品名": { ...物品数据... }
  }
}

`martial_arts` 没有就省略，不要输出空数组。
`items` 必须有 2~4 个物品。

【初始境界】
平民、书生、商贾、渔家、孤儿：不入流或三流初期。
门派外门、小门派、猎户、铁匠、卖艺人：三流初期或三流中期。
镖师、世家子弟、将门、退伍老兵、还俗僧人：三流中期或三流圆满。
退隐侍卫、刺客、邪教叛逃者：三流圆满或二流初期。
曾是高手但受限的特殊出身最高到二流中期，必须写清失忆、旧伤、追杀、封禁、心魔、身份暴露等限制。

【掌握程度】
开局功法掌握程度只允许：
- 初窥门径
- 略有小成
- 融会贯通

普通出身默认初窥门径。
二流或特殊身份可以略有小成。
融会贯通必须有明确经历代价，不要滥用。

【物品类型】
只使用：装备、药品、秘籍、杂物。
不要使用“丹药”作为类型。

所有物品必须有：
- 类型
- 品阶
- 物品描述
- 数量

装备额外有：
- 部位：武器 / 护甲 / 鞋履 / 饰品
- 属性修正
- 使用状态：固定写 ""

药品额外有：
- 功效类型：回复 / 临时增幅 / 永久增幅 / 特殊

只有临时增幅药品写持续时间，单位为“时”，只写数字。
回复、永久增幅、特殊都不写持续时间。

【属性修正】
属性修正数字是百分比点。10 表示 +10%。
只能用：臂力、根骨、机敏、洞察、气血、内力。
禁止用：气血上限、内力上限、悟性、风姿、福缘、暴击、吸血、穿透、减伤。

【数值上限】
装备：
- 凡品：总增幅 3~5，最高 5
- 精品：总增幅 6~10，最高 10
- 珍品：总增幅 11~18，最高 18
- 极品：总增幅 19~30，最高 30
- 绝品：总增幅 31~45，最高 45
- 神品：总增幅 46~70，最高 70

回复药品：
- 凡品：单项回复 10~20，最高 20
- 精品：单项回复 25~40，最高 40
- 珍品：单项回复 50~70，最高 70

临时增幅药品：
- 凡品：总增幅 5~10，持续 1
- 精品：总增幅 10~18，持续 2
- 珍品：总增幅 18~30，持续 2~3

永久增幅药品：
- 普通开局不要生成。
- 如特殊要求必须生成，只能珍品以上，并写清不能轻易服用或有严重代价。

【秘籍】
秘籍必须对应可用功法数据库名称。
秘籍品阶使用：粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说。
秘籍不写属性修正、部位、使用状态、持续时间或参悟条件。
如果只是残页、线索、拓片，写成杂物。

【表现力要求】
每个出身至少有一个明确剧情钩子，例如：
- 师门考核
- 身份隐患
- 债务或追杀
- 家传旧案
- 失物线索
- 门派规矩
- 与某类 NPC 的天然关系

每个出身的物品要服务它的身份，不要所有出身都给同样的金疮药。
描述要具体，有材质、药材、地名、门派痕迹、使用限制、代价或流传痕迹。

【输出要求】
只输出严格 JSON 数组。
不要 Markdown。
不要注释。
不要解释。
不要在 JSON 末尾添加多余逗号。
不要输出 `$template`、`cultivation`、`初始属性`、`天赋` 等未要求字段。
```

## 十、校验清单

交给其他 AI 生成后，先按这个清单检查：

| 检查项 | 要求 |
