# 武侠物品生成模板

这份模板用于让其他 AI 为 `src/武侠/data/出身选项.json` 生成开局物品。AI 只填写百分比，前端负责计算装备、药效生效后的最终属性。

## 百分比规则

`属性修正` 中的数字就是百分比点：

```json
"属性修正": {
  "臂力": 10,
  "洞察": 5
}
```

表示 `臂力 +10%`、`洞察 +5%`。它不是固定增加 10 点，也不写成小数 `0.1`。

装备的推荐总增幅和硬上限：

| 品阶 | 推荐总增幅 | 正向增幅总上限 |
| ---- | ---------- | -------------- |
| 凡品 | 3%~5% | 5% |
| 精品 | 6%~10% | 10% |
| 珍品 | 11%~18% | 18% |
| 极品 | 19%~30% | 30% |
| 绝品 | 31%~45% | 45% |
| 神品 | 46%~70% | 70% |

持续增益丹药的推荐总增幅、硬上限和持续时间：

| 品阶 | 推荐总增幅 | 正向增幅总上限 | 推荐持续时间 |
| ---- | ---------- | -------------- | ------------ |
| 凡品 | 3%~8% | 8% | 1回合 |
| 精品 | 8%~15% | 15% | 2回合 |
| 珍品 | 15%~25% | 25% | 2~3回合 |
| 极品 | 25%~40% | 40% | 3回合 |
| 绝品 | 40%~60% | 60% | 3~4回合 |
| 神品 | 60%~90% | 90% | 4~5回合 |

多属性共享总上限。例如精品装备可以写 `臂力 +7%、洞察 +3%`，不能写成两项各 `+10%`。负数修正不返还正向额度。

## 可直接使用的提示词

```text
请根据给定出身生成 2~4 种综武 RPG 开局物品，并返回可直接放入出身 JSON 的严格 JSON。

【输入】
出身名称：{{出身名称}}
出身描述：{{出身描述}}
希望突出：{{门派身份 / 生存能力 / 江湖趣味 / 剧情钩子}}
必须包含：{{可留空}}
禁止包含：{{可留空}}

【合法类型】
只使用：装备、丹药、秘籍、杂物。
兵器统一写成“类型: 装备，部位: 武器”。

【合法属性】
属性修正只能使用：臂力、根骨、机敏、洞察、气血上限、内力上限。
数字表示百分比点，例如 10 表示 +10%，禁止写成 0.1。
禁止使用：悟性、风姿、福缘、暴击、吸血、穿透、减伤及其他未实现字段。

【装备上限】
- 凡品：总增幅 3%~5%，最高 5%
- 精品：总增幅 6%~10%，最高 10%
- 珍品：总增幅 11%~18%，最高 18%
- 极品：总增幅 19%~30%，最高 30%
- 绝品：总增幅 31%~45%，最高 45%
- 神品：总增幅 46%~70%，最高 70%

多属性共享总上限。精品装备可以写“臂力 7、洞察 3”，不能让每项都达到 10。负数修正不返还正向额度。
装备部位只允许：武器、护甲、鞋履、饰品。

【持续增益丹药上限】
- 凡品：总增幅 3%~8%，最高 8%，持续 1 回合
- 精品：总增幅 8%~15%，最高 15%，持续 2 回合
- 珍品：总增幅 15%~25%，最高 25%，持续 2~3 回合
- 极品：总增幅 25%~40%，最高 40%，持续 3 回合
- 绝品：总增幅 40%~60%，最高 60%，持续 3~4 回合
- 神品：总增幅 60%~90%，最高 90%，持续 4~5 回合

有数值增益的开局丹药默认数量为 1。疗伤、解毒、补给类丹药不填写属性修正和持续时间，只在描述中写用途。

【其他类型】
秘籍名称必须与已有功法数据库名称完全一致，不写属性修正、部位、持续时间或参悟条件。
杂物不写属性修正、部位、使用状态或持续时间。
包裹以物品名为 key，不生成同名不同词条物品。

【表现力】
- 凡品：寻常材料、实用、有磨损，不使用神异描述。
- 精品：工艺可靠，有一个明确优点或当地来历。
- 珍品：稀有材料、名匠或门派印记，有可辨识特征。
- 极品：大派珍藏，带独特异象、限制或使用门槛。
- 绝品：天下有名，有历史事件和江湖声望，但不是无条件万能。
- 神品：举世唯一，有重大因果和剧情后果，必须写清约束。

普通出身以凡品和精品为主；珍品必须有明确来历或代价；极品以上默认不作为常规开局物品。描述应具体体现材质或药材、感官细节、流传痕迹、实际用途、限制或代价，不能只写“十分珍贵”“威力无穷”。

【输出】
只输出 `items` 对象内部可直接使用的严格 JSON，不要注释、Markdown、计算过程或额外字段。
```

## JSON 示例

装备：

```json
"青锋剑": {
  "类型": "装备",
  "品阶": "精品",
  "物品描述": "剑身薄直，护手留有武当外门的阴阳鱼錾纹，适合以轻灵剑路试探门户。",
  "数量": 1,
  "部位": "武器",
  "属性修正": {
    "机敏": 7,
    "洞察": 3
  },
  "使用状态": ""
}
```

持续增益丹药：

```json
"轻身丸": {
  "类型": "丹药",
  "品阶": "精品",
  "物品描述": "薄荷与鹤涎草炼成的小丸，入口清凉，短时间内使脚步更轻。",
  "数量": 1,
  "属性修正": {
    "机敏": 15
  },
  "持续时间": 2
}
```

前端会把这些变量显示为 `机敏 +7%、洞察 +3%` 和 `机敏 +15%`，并根据玩家当前基础属性计算装备后或服药后的实际变化。
