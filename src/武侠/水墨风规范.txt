# 武侠水墨风前端设计规范 v2.0
> 面向纯文本 LLM（如 GLM）的完整风格描述文档  
> v2.0 新增真实水墨素材库支持（wuxia-sprites），原纯 CSS 模拟方案降级为备用

---

## 〇、v2.0 变更说明

v1.0 的面板边框、按钮、圆形框架全部用 CSS 渐变 + 伪元素「模拟」水墨效果。
v2.0 引入了真实 AI 生成的水墨素材库，核心变化如下：

| 组件 | v1.0 做法 | v2.0 做法 |
|------|-----------|-----------|
| 面板边框 | CSS 伪元素模拟四角线框 | `border-image` 九宫格加载真实水墨纹理图 |
| 按钮 | CSS `border-radius` + 渐变背景 | 直接使用切好的三态水墨按钮图（outline/dark/light）|
| 圆形框架 | CSS `border-radius` + `box-shadow` | 使用水墨笔触圆框图（ink/line 两种风格）|
| 图标底座 | 纯 CSS 圆形/方形 | 使用七档深浅的水墨底座图（circle/square 各7个）|
| 标题条 | CSS 渐变横条 | 使用真实墨刷晕染图 |
| 对话气泡 | 不支持 | 新增气泡框（bubble-l / bubble-r）|

**原则：有真实素材的组件，优先用素材；素材库未覆盖的部分（文字、颜色、间距、动画）继续用 CSS。**

## 一、整体视觉基调

这是一种「中国古典水墨画」与「武侠游戏 UI」融合的风格。  
核心感受：苍茫、古朴、飘逸、肃穆，有一种「大漠孤烟直」的孤独美感。

整个界面看起来像是**一幅铺开的宣纸**，背景是水墨晕染的山水画，
UI 组件漂浮在画面之上——面板是毛笔勾勒的卷轴框，按钮是墨色晕染的胶囊，圆框是笔触苍劲的圆圈。

## 六、面板和容器【v2.0 重写】

### ✅ 主推：border-image 九宫格（使用真实素材）

四角水墨纹理不变形，中间随内容自由拉伸，是水墨边框的正确用法。

```html
<!-- 矩形内容面板 -->
<div class="wuxia panel-rect panel-rect-lg" style="padding: 24px; min-height: 120px;">
  面板内容
</div>

<!-- 导航/标题横条 -->
<div class="wuxia panel-rect panel-bar-lg" style="padding: 10px 24px;">
  标题文字
</div>

<!-- 对话气泡 -->
<div class="wuxia panel-bubble-r" style="width: 200px;">
  NPC 说话内容
</div>
```

可用的面板类：
```
panel-bar-lg / panel-bar-md / panel-bar-sm   → 宽横条（适合标题栏、导航）
panel-rect-md / panel-rect-lg / panel-rect-xl → 矩形面板（适合对话框、任务列表）
panel-card-l / panel-card-r                   → 竖向卡片（适合角色卡、物品卡）
panel-square-sm / panel-square-md             → 小方块（适合技能格、道具格）
panel-bubble-r / panel-bubble-l               → 对话气泡（右/左气泡尾）
```

**border-image slice 参考值（调整四角切割精度用）：**
```css
/* 横条面板：角纹理约占边高的 1/4 */
border-image-slice: 20 20 20 20 fill;
/* 矩形面板：角纹理略大 */
border-image-slice: 28 28 28 28 fill;
/* 小方块面板：角纹理占比更大 */
border-image-slice: 35 35 35 35 fill;
```

## 七、按钮【v2.0 重写】

### ✅ 主推：使用素材库按钮

素材库提供三种色态 × 四种尺寸的胶囊按钮，以及宽条按钮和标签形按钮：

```html
<!-- 胶囊按钮：outline（空心）/ dark（墨色）/ light（浅色） -->
<button class="wuxia btn-wuxia btn-dark btn-md">确认</button>
<button class="wuxia btn-wuxia btn-outline btn-md">取消</button>
<button class="wuxia btn-wuxia btn-light btn-md" disabled>禁用</button>

<!-- 四种尺寸 -->
<button class="wuxia btn-wuxia btn-dark btn-lg">大号</button>  <!-- 148×54 -->
<button class="wuxia btn-wuxia btn-dark btn-md">中号</button>  <!-- 128×48 -->
<button class="wuxia btn-wuxia btn-dark btn-sm">小号</button>  <!-- 110×44 -->
<button class="wuxia btn-wuxia btn-dark btn-xs">迷你</button>  <!-- 96×40  -->

<!-- 宽条按钮（确认/取消类大按钮）-->
<button class="wuxia btn-wide btn-wide-dark">开始游戏</button>
<button class="wuxia btn-wide btn-wide-outline">返回主界面</button>

<!-- 标签形按钮（带切角装饰）-->
<button class="wuxia btn-tag btn-tag-dark">出战</button>
<button class="wuxia btn-tag btn-tag-outline">查看</button>
```

**三态对应语义：**
```
btn-outline → 次要操作（取消、返回、查看）  深色文字 #1A1410
btn-dark    → 主要操作（确认、出战、前往）  浅色文字 #E8E2D6
btn-light   → 禁用/弱化状态               灰色文字 #7A6E62
```

**hover/active 交互（wuxia-ui.css 已内置）：**
```css
.btn-wuxia:hover  { filter: brightness(1.06); }
.btn-wuxia:active { transform: scale(0.97); filter: brightness(0.94); }
```

### ⚠️ 备用：纯 CSS 小按钮（列表内「前往」类行内按钮）

素材库按钮尺寸最小到 96px，比这还小的行内按钮用 CSS：

```css
.btn-inline {
  background: transparent;
  border: 1px solid rgba(90, 70, 50, 0.5);
  color: #3D3028;
  padding: 3px 10px;
  font-size: 13px;
  letter-spacing: 2px;
  border-radius: 1px;
  cursor: pointer;
  font-family: inherit;
  transition: background 0.2s;
}
.btn-inline:hover { background: rgba(139, 96, 64, 0.1); }
```

## 九、图标底座【v2.0 新增】

素材库提供圆形和方形两种形状，各有 7 档墨色深浅（从最深的 ink 到最浅的 white）。  
深浅档用于表示**激活/普通/禁用**三种状态，或用于**功能重要性**的视觉区分。

```html
<!-- 圆形底座 + 叠加图标 -->
<div class="wuxia icon-base icon-circle-dark">
  <img src="sword.svg" width="24" height="24" alt="武器">
</div>

<!-- 方形底座 + 叠加图标 -->
<div class="wuxia icon-base icon-square-mid">
  <img src="potion.svg" width="22" height="22" alt="药水">
</div>
```

七档深浅对应语义建议：
```
ink      → 当前激活 / 最高优先级
dark     → 主要功能
mid      → 普通功能
light    → 次要功能
lighter  → 低优先级
outline  → 空态 / 未解锁
white    → 禁用 / 空格占位
```

## 二十一、给 LLM 的快捷描述模板（v2.0 更新）

```
使用中国武侠水墨风格，配合 wuxia-sprites 素材库。

【面板】用 border-image 九宫格加载 panel/ 目录下的水墨边框图，
        slice 值约 20-30，fill 保留中间内容区。
        可选类型：panel-bar（横条）、panel-rect（矩形）、
        panel-card（竖卡）、panel-square（方块）、panel-bubble（气泡）。

【按钮】使用 .btn-wuxia 配合 btn-dark/btn-outline/btn-light 和 btn-lg/md/sm/xs。
        主操作用 dark（浅色文字 #E8E2D6），
        次操作用 outline（深色文字 #1A1410），
        禁用用 light（灰色文字 #7A6E62）。
        极小行内按钮用纯 CSS：border 1px solid rgba(90,70,50,0.5)，border-radius: 1px。

【圆框】circle-frame-ink（笔触感）或 circle-frame-line（细线+角装饰），
        内嵌 <img> 自动居中显示。

【图标底座】icon-circle-* 或 icon-square-*，七档深浅（ink/dark/mid/light/lighter/outline/white），
           深色表激活，浅色表普通/禁用。
```
