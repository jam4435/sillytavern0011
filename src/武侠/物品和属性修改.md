# 物品和属性修改设计稿

本文记录本轮讨论后的目标方案。它优先服务三件事：

1. 让 AI 生成物品时少计算、少写错。
2. 让前端负责装备、药品、状态效果和属性变化的实际结算。
3. 让世界书能用稳定的世界观语言解释物品、药品和秘籍，不把数值计算压给 AI。

当前方案已落入前端代码。后续出身物品模板、架构文档和世界书条目应以本文为准同步。

## 一、核心结论

### 1. 字段单位

`属性修正` 使用纯数字，单位固定为“百分比点”。

```json
"属性修正": {
  "臂力": 20,
  "洞察": -5
}
```

含义是 `臂力 +20%`、`洞察 -5%`。不要写成 `"20%"`，不要写成 `0.2`，也不要写成 `"百分之二十"`。

`持续时间` 也使用纯数字，单位固定为“时”。只有 `功效类型: 临时增幅` 的药品需要这个字段。

```json
"持续时间": 3
```

含义是持续 `3 时`。

### 2. 物品大类

物品大类统一使用四种：

| 类型 | 作用 | 是否直接改属性 | 是否消耗数量 |
| --- | --- | --- | --- |
| 装备 | 穿戴后提供属性修正 | 是 | 否 |
| 药品 | 使用后产生回复、临时增幅、永久增幅或特殊叙事效果 | 视功效类型决定 | 是 |
| 秘籍 | 持有某门功法的载体 | 否，功法效果读功法数据库 | 否 |
| 杂物 | 材料、信物、财货、任务道具和日用品 | 否 | 视剧情决定 |

`丹药` 不再作为变量大类。江湖叙事里仍可说丹药、药散、药酒、膏药、灵果，但变量字段统一写 `类型: 药品`。

### 3. 品阶

普通物品品阶：

```text
凡品 -> 精品 -> 珍品 -> 极品 -> 绝品 -> 神品
```

秘籍显示使用功法品阶：

```text
粗浅 -> 传家 -> 上乘 -> 镇派 -> 绝世 -> 传说
```

秘籍必须和功法数据库绑定。秘籍的描述、功法品阶、参悟条件和功法特性以功法数据库为准，不在包裹里另造一套。

## 二、包裹变量结构

包裹以物品名为 key。基础字段统一是：

```json
{
  "类型": "装备 | 药品 | 秘籍 | 杂物",
  "品阶": "普通物品写凡品/精品/珍品/极品/绝品/神品；秘籍写粗浅/传家/上乘/镇派/绝世/传说",
  "物品描述": "文字描述",
  "数量": 1
}
```

装备额外字段：

```json
{
  "部位": "武器 | 护甲 | 鞋履 | 饰品",
  "属性修正": {
    "臂力": 10
  },
  "使用状态": ""
}
```

药品额外字段：

```json
{
  "功效类型": "回复 | 临时增幅 | 永久增幅 | 特殊",
  "属性修正": {
    "气血": 30
  }
}
```

只有临时增幅药品额外写：

```json
{
  "持续时间": 2
}
```

秘籍不写 `属性修正`、`部位`、`持续时间` 或参悟条件。杂物也不写数值字段。

## 三、属性修正语义

AI 生成物品时只使用这些属性键：

```text
臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力
```

不要让 AI 写 `气血上限`、`内力上限`。前端根据物品行为解释：

| 场景 | `气血: 30` 的含义 |
| --- | --- |
| 回复药品 | 立即回复当前气血，上限的 30% |
| 临时增幅药品 | 临时提高气血上限或气血根基 30% |
| 永久增幅药品 | 永久提高气血上限或气血根基 30% |
| 装备 | 装备生效期间提高气血上限或气血根基 30% |

`内力` 同理。前端内部可以把装备、临时增幅、永久增幅里的 `气血 / 内力` 映射到上限或根基计算；AI 不需要理解这些程序字段。

## 四、装备规则

装备只负责穿戴加成，不负责消耗。装备后数量不减少。

装备部位固定为：

```text
武器 / 护甲 / 鞋履 / 饰品
```

不要临时创造 `左戒`、`右戒`、`腰坠`、`披风` 等额外槽位。它们如果要出现，统一归入 `饰品` 或写成杂物。

装备生效真值是 `user数据.装备栏`，不是包裹里的 `使用状态`。

```json
"装备栏": {
  "武器": "青锋剑",
  "护甲": "乌金软甲"
}
```

`使用状态` 只用于行囊显示和同步。

装备指令队列文本应列出前端已经结算的实际变化：

```text
装备青锋剑，（机敏增加8，洞察增加3）
```

取消装备指令时，需要恢复装备前的装备栏和使用状态。

## 五、药品规则

药品分为四种 `功效类型`：

| 功效类型 | 是否前端直接改变量 | 是否需要属性修正 | 是否需要持续时间 |
| --- | --- | --- | --- |
| 回复 | 是，恢复当前气血或内力 | 是 | 否 |
| 临时增幅 | 是，写入状态效果 | 是 | 是 |
| 永久增幅 | 是，写入 `前端变量.永久属性修正` | 是 | 否 |
| 特殊 | 否，交给 AI 在剧情中体现 | 否 | 否 |

### 1. 回复

回复型药品用于当前气血、当前内力恢复。

```json
"金疮药": {
  "类型": "药品",
  "品阶": "精品",
  "功效类型": "回复",
  "物品描述": "外敷内服皆可的伤药，能止血生肌，对刀剑创口最有效。",
  "数量": 2,
  "属性修正": {
    "气血": 35
  }
}
```

使用后前端直接恢复当前变量，并在指令队列中写明实际变化：

```text
使用金疮药，（气血已恢复28，当前气血42 -> 70）
```

### 2. 临时增幅

临时增幅型药品用于短时间爆发。

```json
"暴血丹": {
  "类型": "药品",
  "品阶": "珍品",
  "功效类型": "临时增幅",
  "物品描述": "以虎骨、赤参和烈酒炼成，服后气血上涌，短时间内出手更狠。",
  "数量": 1,
  "属性修正": {
    "臂力": 30
  },
  "持续时间": 2
}
```

使用后前端扣减数量，创建 `状态效果`，并把实际变化写入指令队列：

```text
使用暴血丹，（臂力临时增加18，持续2时）
```

### 3. 永久增幅

永久增幅型药品用于洗髓、易筋、固本、扩充气海等根基变化。它不建议存在低品阶版本。

凡品和精品不要生成永久增幅药品。珍品以上才允许出现。

```json
"大还丹": {
  "类型": "药品",
  "品阶": "神品",
  "功效类型": "永久增幅",
  "物品描述": "少林秘传奇药，能洗髓固本，扩充气海，但药力猛烈，非重伤垂危或根基深厚者难以承受。",
  "数量": 1,
  "属性修正": {
    "气血": 50,
    "内力": 70
  }
}
```

使用后前端写入 `stat_data.前端变量.永久属性修正`，并在指令队列中说明已经发生的变化：

```json
"前端变量": {
  "永久属性修正": {
    "大还丹_1234567890_abcd": {
      "类型": "药品",
      "功效类型": "永久增幅",
      "来源": "大还丹",
      "品阶": "神品",
      "属性修正": {
        "气血": 50,
        "内力": 70
      }
    }
  }
}
```

`前端变量` 是前端专用区。AI 仍禁止写入 `前端变量`；其中 `永久属性修正` 只由前端药品按钮维护。

```text
使用大还丹，（气血永久增加480，内力永久增加670）
```

不使用 `同名唯一` 这类限制字段。平衡依靠品阶、数量、剧情稀有度和数值封顶。

### 4. 特殊

特殊型药品用于解毒、醒神、易容、龟息、假死、避瘴、镇痛、压制寒毒等不能稳定抽象成数值的效果。

特殊药品不额外加 `解除效果`、`状态类型`、`解除强度` 等字段，直接由物品描述说明。

```json
"解毒丹": {
  "类型": "药品",
  "品阶": "精品",
  "功效类型": "特殊",
  "物品描述": "可化解寻常毒伤，对奇毒只能暂时压制；若毒已入脏腑，仍需以内力逼毒或另寻名医。",
  "数量": 1
}
```

使用后前端只扣数量，并把描述交给指令队列：

```text
使用解毒丹，（“可化解寻常毒伤，对奇毒只能暂时压制；若毒已入脏腑，仍需以内力逼毒或另寻名医。”，请在剧情中体现）
```

AI 看到这类指令后，只负责让药效在剧情中自然体现，不自行修改已由前端负责的数值变量。

## 六、指令队列与撤销

装备和使用物品都要进入指令队列，保证玩家行为能被 AI 感知。

装备：

```text
装备青锋剑（机敏增加8，洞察增加3）
```

回复药品：

```text
使用金疮药（气血已恢复28，当前气血42 -> 70）
```

临时增幅药品：

```text
使用暴血丹（臂力临时增加18，持续2时）
```

永久增幅药品：

```text
使用大还丹（气血永久增加480，内力永久增加670）
```

特殊药品：

```text
使用解毒丹（“物品描述”，请在剧情中体现）
```

药品使用后数量减一。数量为 0 时从包裹移除。取消待发送指令时必须恢复完整物品快照，不能只恢复数量。

撤销需要恢复：

| 行为 | 撤销内容 |
| --- | --- |
| 装备 | 装备栏、旧装备使用状态、新装备使用状态 |
| 回复药品 | 药品完整快照、当前气血或内力 |
| 临时增幅药品 | 药品完整快照、新建状态效果、属性重算结果 |
| 永久增幅药品 | 药品完整快照、永久修正来源、属性重算结果 |
| 特殊药品 | 药品完整快照 |

## 七、百分比与封顶规则

物品变量中保存的是百分比，但实际增加多少点由前端计算。

计算原则：

```text
理论增幅 = 使用者基础属性 × 属性修正 / 100
品阶封顶 = 物品品阶对应的参照境界基准属性 × 该品阶封顶比例 / 100
实际增幅 = min(理论增幅, 品阶封顶)
最终属性 = 基础属性 + 实际增幅
```

也就是说，百分比先看使用者自己的基础属性，保证角色差异有效；再受物品品阶封顶，保证低阶物品不会随着高境界玩家无限变强。

例：

```text
角色基础臂力 = 120
精品刀：臂力 +20
精品参照境界 = 三流圆满
三流圆满基准臂力 = 160
精品封顶比例 = 10

理论增幅 = 120 × 20% = 24
品阶封顶 = 160 × 10% = 16
实际增幅 = 16
最终臂力 = 136
```

如果角色基础臂力只有 50：

```text
理论增幅 = 50 × 20% = 10
品阶封顶 = 16
实际增幅 = 10
最终臂力 = 60
```

同属性多个来源建议逐个物品、逐个药效独立计算封顶后再相加。这样凡品装备不会被神品药效带着突破自身上限。

气血/内力上限变化时，当前值按“同增同减”处理：

```text
新当前值 = clamp(旧当前值 + 新上限 - 旧上限, 0, 新上限)
```

也就是保留当前损失值。回复型药品单独修改当前气血/内力，不参与上限同增同减。

## 八、秘籍规则

秘籍和功法直接挂钩。

包裹中的秘籍只表示“玩家持有这个功法载体”，不负责计算功法效果。

```json
"金雁功抄本": {
  "类型": "秘籍",
  "品阶": "上乘",
  "物品描述": "记有金雁功入门到进阶要诀的抄本，纸页边角有武当弟子反复翻阅的油痕。",
  "数量": 1
}
```

注意：

1. 秘籍名称或绑定功法名必须能对应功法数据库。
2. 功法描述、功法品阶、修炼限制、战斗系数和特性全部读取功法数据库。
3. 秘籍不写 `属性修正`。
4. 秘籍品阶使用功法品阶文案，不使用凡品、精品这套普通物品文案。
5. 如果只是残页、拓片、线索而不能直接学习，应写成 `杂物`，不要写成秘籍。

秘籍品阶表现：

| 功法品阶 | 表现力 |
| --- | --- |
| 粗浅 | 市井拳脚、军中散手、入门口诀，易学但上限低 |
| 传家 | 家传或小门派核心本事，有完整路数和可辨识传承 |
| 上乘 | 名门正支、江湖好手赖以成名的武学，有明确修炼门槛 |
| 镇派 | 大派根本武功或核心绝技，常有门规、心性或内力要求 |
| 绝世 | 天下闻名，足以引发争夺，得之会改变江湖势力判断 |
| 传说 | 时代级武学，常伴随重大因果，不应作为普通开局奖励 |

## 九、杂物规则

杂物不参与属性结算。

杂物可以是：

```text
信物 / 财货 / 材料 / 药材 / 工具 / 残页 / 地图 / 书信 / 令牌 / 任务物品
```

杂物的品阶表达稀有度、身份效力和剧情价值，不表达战斗加成。

例：

```json
"丐帮竹符": {
  "类型": "杂物",
  "品阶": "珍品",
  "物品描述": "一枚刻有丐帮暗记的旧竹符，可在部分丐帮弟子面前证明来历，但若遇长老盘问仍需说清取得经过。",
  "数量": 1
}
```

## 十、可放入世界书的世界信息 XML

下面这段可作为 `世界信息` 中关于物品和秘籍的条目。外层只保留一个 XML 标签，内部用中文 YAML，避免多层 XML 占 token。

```xml
<世界信息>
物品与秘籍体系:
  总则:
    - 物品分为装备、药品、秘籍、杂物。
    - 装备和可结算药品由前端处理属性变化；剧情应承认指令队列里已经写明的结果，不重新计算。
    - 特殊药品、信物、残页、机关、毒物和奇物主要按物品描述在剧情中体现。

  普通物品品阶:
    凡品: 市井或外门常用品，实用、有磨损；例：柴刀、粗布护腕、寻常金疮药。
    精品: 工艺可靠，有明确优点或来历；例：青锋剑、精制金疮药、熟铜护心镜。
    珍品: 一地闻名或少量流通，常有名匠、门派、药师或特殊材料痕迹；例：乌金软甲、暴血丹、丐帮竹符。
    极品: 大派珍藏或江湖难求，有限制、代价或使用门槛；例：寒玉护符、少林秘药、名剑山庄旧藏。
    绝品: 天下有名、屈指可数，会改变旁人反应，但不是无条件万能；例：软猬甲、名动江湖的宝刀。
    神品: 举世唯一或时代级遗物，必有重大因果和后患；例：大还丹、千年朱果、倚天屠龙级神兵。

  类型:
    装备:
      - 兵刃、防具、鞋履和饰品；装备后生效，数量不减少。
      - 部位只认武器、护甲、鞋履、饰品。
      - 高阶装备要写材质、来历、限制或江湖声望，不只写锋利坚固。
    药品:
      - 变量大类统一写药品，叙事里可称丹药、药散、药酒、膏药、灵果或解药。
      - 回复：恢复当前气血或内力，由前端结算。
      - 临时增幅：短时提高属性或气血内力根基，由前端写入状态效果，持续时间单位为时。
      - 永久增幅：永久改善根基、气海、筋骨或内力容量；不建议有凡品和精品版本。
      - 特殊：解毒、醒神、龟息、易容、假死、避瘴等不数值化，按物品描述入剧情。
    秘籍:
      - 秘籍是功法载体，不是装备，也不直接加属性。
      - 秘籍必须对应功法数据库；功法描述、功法品阶、参悟条件、战斗系数和特性以数据库为准。
      - 秘籍品阶使用粗浅、传家、上乘、镇派、绝世、传说。
    杂物:
      - 信物、材料、财货、书信、地图、残页、工具和任务物品。
      - 杂物不直接加属性；品阶体现稀有度、身份效力、交易价值和剧情通行能力。

  数值提示:
    - 属性修正中的数字是百分比点；20 表示增加百分之二十，不写百分号，不写小数。
    - 只有临时增幅药品需要持续时间，单位为时。
    - 实际增幅先按使用者基础属性百分比计算，再受物品品阶对应参照境界的基准值封顶。
    - 参照境界：凡品不入流圆满，精品三流圆满，珍品二流圆满，极品一流圆满，绝品宗师圆满，神品绝顶圆满。
</世界信息>
```

## 十一、数值附录

### 1. 参照境界

| 普通品阶 | 参照境界 | 说明 |
| --- | --- | --- |
| 凡品 | 不入流圆满 | 市井、外门、军中常用品 |
| 精品 | 三流圆满 | 入门江湖人可稳定使用的良品 |
| 珍品 | 二流圆满 | 一地有名，适合成熟江湖好手 |
| 极品 | 一流圆满 | 大派珍藏或名匠精品 |
| 绝品 | 宗师圆满 | 天下有名，足以改变旁人判断 |
| 神品 | 绝顶圆满 | 举世唯一或时代级遗物 |

陆地神仙境不作为常规物品封顶参照。陆地神仙级影响应来自功法、境界、剧情奇遇或特殊规则，而不是普通包裹物品。

### 2. 装备数值

| 品阶 | 推荐总增幅 | 正向总上限 | 参照境界 |
| --- | ---: | ---: | --- |
| 凡品 | 3~5 | 5 | 不入流圆满 |
| 精品 | 6~10 | 10 | 三流圆满 |
| 珍品 | 11~18 | 18 | 二流圆满 |
| 极品 | 19~30 | 30 | 一流圆满 |
| 绝品 | 31~45 | 45 | 宗师圆满 |
| 神品 | 46~70 | 70 | 绝顶圆满 |

多属性共享总上限。例如精品装备可以写 `臂力: 7, 洞察: 3`，不能写两项各 `10`。

### 3. 回复药品数值

| 品阶 | 单项回复推荐 | 双项回复推荐 | 正向总上限 | 参照境界 |
| --- | ---: | ---: | ---: | --- |
| 凡品 | 10~20 | 10 / 10 | 20 | 不入流圆满 |
| 精品 | 25~40 | 20 / 20 | 40 | 三流圆满 |
| 珍品 | 50~70 | 35 / 35 | 70 | 二流圆满 |
| 极品 | 80~100 | 50 / 50 | 100 | 一流圆满 |
| 绝品 | 100 | 75 / 75 | 150 | 宗师圆满 |
| 神品 | 100 | 100 / 100 | 200 | 绝顶圆满 |

回复不能超过当前缺口。低阶回复药也受参照境界封顶，避免凡品金疮药在高境界阶段恢复过量。

### 4. 临时增幅药品数值

| 品阶 | 推荐总增幅 | 正向总上限 | 推荐持续时间 |
| --- | ---: | ---: | ---: |
| 凡品 | 5~10 | 10 | 1 |
| 精品 | 10~18 | 18 | 2 |
| 珍品 | 18~30 | 30 | 2~3 |
| 极品 | 30~50 | 50 | 3 |
| 绝品 | 50~75 | 75 | 4 |
| 神品 | 75~110 | 110 | 5 |

持续时间单位是“时”。只有临时增幅药品写 `持续时间`。

### 5. 永久增幅药品数值

凡品和精品不生成永久增幅药品。

| 品阶 | 单项永久增幅建议 | 多属性总预算建议 | 正向总上限 | 参照境界 |
| --- | ---: | ---: | ---: | --- |
| 珍品 | 8~12 | 12~18 | 18 | 二流圆满 |
| 极品 | 15~25 | 25~35 | 35 | 一流圆满 |
| 绝品 | 30~45 | 45~65 | 65 | 宗师圆满 |
| 神品 | 50~80 | 80~120 | 120 | 绝顶圆满 |

永久增幅药品稀有度高于普通回复药和临时爆发药。它应改变根基，而不是被当作普通补给批量发放。

### 6. 特殊药品

特殊药品不填 `属性修正`，不填 `持续时间`，不另加解除强度字段。

| 品阶 | 表现 |
| --- | --- |
| 凡品 | 缓解轻微症状，效果有限 |
| 精品 | 解决常见问题，如寻常毒伤、轻微迷药 |
| 珍品 | 能处理较麻烦的异常，但常有前提或代价 |
| 极品 | 可压制重毒、寒毒、内伤、易容等复杂效果 |
| 绝品 | 江湖名医或大派秘藏之物，可影响重要剧情 |
| 神品 | 近乎传说的奇药，必须伴随重大因果和限制 |

特殊药品的实际效果由物品描述和剧情情境决定。

### 7. 计算示例

装备示例：

```text
角色基础机敏 = 90
青锋剑：精品，机敏 +10
精品参照三流圆满，假设三流圆满基准机敏 = 160
精品装备正向总上限 = 10

理论增幅 = 90 × 10% = 9
品阶封顶 = 160 × 10% = 16
实际增幅 = 9
最终机敏 = 99
```

高境界封顶示例：

```text
角色基础机敏 = 900
青锋剑：精品，机敏 +10
精品参照三流圆满，假设三流圆满基准机敏 = 160

理论增幅 = 900 × 10% = 90
品阶封顶 = 160 × 10% = 16
实际增幅 = 16
最终机敏 = 916
```

回复药品示例：

```text
当前气血 = 40 / 100
金疮药：精品，气血 +35
理论回复 = 100 × 35% = 35
当前缺口 = 60
实际回复 = 35
使用后气血 = 75 / 100
```

特殊药品示例：

```text
解毒丹：精品，功效类型 = 特殊
前端只扣数量并进入指令队列。
指令：使用解毒丹，（“可化解寻常毒伤，对奇毒只能暂时压制”，请在剧情中体现）
AI 负责在剧情中表现毒性缓解、仍需逼毒、或对奇毒只能压制等结果。
```
