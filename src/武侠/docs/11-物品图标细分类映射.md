# 物品图标细分类映射

## 目的

本文定义前端行囊图标的细分类、资源选取策略与维护边界，供 `src/武侠/assets/icons/jinyong` 下的物品图标持续扩充时参考。

目标是让图标选择遵循稳定规则：

1. 先按物品语义落到细分类。
2. 再只在该细分类内部按品阶挑邻近资源。
3. 避免跨细分类借图导致视觉误导。

## 顶层类型与匹配顺序

顶层类型固定为：

- 装备
- 药品
- 秘籍
- 杂物

匹配顺序固定为：

1. 同类型精确名称 / 别名
2. 名称与描述关键词细分类
3. 部位兜底
4. 顶层类型兜底

约束：

- “同类型精确名称 / 别名” 优先级最高，只在同一顶层类型内命中，不跨到别的顶层类型借图。
- 关键词细分类同时参考 `物品名` 与 `物品描述`；命中后直接锁定细分类。
- 部位兜底只用于装备。建议只认当前行囊模型中的 `武器 / 护甲 / 鞋履 / 饰品`，再映射到武器大类或穿戴类。
- 顶层类型兜底只负责保证“看起来还是这一类东西”，不负责细节精度。
- 品阶只在细分类内选图，不能因为高品阶而跳去别的细分类找更“华丽”的图。

## 品阶资源策略

品阶资源按四档邻近匹配：

| 档位 | 对应品阶 | 资源选择规则                                             |
| ---- | -------- | -------------------------------------------------------- |
| 低档 | 凡 / 精  | 优先 `_1`，缺失时取同细分类最邻近低档资源                |
| 中档 | 珍       | 优先 `_2` 或 `_3` 中更朴素者，保持“明显更好但不过度发光” |
| 高档 | 极       | 优先 `_3` 或 `_4` 中较强表现资源                         |
| 顶档 | 绝 / 神  | 优先 `_4`；`神` 可与 `绝` 共池，但不要越类借图           |

补充约束：

- 允许同细分类内做“邻近匹配”，但不要求每个细分类都必须完整拥有四张图。
- 若某细分类资源不足，优先复用同细分类相邻档位资源，不要回退到误导性强的专名图。
- 新增资源文件建议使用 ASCII 文件名，并遵循：
  - `medicine_<subtype>_<tier>.<ext>`
  - `equip_<subtype>_<tier>.<ext>`
  - `secret_<subtype>_<tier>.<ext>`
  - `misc_<subtype>_<tier>.<ext>`

## 部位兜底建议

仅装备使用部位兜底，建议映射如下：

| 部位 | 兜底细分类                                                                                                     |
| ---- | -------------------------------------------------------------------------------------------------------------- |
| 武器 | 先看名称关键词；看不出时再按常见武器词频落到剑 / 刀 / 枪戟 / 棍棒 / 暗器，仍无法判断时回退剑或刀这类通用兵器池 |
| 护甲 | 衣甲                                                                                                           |
| 鞋履 | 鞋履                                                                                                           |
| 饰品 | 饰品                                                                                                           |

实现上要点：

- `武器` 不是一个可直接选图的细分类，它只是进入武器子类判断的入口。
- 若装备只有“兵器”“武器”这类泛称，又没有描述支撑，才允许退到较通用的武器池。

## 已确认误导资源

下列资源已确认不适合作为通用细分类兜底图：

| 源文件                | 当前视觉问题                                  | 处理建议                                                               |
| --------------------- | --------------------------------------------- | ---------------------------------------------------------------------- |
| `jinchuang_yao.jpg`   | 实际更像一盘红果 / 果实拼盘，不像外伤药或丹药 | 不要再作为“金创药”或通用药品兜底；若保留，只能在明确灵果语义时谨慎特判 |
| `jiuhua_yulu_wan.png` | 画面主体是强法术光效与能量束，不像实体药丸    | 不要作为“药丸”通用池；若保留，应仅限专名 `九花玉露丸` 的精确名匹配     |

这两类资源的共同问题是“专名能成立，通用就会误导”。后续新增图标时，应优先补通用细分类池，而不是继续扩充强专名图来承担兜底职责。

## 维护注意

1. 不要杜撰完整资源清单。文档里只记录可稳定依赖的代表性源文件，具体实现可在同细分类内继续扩充。
2. 新增图标优先补稀缺池：`弓 / 斧 / 锤 / 鞭` 这类装备子类当前代表资源较少，容易被迫全档复用。
3. 专名图与通用图分层维护。像 `大还丹`、`疾风丹` 这类专名图可以保留，但不能反向替代整个细分类默认池。
4. 名称与描述关键词要做同义词维护，尤其注意繁简体、武侠常见别称与文言写法。
5. 若未来补齐更多 `_1` 到 `_4` 资源，优先替换“跨档邻近复用”，不要改动细分类本身。
6. 当细分类判定与部位冲突时，以细分类优先。例如“铁扇”应命中扇，而不是因为可装备就退回泛武器。
7. 杂物兜底要尽量中性，避免把任务道具误画成高价值珠宝，或把书信误画成秘籍。

## 最终约束

1. 图标选择先分顶层类型，再分细分类，再按品阶选图。
2. 品阶匹配只在当前细分类资源池内部进行。
3. 精确名 / 别名命中可以覆盖关键词，但不能跨顶层类型借图。
4. 装备才允许走部位兜底；其他类型直接回退顶层类型兜底。
5. 已确认误导资源不能再承担通用默认图职责。
