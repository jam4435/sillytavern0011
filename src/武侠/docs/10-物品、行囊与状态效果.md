# 物品、行囊与状态效果

## 目的与边界

本文记录 `user数据.包裹`、`user数据.装备栏`、`user数据.状态效果`、`前端变量.永久属性修正` 的当前模型，以及行囊按钮如何影响持久变量和属性计算。

这套模型只讨论前端可读写的游戏状态。物品类型、品阶、数值预算、表现力和出身物品生成规则见 `../修为境界功法属性战斗的体系架构.txt` 第十一章；可直接交给其他 AI 的提示词见 `../物品生成模板.md`。

## 三层数据模型

| 层 | 字段 | 职责 | 真值含义 |
| --- | --- | --- | --- |
| 包裹 | `user数据.包裹` | 物品持有关系和物品模板信息 | 玩家是否拥有、拥有几个、物品基础元信息 |
| 装备栏 | `user数据.装备栏` | 当前生效装备 | 哪个部位实际装备了哪个物品 |
| 状态效果 | `user数据.状态效果` | 当前持续中的临时效果 | 哪些临时增幅药品仍在持续、还剩几时 |
| 永久修正 | `前端变量.永久属性修正` | 前端专用持久修正 | 哪些永久增幅药品已经生效 |

`包裹.使用状态` 只保留为 UI 显示/同步字段。属性计算不以它为准，而是读取 `装备栏`、`状态效果` 和 `前端变量.永久属性修正`。

## 包裹结构

包裹物品以物品名为 key：

```yaml
user数据:
  包裹:
    玄铁重剑:
      类型: 装备
      品阶: 绝品
      物品描述: 重剑无锋，大巧不工。
      数量: 1
      部位: 武器
      属性修正:
        臂力: 20 # 表示 +20%
      使用状态: 装备中
```

基础字段统一是：

- `类型`
- `品阶`
- `物品描述`
- `数量`

当前开发版底层字段已经从 `品质` 改为 `品阶`，不做旧 `品质` 兼容。

类型专属字段：

- 装备：`部位`、`属性修正`、`使用状态`
- 药品：`功效类型`；回复、临时增幅、永久增幅写 `属性修正`，只有临时增幅写 `持续时间`
- 秘籍：包裹只保存持有关系；描述、功法品阶、参悟条件优先从功法数据库补全

## 装备栏

装备栏是装备是否生效的真值：

```yaml
user数据:
  装备栏:
    $template: ''
    武器: 玄铁重剑
    护甲: 软猬甲
```

规则：

- key 是装备的 `部位` 字段，value 是包裹里的物品名。
- 同一部位只能生效一件装备。
- 新装备同部位时，`itemManager.equipInventoryItem()` 会替换旧装备。
- 替换时会同步包裹里的 `使用状态`，但计算仍以 `装备栏` 为准。

## 状态效果

状态效果是临时增幅药品是否仍在持续的真值：

```yaml
user数据:
  状态效果:
      九花玉露丸_1234567890_abcd:
      类型: 药品
      功效类型: 临时增幅
      来源: 九花玉露丸
      品阶: 珍品
      属性修正:
        气血: 30 # 表示 +30%
      持续时间: 3
      剩余时间: 2
```

规则：

- 使用临时增幅药品会扣减包裹数量，并创建一个独立状态效果。
- `来源` 记录药品物品名。
- `品阶` 和 `属性修正` 从药品模板复制，用于属性封顶计算。
- `持续时间` 从药品模板复制，默认至少为 1，单位为“时”。
- `剩余时间` 在玩家消息成功发送后递减，归零后删除。
- 同名药品再次服用当前先按独立效果处理，不做覆盖、互斥、刷新时长或叠层上限。

## 永久属性修正

永久增幅药品不写入 `user数据.状态效果`，而是写入前端专用区：

```yaml
前端变量:
  永久属性修正:
    大还丹_1234567890_abcd:
      类型: 药品
      功效类型: 永久增幅
      来源: 大还丹
      品阶: 神品
      属性修正:
        气血: 50
        内力: 70
```

`前端变量` 整体仍禁止 AI 写入。这里的 `永久属性修正` 只是前端按钮维护的持久子区；刷新 `周围地点 / 战力区 / 随机数 / 修为变化参考` 时必须合并保留它。

## 属性修正

`属性修正` 中的数字表示百分比点，例如 `臂力: 10` 表示 `臂力 +10%`。`attributeCalculator.applyAttributeModifiers()` 会按来源独立计算、按品阶封顶，再把实际增幅相加。

```text
理论增幅 = 基础属性 × 属性修正 / 100
品阶封顶 = 物品品阶对应参照境界基准属性 × 该类物品封顶比例 / 100
实际增幅 = min(理论增幅, 品阶封顶)
最终属性 = max(0, 基础属性 + 所有来源实际增幅之和)
```

正向增幅受品阶封顶；负数修正不吃正向封顶，但最终属性下限为 0。

生效来源：

1. `装备栏` 指向的包裹装备。
2. `状态效果` 中 `剩余时间 > 0` 的临时增幅。
3. `前端变量.永久属性修正` 中的永久增幅。

支持字段：

- 战斗属性：`臂力`、`根骨`、`机敏`、`洞察`
- 资源别名：变量生成统一写 `气血`、`内力`；前端在装备、临时增幅、永久增幅语境下按上限处理

气血/内力上限变化时，当前值按同增同减保留：

```text
新当前值 = clamp(旧当前值 + 新上限 - 旧上限, 0, 新上限)
```

回复型药品只修改当前值，不修改上限。

## 行囊交互链路

装备：

1. `InventoryPanel` 触发 `App.handleInventoryItemAction()`。
2. `App` 调用 `itemManager.equipInventoryItem(item.name)`。
3. `itemManager` 写入 `user数据.装备栏[部位]`。
4. 同步包裹内新旧装备的 `使用状态`。
5. `App` 重算并写回 `user数据.属性`，再重读 `readGameDataPure()` 刷新 UI。

使用药品：

1. `InventoryPanel` 触发 `App.handleInventoryItemAction()`。
2. `App` 调用 `itemManager.useMedicineItem(item.name)`。
3. `itemManager` 记录完整物品快照，按 `功效类型` 扣数量并写入当前气血/内力、状态效果、永久修正或特殊指令。
4. `App` 通过 `useCommandQueue.addUseItemCommand()` 追加待发送物品指令。
5. 取消待发送指令时，`useCommandQueue.cancelCommand()` 用完整快照恢复物品，并撤销资源变化、状态效果或永久修正。
6. 玩家消息成功发送后，`useCommandQueue.sendMessageWithCommands()` 调用 `decrementStatusEffectTurns()` 递减状态效果。

刷新 UI 不会扣减状态效果时间；只有成功发送玩家消息才会扣减。

## 读取与派生链路

`variableReader.ts` 负责把聊天变量映射为 `GameState`：

- `parseInventory()` 读取包裹，并把物品转换为行囊卡片数据。
- `parseEquipmentSlots()` 读取 `user数据.装备栏`。
- `parseStatusEffects()` 读取 `user数据.状态效果`。
- `collectActiveAttributeModifiers()` 汇总当前生效装备、有效状态效果和永久属性修正。
- `calculateAllAttributes(..., modifiers)` 计算玩家最终属性。
- `stats.baseAttributes` 保存不含物品效果的前端内部基准，供换装和服药预览使用，不写入存档。
- `InventoryPanel` 会显示百分比，并预览同部位替换后或服药后的实际属性变化。

`frontendDerivedVariables.ts` 也会读取同一套修正，用于生成 `前端变量.战力区`。因此提示词里看到的玩家战力区与角色面板属性使用同一个装备/药品模型。

## 必须保持的约束

1. 包裹是持有关系和模板信息，不是生效状态总表。
2. 装备是否生效只认 `user数据.装备栏`。
3. 临时增幅药品是否仍在持续只认 `user数据.状态效果`。
4. 永久增幅药品是否生效只认 `前端变量.永久属性修正`。
5. `包裹.使用状态` 只能服务显示和同步，不能作为属性计算真值。
6. 秘籍的功法描述、功法品阶、参悟条件优先读取功法数据库。
7. 属性修正是百分比点；每个来源独立按品阶封顶后再相加。
8. 玩家消息发送失败不能扣减状态效果时间。
9. 使用药品指令取消必须恢复完整物品对象，不能只恢复数量。
10. 新生成的装备部位只使用 `武器 / 护甲 / 鞋履 / 饰品`，避免动态部位扩充可装备数量。
11. 属性修正只使用 `臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力`；其他词条当前只具备叙事意义。
12. 疗伤、解毒类药品不能用临时增加气血上限来冒充即时恢复。

## 修改后验证

- 包裹物品底层字段使用 `品阶`。
- 秘籍卡片能从功法数据库读取描述、功法品阶和参悟条件。
- 装备按钮写入 `装备栏`，同部位替换旧装备。
- 药品按钮按 `功效类型` 扣数量并写入当前资源、`状态效果`、`永久属性修正` 或特殊指令。
- 取消使用指令能恢复完整物品元信息和对应变量变化。
- 装备和药品修正会影响角色属性与 `前端变量.战力区`。
- 行囊详情显示百分比，并能正确预览同部位换装后的最终属性。
- 成功发送玩家消息后状态效果递减，发送失败不递减。
