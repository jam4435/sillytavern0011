# CK 机制移植总表

本表不以“还原度”排序，而以它能否强化酒馆中的人物对话、长期政治后果和地图约束来筛选。

| 机制 | 主要借鉴 | 精华 | 酒馆化改造 | 首版优先级 |
|---|---|---|---|---|
| 伯爵领地图与称号层级 | CK2 / CK3 | 土地、称号和人物绑定 | 伯爵领作为战略多边形；男爵领作为县内地点；高阶称号作为法理与封臣关系 | P0 |
| 法理与实际统治 | CK2 / CK3 | “应该属于谁”和“实际属于谁”能长期冲突 | 分开保存法理父称号、称号持有者、实际领主链 | P0 |
| 战争占领 | CK2 / CK3 | 占领是谈判筹码，不等于立即吞并 | 独立控制层；和平时按战争理由转移称号 | P1 |
| 王朝、婚姻与继承 | CK2 / CK3 | 人的死亡会重排政治版图 | 继续扮演继承人；承诺、仇恨、秘密和债务跨代留下部分影响 | P1 |
| 性格与压力 | CK3 | 角色不是最优解机器，违背本性有代价 | 性格约束 NPC 决策与台词；玩家反复违背特质积累压力和事件 | P1 |
| 人物关系 | CK2 / CK3 | 私人好恶改变政治选择 | 不只用单一好感，至少拆成好感、信任、恐惧、义务/人情、怀疑；朋友/恋人/仇敌是关系标签 | P0 |
| 人物互动 | CK2 / CK3 | 行动有条件、接受度和明确后果 | 正式行动卡负责硬结果，自由对话负责谈条件和塑造接受度 | P0 |
| 秘密、把柄与阴谋 | CK3 | 信息本身就是政治资源 | 对话可发现线索，调查确认秘密，把柄可迫使一次正式让步；阴谋按阶段推进 | P1 |
| 角色位置与外交范围 | CK3 | 地图限制人物接触 | 同地才能面谈；远程用信件/使者；距离决定送达时间、失密与拒绝概率 | P0 |
| 旅行 | CK3 | 路线、随从、安全和事件把地图变成经历 | 伯爵领图寻路；速度、安全、危险三项；途中生成受地形、战争和同路人影响的场景 | P1 |
| 活动 | CK3 | 活动把多人集中到同一地点，并提供公开目的与私下意图 | 统一“筹办—邀请—旅行—阶段场景—结算”框架；宴会先行 | P1 |
| 巡游 | CK3 | 领主亲自接触边远封臣，用缺席换取统治收益 | 多站点路线；每站选择安抚、征税或监察倾向；核心奖励来自与当地人物面谈 | P1 |
| 摄政/权力分享 | CK3 为主 | 离开权力中心会给代理人积累实际权力 | 临时摄政与长期摄政分开；加入授权范围、任务、权力天平、滥权证据和罢免冲突 | P1 |
| 社团 | CK2 | 等级、任务、资源和秘密身份构成长线角色扮演 | 一个角色通常只有一个主要社团；任务必须进入地图和对话；能力优先提供新交互，而非纯数值加成 | P2 |
| 评议会与宫廷职位 | CK2 / CK3 | 任命既是能力选择也是政治分赃 | 官职提供行动权限、接触渠道与议题，不只提供被动加成 | P1 |
| 封臣义务与派系 | CK2 / CK3 | 内政不是单纯好感管理 | 税/兵义务简化为契约；不满者围绕具体诉求结成派系，可通过谈判、让步、威胁或战争处理 | P1 |
| 宝物与圣物 | CK2 / CK3 | 物品能承载身份、历史和争端 | 少量有来历的独特物品，可赠送、索回、继承、盗窃和成为宣称理由 | P2 |
| 完整兵种与战术微操 | CK2 / CK3 | 战争有准备和风险 | 只保留兵力、质量、补给、地形、指挥官和围城；不复刻庞大兵种表 | 暂缓 |
| 全量文化/宗教/科技树 | CK2 / CK3 | 世界差异与长期发展 | 第一版仅做会改变人物禁忌、继承、婚姻和地点事件的少数规则 | 暂缓 |

## 最重要的改造：关系不能只是一条“好感度”

CK 的单一评价值适合大量 NPC 的策略计算，但自由对话需要区分：

- **好感**：我是否喜欢你；
- **信任**：我是否相信你会履约；
- **恐惧**：我是否害怕拒绝你；
- **义务**：我欠你多少，或你掌握多少正当请求权；
- **怀疑**：我是否认为你在说谎或密谋；
- **吸引**：仅在相关关系与角色条件下使用。

同样是答应婚约，“喜欢且信任”“讨厌但畏惧”“欠下人情”应该产生完全不同的台词、后续稳定性和背叛风险。

## 最重要的交互改造：自由说话与正式行动并存

纯菜单会浪费酒馆，纯自然语言又会让状态不可控。建议每个场景同时有两条通道：

### 自由对话

玩家可以说任何话，用于试探、许诺、撒谎、羞辱、求情和建立私人关系。AI 记录候选事实，但不能直接改写硬状态。

### 正式行动

界面提供“提出婚约、索要封臣支持、要求交税、邀请入谋、赠送头衔”等可校验动作。自由对话中达成的条件会被整理进动作卡：

```text
对方愿意支持你的战争，条件是：
- 你在一年内任命其弟为元帅；
- 你承担 80 金币军费；
- 若食言，失去 30 信任并获得“背誓者”证据。
```

玩家确认后，系统创建承诺和条件，而不是让 AI 仅用一段文字宣布“他答应了”。

## 活动为何是对话系统的枢纽

活动天然解决了“地图很大，但玩家很难见到人”的问题：

- 主办人决定地点、规模、预算、来宾和公开目的；
- 来宾要判断是否接受，并实际旅行；
- 到场后形成有限时间的共同人物池；
- 每名参与者还可携带私下意图：拉拢、求婚、谋杀、和解、炫耀、调查；
- 多阶段日程给玩家数次有意义的会面机会；
- 活动结束后，关系、秘密、声望、承诺和伤亡统一结算。

因此宴会不是一个“花钱换好感”按钮，而应是第一种完整多人社交副本。巡游则是串联多个封臣地点的一组活动。

## 社团为何值得保留，但不应照搬数值能力

CK2 社团的真正价值是持续身份：加入门槛、秘密成员、任务、等级、社团资源、同伴网络和新能力。酒馆版更适合把能力设计成新的对话和场景权限：

- 识别暗号并与隐藏成员密谈；
- 请求同伴提供藏身处、介绍人或伪造文书；
- 在神殿、大学、酒馆等地点触发专属任务；
- 因公开身份或暴露秘密身份而改变他人态度；
- 晋升时获得仪式、导师和内部对手，而非只加属性。

首版社团数量应极少，但每个都要能穿过地图、对话、秘密和政治四个系统。

## 摄政为何应与旅行同时实现

如果旅行只有沿途事件而没有权力真空，领主离开首都几乎没有战略代价。摄政提供恰当交换：

- 玩家外出获得当面外交、巡察和活动机会；
- 摄政在首都处理日常事务并接触封臣；
- 玩家授权越广，摄政越有效，也越容易建立自己的关系网；
- 长期缺席、幼主或失能会把临时代理变成权力斗争；
- 玩家回归后可能需要奖励、安抚、调查或清洗摄政集团。

这正好把地图移动、人物交互和内政风险连成一个系统。
