# 世界书编辑脚本 - UI 全面审美升级计划 (代码级)

## 设计目标
在**不改变现有 HTML 结构逻辑（防破坏事件绑定）**、**不引入外部 CSS 框架**、**不影响后端交互**的前提下，通过修改 JS 文件中硬编码的 `<style>` 字符串和内联 `.css()` 调用，实现 UI 的**现代化暗黑扁平风格** (Modern Dark Flat Design) 升级。

## 全局设计规范 (参考)
*   **背景色 (Background):** 主面板 `#1e1e1e` (深灰)，次级面板 (条目, 弹窗) `#252526`，输入框 `#333333`。
*   **文字色 (Text):** 主文本 `#e0e0e0`，次要文本/描述 `#a0a0a0`。
*   **强调色 (Primary/Accent):** 采用更柔和、现代的蓝紫色，例如 `#6c5ce7` 或青色 `#00cec9`。
*   **边框 (Border):** 统一为 `#444444`，弱化存在感。
*   **圆角 (Border-Radius):** 全局控件统一使用 `4px` 或 `6px`，弹窗/面板使用 `8px`。
*   **动画 (Transitions):** 按钮 hover、输入框 focus 增加 `transition: all 0.2s ease`。

## 阶段 1：全局主题与基础组件重塑

### 目标文件: `src/世界书编辑脚本/modules/ui/theme.js`
*   **操作:** 修改默认主题变量，奠定暗黑风格基础。
*   **代码修改点:**
    *   找到 `getDefaultTheme()` 函数。
    *   修改返回对象的默认值：
        ```javascript
        return {
          bgColor: '#1e1e1e', // 更深的背景
          textColor: '#e0e0e0', // 柔和的白色
          accentColor: '#6c5ce7', // 现代的强调色 (蓝紫)
          entryBgColor: '#252526', // 条目卡片背景
          yamlInputBgColor: '#2d2d30',
          // ... 其他变量
        };
        ```

### 目标文件: `src/世界书编辑脚本/modules/ui/panel.js`
*   **操作:** 重写全局的基础 CSS，特别是滚动条、按钮、输入框的默认样式。
*   **代码修改点:**
    *   定位到 `const panelStyles = \`<style id="enhanced-lorebook-styles">...\`` 块。
    *   **滚动条 (Scrollbar):**
        ```css
        ::-webkit-scrollbar { width: 8px; height: 8px; }
        ::-webkit-scrollbar-track { background: transparent; }
        ::-webkit-scrollbar-thumb { background-color: #555; border-radius: 4px; }
        ::-webkit-scrollbar-thumb:hover { background-color: #777; }
        ```
    *   **通用按钮 (.lorebook-copy-confirm-btn, .theme-settings-button 等):**
        *   移除现有的硬边框和可能存在的渐变。
        *   增加 `border-radius: 6px; border: none; padding: 6px 12px; transition: background-color 0.2s, transform 0.1s;`。
        *   增加 hover 状态：`&:hover { filter: brightness(1.1); transform: translateY(-1px); }`
        *   增加 active 状态：`&:active { transform: translateY(0); }`
    *   **通用输入框/文本域 (input[type="text"], textarea, .form-control):**
        *   统一背景和边框：`background-color: #333333; border: 1px solid #444444; border-radius: 4px; color: #eee; padding: 8px; transition: border-color 0.2s, box-shadow 0.2s;`
        *   统一 focus 状态：`&:focus { border-color: var(--panel-accent-color, #6c5ce7); outline: none; box-shadow: 0 0 0 2px rgba(108, 92, 231, 0.2); }`
    *   **开关 (Toggle Switch):** 重写 `.switch`, `.slider.round` 的样式，使其更像 iOS 或现代 Web UI (减小高度，增加动画平滑度)。
    *   **标签页 (.tab-button):** 移除下划线等老旧样式，改为背景色块切换或更精致的下划线动画。

## 阶段 2：列表与主从布局优化

### 目标文件: `src/世界书编辑脚本/modules/ui/list.js`
*   **操作:** 优化顶部工具栏和条目列表的视觉层级。
*   **代码修改点:**
    *   定位到拼接 `.lorebook-batch-action-button` 的地方 (大量 `html()` 和 `.css('background-color', ...)` 的调用)。
    *   统一这些工具按钮的颜色风格，不要使用过于杂乱的高饱和度颜色。可以考虑统一使用暗灰色底色 (`#444`)，hover 时才显示各自的功能色；或者统一降低现有颜色的饱和度和明度。
    *   修改内联样式的圆角：`.css('border-radius', '4px')` -> `.css('border-radius', '6px')`。
    *   如果有针对列表容器的内联 CSS，增加一些 padding。

### 目标文件: `src/世界书编辑脚本/modules/ui/entry.js`
*   **操作:** 美化单个条目的卡片样式。
*   **代码修改点:**
    *   找到针对条目容器的样式类 (`.master-entry-item`, `.lorebook-entry-item`)。这些可能在 `panel.js` 的 `<style>` 中，也可能部分内联。
    *   **卡片化:** 增加细微的背景色差 (`background-color: var(--panel-entry-bg-color)`) 和极弱的边框 (`border: 1px solid #333`)，加上 `border-radius: 6px`。
    *   **悬停效果:** `&:hover { background-color: #2a2d31; }`。
    *   **激活状态 (.active):** 使用柔和的发光或左侧粗边框来指示选中状态，而不是生硬的背景色替换。
    *   优化 `UID` 显示和次要信息 (`.master-entry-meta`) 的字体颜色 (变淡) 和大小 (变小)。

## 阶段 3：详情编辑与弹出编辑器美化

### 目标文件: `src/世界书编辑脚本/modules/ui/detail.js`
*   **操作:** 优化主从布局右侧的表单排版。
*   **代码修改点:**
    *   找到 `const DETAIL_STYLE_ID` 下的 `<style>` 块。
    *   优化 `.detail-editor` 的内边距。
    *   规范所有的 `.detail-field` 和 `.detail-row`。增加 `gap` 以改善拥挤感。
    *   优化**关键词编辑区**和**标志位区 (checkboxes)** 的排版，使用 Flexbox 或 CSS Grid 对齐它们，使其看起来更整齐。

### 目标文件: `src/世界书编辑脚本/modules/ui/contentEditor.js`
*   **操作:** 优化全屏编辑器和双栏对比编辑器的视觉体验。
*   **代码修改点:**
    *   找到 `<style id="${STYLE_ID}">` 块。
    *   **模态框容器 (`#${COMPARE_EDITOR_MODAL_ID}`):** 优化背景遮罩 (使用 `backdrop-filter: blur(4px)`)，调整模态框主体的圆角和阴影 (`box-shadow: 0 8px 32px rgba(0,0,0,0.5)`).
    *   **对比窗格 (`.compare-diff-panel`):** 增强对比度，左侧(旧)和右侧(新)的差异文本使用更柔和的红/绿色块，而不是刺眼的纯色。
    *   优化保存/关闭等动作按钮的样式，与阶段 1 保持一致。

## 阶段 4：AI 工作区深度美化 (重点)

### 目标文件: `src/世界书编辑脚本/modules/ui/aiWorkspaceDesktop.js`
*   **操作:** 这是最复杂的部分。优化侧边栏、步骤条和各个面板。
*   **代码修改点:**
    *   找到 `<style id="lorebook-ai-workspace-desktop-styles">`。
    *   **侧边栏 (`.ai-desktop-nav`):** 深化背景色，优化 `.ai-mode-nav-button` 的选中状态 (例如左侧高亮条)。
    *   **步骤指示器 (`.ai-stepper`):** 设计更现代的步骤条。使用圆形数字图标和连接线。已完成的步骤用主强调色，当前步骤高亮，未完成的步骤置灰。
    *   **表单容器 (`.ai-panel`):** 增加背景色块划分，使用 `border: 1px solid #333; border-radius: 8px; padding: 20px; margin-bottom: 20px;` 将每个设定区域清晰地隔开。
    *   **调试网格 (`.ai-debug-grid`):** 优化 `<details>` 和 `<summary>` 的样式，使其更像现代的代码折叠面板。

### 目标文件: `src/世界书编辑脚本/modules/ui/aiWorkspace.js`
*   **操作:** 如果旧版抽屉式布局仍需保留支持，优化其基础样式。
*   **代码修改点:**
    *   找到 `<style id="lorebook-ai-workspace-styles">`。
    *   美化 `.ai-drawer-summary` (抽屉头部)，增加悬停效果和展开/折叠的动画图标指示。

## 阶段 5：剩余模态框与组件

### 目标文件: 
*   `src/世界书编辑脚本/modules/features/optimizer.js` (优化工具)
*   `src/世界书编辑脚本/modules/features/bulkImport.js` (批量导入)
*   `src/世界书编辑脚本/modules/features/batchActions.js` (批量复制/位置调整)
*   `src/世界书编辑脚本/modules/ui/editor.js` (旧版模态编辑器)

*   **操作:** 统一所有独立弹窗的风格。
*   **代码修改点:**
    *   这些文件通常都在内联字符串中定义了自己的 `<style>` 和 `style="..."` 属性。
    *   全局搜索这些文件中的 `background-color: #2c2c2c`, `border: 1px solid #555`, `border-radius: 8px` 等硬编码样式。
    *   将它们替换为与阶段 1、阶段 2 统一的颜色和圆角规范。特别是模态框头部的背景色 (`background-color: #3a6a8e` 等) 统一改用低饱和度的暗色或强调色。
    *   确保关闭按钮 (`.close-button`) 样式统一（放大热区，hover 时颜色变化）。

## 执行方式说明
在执行时，我们将逐个文件打开，定位到指定的 `<style>` 字符串或 JS 拼接逻辑处，使用正则表达式替换或字符串片段替换重写 CSS，绝不修改带有 `data-action` 绑定的 HTML 结构。
