# 世界书编辑脚本插件前端美观优化计划

## 1. 目标

针对 `src/世界书编辑脚本` 目录下的世界书编辑插件，在**不涉及功能改动**、**影响最小化**的前提下，对其所有页面和窗口进行完整的前端美观优化。

## 2. 优化原则

*   **美观优先**：提升整体视觉体验，包括色彩搭配、间距、排版、交互反馈等。
*   **不涉及功能改动**：绝对不修改任何现有的业务逻辑、API 调用和数据处理。
*   **影响最小化**：优先通过修改 CSS 样式来实现。

## 3. 具体修改计划

以下是详细的修改计划，精确到文件、行号和具体的 CSS 改动。

### 3.3 内联样式替换建议 (Inline Styles)

在 JS 文件中存在少量直接使用 `.css()` 或 `style="..."` 的地方。虽然计划主要关注 CSS，但可以留意以下几点：

1.  **文件：** `src/世界书编辑脚本/modules/ui/list.js`
    *   **行 809, 1962 (近似)：** 虚拟滚动条目占位高
        *   **原代码：** `$1 style="height: ${styleHeight}px; box-sizing: border-box;"`
        *   **修改建议：** 这里控制高度不可避免，但可将 `box-sizing: border-box;` 移至 CSS 类中。
    *   **行 932：** 搜索栏容器 (`.global-lorebook-adder`)
        *   **原代码：** `style="margin-bottom: 15px; position: relative; display: ${showSearchBar ? 'flex' : 'none'}; align-items: center;"`
        *   **修改建议：** 将基础样式移入 `.global-lorebook-adder` 的 CSS 规则中，JS 中只使用 `display` 控制显示/隐藏或用 `.toggle()`。
    *   **行 938, 977, 1075, 1088, 1090 等：** 各种全局/常驻世界书相关的容器
        *   **修改建议：** 这些通过 HTML 字符串拼接的组件内联了大量的 `style="..."`。将它们提炼到 `panel.js` 的 `panelStyles` 中，例如提取类 `.current-bound-books`, `.global-search-bars-container`, `.preset-dropdown-container`, `.preset-dropdown-button` 等对应的 CSS 规则。

2.  **文件：** `src/世界书编辑脚本/modules/ui/entry.js`
    *   **行 114, 166, 201：** 置顶图标 (`.master-entry-pin`)
        *   **原代码：** `style="${isPinned ? '' : 'display:none;'}"`
        *   **修改建议：** 改用类名控制，例如 `<i class="fa-solid fa-thumbtack master-entry-pin ${isPinned ? '' : 'd-none'}"></i>`（需在 CSS 中定义 `.d-none { display: none !important; }`）。

3.  **使用 jQuery `.css()` 的地方 (跨多文件)：**
    *   **文件：** `src/世界书编辑脚本/modules/ui/list.js`
        *   大量的 `.css('background-color', '...')` 用于控制按钮颜色。
        *   **修改建议：** 这些按钮都附加了相关的 class，比如 `.lorebook-batch-action-button` 或具体功能对应的数据属性。最好在 CSS 中使用 `[data-action="..."]` 选择器来统一管理颜色，而不是在 JS 中硬编码。例如：
            ```css
            #${LOREBOOK_PANEL_ID} .lorebook-batch-action-button[data-action="bulk-import"] {
                background-color: #4a7c9a;
            }
            #${LOREBOOK_PANEL_ID} .lorebook-batch-action-button[data-action="bulk-import"]:hover {
                background-color: #5c8cae; /* 顺便添加悬停效果 */
            }
            ```
            然后在 JS 中移除 `.css('background-color', '...')` 的调用。

        ```javascript
            // ...
        };
        ```

## 4. 实施步骤总结

1.  **备份文件**：修改前确保通过 Git 管理 `panel.js`。
2.  **定位 `panelStyles`**：在 `src/世界书编辑脚本/modules/ui/panel.js` 的 `initPanel` 函数内，找到包含 `<style id="enhanced-lorebook-styles">` 的巨大模板字符串。
3.  **应用 CSS 修改**：按照上述 3.1 和 3.2 的细节，逐一替换相应的 CSS 规则块。
4.  **清理 JS 内联样式**：按照 3.3 节的建议，查找 `ui` 目录下的其他 JS 文件（主要是 `list.js` 和 `entry.js`），将硬编码的 `style="..."` 和 `.css('background-color', ...)` 转移到 CSS 选择器中。
5.  **调整默认主题**：修改 `theme.js` 中的默认色值。
6.  **保存并测试**：无需重新编译 JS 逻辑（如果使用构建工具则运行 build），在酒馆中硬刷新页面，唤出世界书面板，检查：
    *   面板外观是否更加现代化、圆润。
    *   条目 Hover 效果是否平滑。
    *   展开条目后内部的输入框和布局是否美观且不破坏功能。
    *   悬浮球拖拽和点击是否正常。

这份计划通过纯 CSS 的微调，实现了“美观优先、无功能改动、影响最小化”的目标。
