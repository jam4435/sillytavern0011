# 世界书编辑脚本 - UI 全面审美升级计划 (代码级详细版)

## 设计目标
在**不改变现有 HTML 结构逻辑（防破坏事件绑定）**、**不引入外部 CSS 框架**、**不影响后端交互**的前提下，通过修改 JS 文件中硬编码的 `<style>` 字符串和内联 `.css()` 调用，实现 UI 的**现代化暗黑扁平风格** (Modern Dark Flat Design) 升级。

## 全局设计规范 (参考)
*   **背景色 (Background):** 主面板 `#1e1e1e` (深灰)，次级面板 (条目, 弹窗) `#252526`，输入框 `#333333`。
*   **文字色 (Text):** 主文本 `#e0e0e0`，次要文本/描述 `#a0a0a0`。
*   **强调色 (Primary/Accent):** 采用更柔和、现代的蓝紫色，例如 `#6c5ce7` 或青色 `#00cec9`。
*   **边框 (Border):** 统一为 `#444444`，弱化存在感。
*   **圆角 (Border-Radius):** 全局控件统一使用 `4px` 或 `6px`，弹窗/面板使用 `8px`。
*   **阴影 (Box-Shadow):** 使用更柔和的多层阴影，如 `0 4px 12px rgba(0,0,0,0.3)`。
*   **动画 (Transitions):** 按钮 hover、输入框 focus 增加 `transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`。


## 阶段 2：列表与主从布局优化

### 2.1 `src/世界书编辑脚本/modules/ui/list.js`
*   **目标:** 弱化顶部大面积的色块工具栏，使其融入暗黑背景；统一图标按钮风格。
*   **具体代码修改:**
    *   在 `.addClass('lorebook-batch-action-button')` 后面的 `.css('background-color', '...')`。
    *   将各种五颜六色的高纯度色值（如 `#336699`, `#993333`, `#7a5a9e`）统一改为低饱和度、低明度的深色，或者统一使用主背景色但依赖 icon 本身的颜色或 hover 态。
    *   **建议修改方式:**
        将其背景色统一设为 `#333` 或 `#2a2d31`，文字色为浅灰 `#ccc`。
        ```javascript
        .css({
            'background-color': '#333',
            'color': '#ccc',
            'border': '1px solid #444',
            'border-radius': '6px',
            'padding': '6px 10px'
        })
        ```
        （由于这是 jQuery 动态设置的内联样式，如果可能，最好在 `panel.js` 的 CSS 中增加 `.lorebook-batch-action-button { background: #333 !important; ... }` 并在此处移除 `.css()` 调用，以实现彻底的样式分离，但这取决于代码的耦合程度。若只求最少修改，则直接改 `.css()` 参数。）

*   **目标:** 替换掉这些文件中 HTML 字符串内联 `style="..."` 的老旧暗色主题定义。
*   **具体代码修改:**
    *   搜索文件内的: `background-color: #2c2c2c` (主背景) -> 替换为 `#1e1e1e` (或依赖 theme 变量如果在 `<style>` 块内)。

        ```css
            border-radius: 8px;
        ```
