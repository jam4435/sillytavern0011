# AI 工作区 UI 美化方案

## 1. 总体设计理念

本方案旨在将“世界书编辑脚本”的AI工作区从现有功能性的抽屉式/主从布局，重塑为一个专业、现代、具有科技感的SaaS工具界面。设计灵感来源于Vercel Dashboard、Linear及Claude 2等现代AI与开发工具，强调清晰的信息层级、流畅的操作流程和精致的视觉细节。

**核心设计原则：**

1.  **沉浸式主从布局 (PC端):** 借鉴现代Web App，采用左侧固定导航栏+右侧内容区的经典布局，取代目前分散的抽屉式结构，为核心操作提供更集中的舞台。
2.  **卡片化与分组:** 将功能区域（如API设置、条目选择、指令等）整合进视觉清晰的卡片（Panel）中，使用圆角、描边和阴影定义边界，增强模块感。
3.  **视觉层级优化:** 通过字体大小、字重、颜色和间距的微妙变化，引导用户视线。重要操作按钮（如“生成预览”）将使用更醒目的强调色，次要操作则弱化处理。
4.  **精致的交互反馈:** 为按钮、输入框、下拉菜单等交互元素添加平滑的过渡动画和状态变化（Hover, Focus, Active），提升操作的响应感和愉悦感。
5.  **统一的视觉语言:** 严格遵循 `theme.js` 中的CSS变量，确保新设计能与现有主题系统无缝对接，同时引入新的CSS变量以支持更丰富的视觉效果（如渐变、阴影）。
6.  **响应式设计:** 移动端将保留并优化现有的“手机弹窗式AI助手”和抽屉式布局，但会采用与PC端一致的视觉风格和组件样式，确保跨设备体验的一致性。

### 2.3 新增CSS变量

为了实现更丰富的设计，将在 `theme.js` 中引入以下新的CSS变量（在`applyTheme`函数中计算并应用）：

```javascript
// 在 theme.js 的 applyTheme 中
$panel.css({
    '--ai-surface-color': colorMix(layoutTheme.bgColor, 80, '#000000'),
    '--ai-surface-color-hover': colorMix(layoutTheme.bgColor, 70, '#ffffff'),
    '--ai-surface-color-subtle': colorMix(layoutTheme.bgColor, 90, '#000000'),
    '--ai-border-color': colorMix(layoutTheme.bgColor, 50, '#ffffff'),
    '--ai-border-color-hover': colorMix(layoutTheme.accentColor, 70, layoutTheme.bgColor),
    '--ai-text-color-secondary': colorMix(layoutTheme.textColor, 70, 'transparent'),
    '--panel-accent-color-translucent': colorWithOpacity(layoutTheme.accentColor, 0.15),
});
```
这些变量将统一应用到上述所有新组件中。

## 3. 移动端UI美化方案 (`aiWorkspace.js`)

移动端将保持现有的抽屉式布局和手机AI助手弹窗，但会对其内部组件应用与PC端一致的卡片化、控件样式和视觉语言。

### 3.1 抽屉(`ai-drawer`)美化

将`ai-drawer`改造为更具现代感的折叠面板。

**HTML结构 (不变):**
保持 `ai-drawer` > `ai-drawer-summary` + `ai-drawer-body` 的结构。

**CSS样式 (修改 `ensureStyles`):**

```css
#${ROOT_ID} .ai-drawer {
    border: 1px solid var(--ai-border-color); /* 使用新变量 */
    border-radius: 12px; /* 增大圆角 */
    background: transparent; /* 父级已有背景 */
    overflow: hidden;
    margin-bottom: 16px;
    transition: box-shadow 0.3s ease;
}
#${ROOT_ID} .ai-drawer-summary {
    padding: 16px 20px;
    font-weight: 500; /* 减轻字重 */
    background-color: var(--ai-surface-color);
    transition: background-color 0.2s ease;
}
#${ROOT_ID} .ai-drawer-summary:hover {
    background-color: var(--ai-surface-color-hover);
}
#${ROOT_ID} .ai-drawer-body {
    padding: 20px;
    background-color: var(--ai-surface-color-subtle);
}
```

保持其“手机”形态，但内部UI元素（如聊天气泡、输入框、按钮）将进行精致化处理。

## 4. 响应式适配

- **PC端:** 新的主从布局天然适合宽屏。当屏幕宽度减小到一定阈值（如 `1024px`）时，左侧导航栏可以设计为可折叠状态，只显示图标，鼠标悬浮时再展开。
- **移动端:** 当 `isMobile()` 为 `true` 时，`aiWorkspaceDesktop.js` 的 `ensureMarkup` 将不执行任何操作，回退到 `aiWorkspace.js` 的抽屉式布局，并应用上述移动端美化样式。确保两种布局的CSS变量和基础组件样式（按钮、输入框等）保持一致，实现视觉统一。
