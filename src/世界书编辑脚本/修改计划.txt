# 世界书编辑脚本 - UI 全面审美升级计划 (严格宿主隔离与内联样式消除版)

## 核心准则 (GPT 评估反馈修正)

1.  **严格选择器隔离：** 所有注入到宿主 (`parentDoc`) 的 CSS 规则，**必须**以 `#${LOREBOOK_PANEL_ID}`、`#theme-settings-modal` 或具体的弹窗 ID 作为前缀。**绝对禁止**全局定义 `button`, `input`, `::-webkit-scrollbar` 等通用标签，防止污染酒馆宿主页面或其他插件。
2.  **消除内联背景色：** 现存的通过 `$.css('background-color', ...)` 动态设置的高饱和度颜色（集中在 `list.js` 和部分批量菜单），尽量移除或统一改用添加 class 配合 CSS 变量的方式处理。
3.  **精准属性更新：** 主题变量的设置状态不属于单纯的“主题”，应仅修改颜色和圆角等纯视觉变量（如 `bgColor`, `textColor`, `accentColor` 等），不要混入需要 Settings Manager 管理的功能开关（如 `showSearchBar` 等）。
4.  **安全的主题更新机制：** 直接修改 `getDefaultTheme` 可能无法覆盖用户 localStorage 中的旧配置。因此，新的 CSS 规则应该在设计上兼容或优雅降级，或者直接将默认色板更替为暗黑风格，如果用户已存储则按用户存储的来，确保不破坏用户的自定义。

## 全局设计规范
*   **背景色 (Background):** 主面板 `#1e1e1e` (深灰)，次级面板 (条目, 弹窗) `#252526`，输入框 `#333333`。
*   **文字色 (Text):** 主文本 `#e0e0e0`，次要文本/描述 `#a0a0a0`。
*   **强调色 (Primary/Accent):** 采用更柔和、现代的蓝紫色，例如 `#6c5ce7` 或青色 `#00cec9`。
*   **边框 (Border):** 统一为 `#444444`，弱化存在感。
*   **圆角 (Border-Radius):** 全局控件统一使用 `4px` 或 `6px`，弹窗/面板使用 `8px`。
*   **阴影 (Box-Shadow):** 使用更柔和的多层阴影，如 `0 4px 12px rgba(0,0,0,0.3)`。
*   **动画 (Transitions):** 按钮 hover、输入框 focus 增加 `transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`。

