# 世界书编辑脚本插件前端美观优化计划\n\n## 1. 目标\n\n针对 `src/世界书编辑脚本` 目录下的世界书编辑插件，在**不涉及功能改动**、**影响最小化**的前提下，对其所有页面和窗口进行完整的前端美观优化。\n\n## 2. 优化原则\n\n*   **美观优先**：提升整体视觉体验，包括色彩搭配、间距、排版、交互反馈等。\n*   **不涉及功能改动**：绝对不修改任何现有的业务逻辑、API 调用和数据处理。\n*   **影响最小化**：优先通过修改 CSS 样式来实现。\n\n## 3. 具体修改计划\n\n以下是详细的修改计划，精确到文件、行号和具体的 CSS 改动。\n\n### 3.1 主面板样式优化 (src/世界书编辑脚本/modules/ui/panel.js)\n\n**文件：** `src/世界书编辑脚本/modules/ui/panel.js`\n**目标：** 优化整体容器的阴影、圆角、背景色，以及 Header 的内边距。\n\n1.  **行 366-372：优化 `#${LOREBOOK_PANEL_ID}` 基础样式**\n    *   **原代码 (近似)：**\n        ```css\n        background-color: var(--panel-bg-color);\n        border: 1px solid var(--panel-border-color);\n        border-radius: 8px;\n        box-shadow: 0 5px 15px rgba(0, 0, 0, 0.5);\n        ```\n    *   **修改为：**\n        ```css\n        background-color: var(--panel-bg-color);\n        /* 添加一点毛玻璃效果（取决于环境是否支持，不影响功能） */\n        backdrop-filter: blur(10px);
