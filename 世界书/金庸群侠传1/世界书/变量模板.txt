<变量模板>

本模板只定义 AI 可写变量的**路径、数据结构、字段含义与写入权限**。  
未在本模板列出的变量，默认不属于 AI 可直接写入范围。

权限说明：

- **仅添加**：字段创建后原则上不再修改。
- **可修改**：可新增，也可修改已有内容。
- **仅修改已有**：只能修改当前已经存在的字段或子项，不得自行扩展新结构。
- **只读**：仅供理解上下文，不得写入。

---

## 一、世界信息

AI 在 `世界信息` 下只允许修改 `时间`。

路径：

`世界信息.时间`

| 字段 | 类型 | 权限 | 说明 |
|---|---|---|---|
| 时间 | object | 可修改 | 当前游戏时间；修改时必须作为完整原子对象写入 |

结构：

```json
{
  "世界信息": {
    "时间": {
      "年": 1201,
      "月": 4,
      "日": 2,
      "时": 13,
      "分": 10
    }
  }
}
```

`年 / 月 / 日 / 时 / 分`均为整数，`分`只能为 0–59。  
修改时间时必须一次写入完整五字段，不得只修改其中一部分。具体何时推进、推进多少以及禁止回拨等判定规则，以《变量指导》为准。

---

## 二、参与事件变量

路径：

`参与事件.【事件名】`

事件本身由系统创建，AI **不得新增或删除事件键**。

| 字段 | 类型 | 权限 | 说明 |
|---|---|---|---|
| 描述 | string | 只读 | 当前事件及原定发展的说明 |
| 结局 | string | 可修改 | 事件最终结果概要，仅在实际剧情明显偏离原定结果时修改 |
| insert | object | 仅修改已有 | 原定需要新增到 NPC 数据中的结算差分 |
| update | object | 仅修改已有 | 原定需要修改的 NPC 数据差分 |
| delete | object | 仅修改已有 | 原定需要删除的 NPC 数据差分 |

结构示意：

```json
{
  "参与事件": {
    "【已有事件名】": {
      "描述": "【系统提供，只读】",
      "结局": "【实际事件最终结果概要】",
      "insert": {
        "【人物名】": {
          "【已有差分字段】": "【修改后的值】"
        }
      },
      "update": {
        "【人物名】": {
          "【已有差分字段】": "【修改后的值】"
        }
      },
      "delete": {
        "【人物名】": {
          "【已有差分字段】": {}
        }
      }
    }
  }
}
```

`insert / update / delete` 只用于事件原本已经提供的 NPC 差分快照。  
不得在其中新增原本不存在的结算项目，也不得在其中写入 `user数据`。

## 三、人物共有字段

以下字段同时适用于：

- `user数据`
- `角色数据.【人物名】`

| 字段 | 类型 | 权限 | 内容 |
|---|---|---|---|
| 性别 | string | 仅添加 | 人物生理性别 |
| 外貌 | string | 可修改 | 稳定外貌特征；永久伤残等长期变化可更新 |
| 出生年份 | number | 仅添加 | 出生年份 |
| 状态 | string | 可修改 | 当前具有长期意义的身体或生活状态 |
| 境界 | string | 可修改 | 当前武学境界 |
| 修为 | number | 可修改 | 当前修为值 |
| 所在位置 | string | 可修改 | 当前所在地点路径 |
| 身份 | object | 可修改 | 对剧情有实际意义的身份 |
| 功法 | object | 可修改 | 当前掌握的武学 |
| 属性 | object | 部分可修改 | 气血、内力保存当前值与上限；其余战斗属性由系统计算 |
| 人物经历 | object | 可修改 | 对人物具有长期影响的重要经历 |
| 关系网 | object | 可修改 | 以人物名为键，记录长期关系描述或关系数值 |

### 身份

身份使用“身份名 → 说明”的扁平结构：

```json
{
  "身份": {
    "【身份名】": "【该身份对剧情有意义的说明】"
  }
}
```

---

### 关系网

关系网固定使用“人物名 → 关系值”的扁平结构，当前关系值只允许 `string` 或有限数值 `number`：

```json
{
  "关系网": {
    "郭靖": "生死之交",
    "黄蓉": 75
  }
}
```

- 字符串表示长期关系标签或关系说明。
- 数字表示关系数值。
- 同一个人物当前只保存一个字符串或一个数字，不要写成嵌套对象，不要自行增加 `关系 / 关系值 / 好感度` 等子字段。
- 普通交谈、一次帮助、短时情绪或尚未形成稳定关系的互动，不应修改关系网。

---

### 功法

```json
{
  "功法": {
    "【功法名】": {
      "类型": "【内功 / 外功 / 轻功 / 剑法 / 刀法 / 拳掌 / 指法 / 暗器 / 枪戟 / 棍锤】",
      "功法描述": "【功法的稳定说明】",
      "功法品阶": "【粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说】",
      "掌握程度": "【初窥门径 / 略有小成 / 融会贯通 / 炉火纯青 / 出神入化】",
      "特性": {
        "【掌握程度】": "【对应特性效果】"
      }
    }
  }
}
```

功法类型只使用：

`内功 / 外功 / 轻功 / 剑法 / 刀法 / 拳掌 / 指法 / 暗器 / 枪戟 / 棍锤`

功法品阶只使用：

`粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说`

掌握程度由低到高固定为：

`初窥门径 / 略有小成 / 融会贯通 / 炉火纯青 / 出神入化`

`特性`的键使用对应的掌握程度。  
新增一门功法时，应按完整功法结构建立，不要因为猜测该功法可能存在于数据库而只写 `掌握程度`。

运行时若功法数据库存在同名功法，系统会保留变量中的 `掌握程度`，并以数据库中的 `类型 / 功法描述 / 功法品阶 / 特性`补全或校正变量；若数据库不存在该功法，则变量中生成的完整结构继续作为该功法的完整信息来源。

---

### 属性

```json
{
  "属性": {
    "气血": "当前气血/气血上限",
    "内力": "当前内力/内力上限",
    "臂力": 0,
    "根骨": 0,
    "机敏": 0,
    "洞察": 0
  }
}
```

`气血`和`内力`必须保存为完整的：

`当前值/上限值`

例如：

`72/100`

表示当前气血为 72，气血上限为 100。

修改当前气血或内力时，仍应保留完整的 `当前值/上限值`，不得只写单独的当前值。

`臂力 / 根骨 / 机敏 / 洞察`为单一战斗属性数值，由初始属性、境界、功法及其他加成计算，原则上由系统维护，AI 不直接修改。

---

### 人物经历

```json
{
  "人物经历": {
    "【经历名】": "(1201.04.02) 【具有长期意义的经历内容】"
  }
}
```

经历值必须以**游戏内日期**开头：

`(年.月.日) 内容`

普通交谈、短时动作、一次性情绪变化不属于人物经历。

---

## 四、user数据

路径：

`user数据`

除上述人物共有字段外，玩家还拥有以下专属结构。

| 字段 | 类型 | 权限 | 内容 |
|---|---|---|---|
| 初始属性 | object | 原则只读 | 玩家基础七维属性 |
| 包裹 | object | 可修改 | 玩家当前持有的物品 |
| 装备栏 | object | 只读 | 当前装备，由前端装备系统维护 |
| 状态效果 | object | 只读 | 当前持续中的临时效果，由前端用药与回合递减链维护 |
| 天赋 | object | 只读 | 玩家已有天赋 |
| 势力 | object | 可修改 | 玩家所属门派、帮会、世家、行伍等势力关系与状态 |

`状态效果`虽然会出现在当前变量中，但它是前端临时增幅药系统的生效真值：使用药品时创建，玩家消息成功发送后递减，归零后删除。AI 不得直接新增、修改或删除，以免与前端重复结算。

### 初始属性

```json
{
  "初始属性": {
    "臂力": 0,
    "根骨": 0,
    "机敏": 0,
    "悟性": 0,
    "洞察": 0,
    "风姿": 0,
    "福缘": 0
  }
}
```

除明确允许的长期成长机制外，不要直接修改初始属性。

---

## 五、包裹

路径：

`user数据.包裹.【物品名】`

包裹中的物品只使用四种类型：

`装备 / 药品 / 秘籍 / 杂物`

所有物品都有以下基础字段：

- `类型`
- `品阶`
- `物品描述`
- `数量`

其中：

- 装备、药品、杂物品阶：`凡品 / 精品 / 珍品 / 极品 / 绝品 / 神品`
- 秘籍品阶：`粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说`

### 装备

```json
{
  "包裹": {
    "【装备名】": {
      "类型": "装备",
      "品阶": "【凡品 / 精品 / 珍品 / 极品 / 绝品 / 神品】",
      "物品描述": "【装备的材质、来历、特点或用途】",
      "数量": 1,
      "部位": "【武器 / 护甲 / 鞋履 / 饰品】",
      "属性修正": {
        "【臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力】": 0
      },
      "使用状态": ""
    }
  }
}
```

装备部位只允许：

`武器 / 护甲 / 鞋履 / 饰品`

`属性修正`只允许以下属性：

`臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力`

属性修正使用纯数字，表示百分比点。例如：

```json
{
  "属性修正": {
    "臂力": 10,
    "洞察": 5
  }
}
```

表示臂力增加 10%，洞察增加 5%。

不要使用：

`悟性 / 风姿 / 福缘 / 暴击 / 吸血 / 穿透 / 减伤 / 气血上限 / 内力上限`

`使用状态`只使用：

- `""`：未装备
- `"装备中"`：当前已装备

装备实际穿戴与卸下由前端维护，不要为了装备操作重复修改包裹或装备栏。

---

### 药品

```json
{
  "包裹": {
    "【药品名】": {
      "类型": "药品",
      "品阶": "【凡品 / 精品 / 珍品 / 极品 / 绝品 / 神品】",
      "功效类型": "【回复 / 临时增幅 / 永久增幅 / 特殊】",
      "物品描述": "【药品的作用、限制及特点】",
      "数量": 1,
      "属性修正": {
        "【臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力】": 0
      },
      "持续时间": 0
    }
  }
}
```

药品功效类型只允许：

`回复 / 临时增幅 / 永久增幅 / 特殊`

不同功效类型使用不同字段：

| 功效类型 | 属性修正 | 持续时间 | 说明 |
|---|---|---|---|
| 回复 | 必须 | 不使用 | 恢复当前气血或内力 |
| 临时增幅 | 必须 | 必须 | 在限定时间内提高属性 |
| 永久增幅 | 必须 | 不使用 | 永久改变人物根基 |
| 特殊 | 不使用 | 不使用 | 解毒、醒神、龟息、易容、假死、避瘴等叙事效果 |

`属性修正`只允许：

`臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力`

`持续时间`使用数字，单位固定为“时”。

叙事中可以称为丹药、药散、药酒、膏药、灵果、解药等，但变量中的 `类型`统一写为：

`药品`

不同功效类型不要强行补入不属于自身结构的字段。

---

### 秘籍

```json
{
  "包裹": {
    "【秘籍名】": {
      "类型": "秘籍",
      "品阶": "【粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说】",
      "物品描述": "【秘籍的载体、来历及所载武学说明】",
      "数量": 1
    }
  }
}
```

秘籍品阶必须使用功法品阶：

`粗浅 / 传家 / 上乘 / 镇派 / 绝世 / 传说`

秘籍只是功法载体，不写：

`属性修正 / 部位 / 使用状态 / 持续时间 / 功效类型 / 参悟条件`

能够直接学习的秘籍应对应一门功法。  
残页、拓片、线索等不能直接学习的物品，应归为 `杂物`。

---

### 杂物

```json
{
  "包裹": {
    "【物品名】": {
      "类型": "杂物",
      "品阶": "【凡品 / 精品 / 珍品 / 极品 / 绝品 / 神品】",
      "物品描述": "【物品的用途、来历、身份意义或剧情作用】",
      "数量": 1
    }
  }
}
```

杂物包括：

信物、材料、财货、工具、残页、地图、任务物品及其他不直接参与属性结算的物品。

杂物不写：

`属性修正 / 部位 / 使用状态 / 持续时间 / 功效类型`

## 六、角色数据

路径：

`角色数据.【人物名】`

不存在的人物可以新增完整人物对象；已经存在的人物，只处理实际发生变化的字段。

除人物共有字段外，NPC 还拥有以下差异字段：

| 字段 | 类型 | 权限 | 内容 |
|---|---|---|---|
| 性格 | string | 仅添加 | 稳定性格特征 |
| 初始属性 | object | 仅添加 | NPC 基础五维属性 |
| 重要物品 | object | 可修改 | 对该 NPC 具有长期意义的重要持有物 |

### NPC 初始属性

```json
{
  "初始属性": {
    "臂力": 0,
    "根骨": 0,
    "机敏": 0,
    "悟性": 0,
    "洞察": 0
  }
}
```

NPC 的 `初始属性` 与玩家不同，不包含：

`风姿 / 福缘`

NPC 的 `属性`结构与玩家相同：

```json
{
  "属性": {
    "气血": "当前气血/气血上限",
    "内力": "当前内力/内力上限",
    "臂力": 0,
    "根骨": 0,
    "机敏": 0,
    "洞察": 0
  }
}
```

其中 `气血 / 内力`为完整的 `当前值/上限值`，其余四项为单一战斗属性数值。

---

        "根骨": 0,

        "悟性": 0,
        "洞察": 0
      },
      "属性": {
        "气血": "当前值/上限值",
        "内力": "当前值/上限值",
        "臂力": 0,
        "根骨": 0,
        "机敏": 0,
        "洞察": 0
      },
      "出生年份": 0,
      "状态": "【当前具有长期意义的状态】",
      "所在位置": "一级/二级/三级[/四级]",
      "身份": {
        "【身份名】": "【说明】"
      },
      "功法": {
        "【功法名】": {

### 重要物品

```json
{
  "重要物品": {
    "【物品名】": "【该物品与人物或剧情的长期意义】"
  }
}
```

普通消耗品、短暂持有物不必记录为重要物品。

## 七、写入边界

本模板只描述可写结构，不代表每回合都应更新这些字段。

应优先保存：

- 长期状态变化
- 武学获得、失去或修习进展
- 身份、师承、阵营变化
- 重要物品得失
- 稳定关系变化
- 长期地点变化
- 具有长期意义的人物经历
- 实际偏离原定发展的参与事件结局

不要仅为了补全变量而创建正文中没有发生的事实。
