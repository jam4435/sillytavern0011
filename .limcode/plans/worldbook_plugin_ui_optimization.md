# 世界书编辑脚本插件前端美观优化计划

## 1. 目标

针对 `src/世界书编辑脚本` 目录下的世界书编辑插件，在**不涉及功能改动**、**影响最小化**的前提下，对其所有页面和窗口进行完整的前端美观优化。

## 2. 原则

*   **美观优先**：提升整体视觉体验，包括色彩搭配、间距、排版、交互反馈等。
*   **不涉及功能改动**：绝对不修改任何现有的业务逻辑、API 调用和数据处理。
*   **影响最小化**：
    *   优先通过修改 CSS 样式 (`theme.js`, `panel.js` 中的内置样式，以及其他含有 CSS 的文件) 来实现。
    *   如果必须修改 HTML 结构，只做微调（例如增加必要的 wrapper div），不破坏原有的 DOM ID 和 Class 绑定。
    *   保持与酒馆 (SillyTavern) 整体风格的协调。
    *   兼容移动端和 PC 端。

## 3. 优化范围

基于架构文档和代码分析，优化范围包括：

1.  **主面板 (`panel.js`)**
    *   整体布局、背景、边框、圆角。
    *   标题栏 (Header)：包含标题、按钮（主题设置、最小化、关闭）。
    *   标签页 (Tabs)：角色世界书、全局世界书、AI 修改。
    *   内容区域 (Content Area)：列表、分隔线、滚动条。
2.  **条目列表与项 (`panel.js`, `entry.js`)**
    *   条目项 (Entry Item) 整体样式：背景、边框、Hover 效果、激活状态。
    *   条目头部 (Entry Header)：标题、常量开关、位置选择、深度/顺序/概率输入、操作按钮（复制、删除、展开）。
    *   条目展开区域 (Entry Expand Area)：内容输入、关键字输入、逻辑选择。
    *   表头 (Table Header)：PC 端的列标题布局。
    *   拖拽排序 (Drag & Drop)：占位符样式。
3.  **主题设置模态框 (`theme.js`)**
    *   整体样式、标题、关闭按钮。
    *   颜色选择器、开关 (Toggle Switch)、选择框。
4.  **其他浮层/弹窗 (`panel.js`, `aiActionDialog.js`, `aiWorkspace.js`, `largeContentPreview.js` 等)**
    *   批量操作下拉菜单。
    *   复制条目模态框。
    *   悬浮气泡 (Floating Bubble)。
    *   AI 相关弹窗/工作区 (需要进一步检查 `ui/ai*.js` 的样式)。
    *   长内容预览弹窗。

## 4. 具体优化方案 (CSS/样式层面)

### 4.1 整体色彩与材质

*   **统一暗黑主题基调**：现有的默认颜色虽然是暗色，但可以更精致。
*   **增加微小透明度/毛玻璃 (可选)**：如果酒馆支持或不影响性能，可以为面板背景添加轻微的 Backdrop-filter。
*   **边框与阴影**：统一边框颜色 (如 `#444`) 和稍微柔和的阴影 (`box-shadow: 0 8px 30px rgba(0,0,0,0.6)`，而非硬朗的黑影)。
*   **圆角**：统一使用略大一点的圆角 (如 `border-radius: 12px` 用于主面板，`8px` 用于内部元素)，看起来更现代。

### 4.2 字体与排版

*   确保使用系统默认或与酒馆一致的字体栈。
*   增加适当的行高 (`line-height`) 提高可读性。
*   通过字号大小和粗细对比，强化层级关系 (如条目标题更显眼，次要信息变淡)。

### 4.3 交互反馈 (Hover / Active)

*   **按钮**：所有可点击元素都应有清晰的 hover 状态（改变背景色、亮度或增加微弱的放缩 `transform: scale(1.02)`，但要小心不要引起抖动）。
*   **输入框/下拉框**：Focus 时提供明显的边框高亮或发光效果 (Glow)。
*   **条目悬停**：当鼠标悬停在列表项时，背景色微微变亮，同时右侧的操作按钮浮现或变得更清晰。

### 4.4 具体模块优化细节

#### 4.4.1 主面板 (`#lorebook-panel`)
*   **Header**：增加内边距，使标题看起来不拥挤。右侧控制按钮（最小化、关闭）增加统一的圆形 hover 区域。
*   **Tabs**：去掉传统的底部粗线，改用类似“药丸” (Pill) 风格的切换，或者更现代的带有背景滑动动画的标签页设计（如果单纯用 CSS 好实现的话）。当前使用下划线也可以，但增加过渡动画。
*   **Scrollbar**：自定义滚动条样式，使其更细、更符合暗黑主题（半透明灰色轨道，深灰色滑块）。

#### 4.4.2 条目样式 (`.lorebook-entry`)
*   **间距**：稍微增加条目之间的 `margin-bottom`，以及内部元素的 `padding`。
*   **头部布局**：优化各种小输入框和按钮的对齐方式，目前略显拥挤。可以利用 `flex-gap` 替代 `margin`。
*   **微型输入框**：为常量、位置、深度等设置更统一的高度和微小的圆角。
*   **展开区域**：背景色与头部做轻微区分（更深一点），形成内嵌的视觉效果。输入框（内容、关键字）移除默认 border，使用带背景色和底部 border 或 focus 发光的现代设计。

#### 4.4.3 开关 (Toggle Switch)
*   优化当前的 iOS 风格开关，使其更圆润、过渡更平滑。

#### 4.4.4 模态框 (Modals)
*   **遮罩层**：确保背景遮罩颜色一致 (`rgba(0,0,0,0.6)` 到 `0.8`)。
*   **弹窗本体**：增加进场动画（如从下方轻微滑入、透明度渐变）。
*   **表单**：统一表单元素的高度，对齐 label 和 input。

#### 4.4.5 悬浮气泡
*   增加呼吸动画或更平滑的拖拽反馈，添加一点渐变色使其更有立体感。

## 5. 实施步骤

1.  **审查所有 UI 组件的现存 CSS**：主要集中在 `panel.js` 的 `panelStyles` 字符串中，以及可能存在的其他 UI 文件的独立样式中。
2.  **重构/提炼 CSS 变量**：在 `:root` 或面板根节点进一步完善 CSS 变量体系，方便统一调整间距、圆角和阴影。
3.  **分阶段应用样式修改**：
    *   阶段一：主面板布局、Header、Tabs、滚动条。
    *   阶段二：列表项 (Entry)、内部表单控件、开关、按钮交互。
    *   阶段三：模态框、悬浮球、下拉菜单等附属组件。
    *   阶段四：移动端适配 (Media Queries) 的样式微调。
4.  **测试与回归**：在浏览器中加载插件，验证各种状态下（深/浅色主题如果有、不同布局模式、移动端/PC端）的视觉表现，确保**无任何功能损坏**，且点击区域、滚动等交互正常。

## 6. 风险评估与对策

*   **CSS 特异性冲突**：酒馆本身或其它插件可能影响本插件样式。
    *   *对策*：尽量使用带有插件专属 ID (如 `#lorebook-panel`) 的高优先级选择器，或者适当使用 `!important` 保护关键样式。
*   **虚拟滚动 (`Clusterize.js`) 布局错乱**：修改条目高度或 `padding/margin` 可能影响虚拟滚动的高度计算。
    *   *对策*：仔细测试滚动行为，若有必要，在不改变整体高度的前提下通过修改内部 padding/line-height 来优化；或在改动后确保容器高度正确自适应。
*   **破坏现有 HTML 结构导致 JS 报错**：
    *   *对策*：严格禁止删除或修改 `id` 和 `data-*` 属性。尽量纯 CSS 解决，不碰 JS 生成的 HTML 字符串结构；除非极度需要（例如为了做更美观的 Flex 布局必须套一个 `div`），才小心修改 HTML。
