# 武侠世界观体系与设定规范

> 适用范围：角色卡数据构建、人物登场/成长设计、事件编写、装备物品生成及 LLM 叙事标尺。  
> 核心原则：**机制交予前端，叙事交予大模，数据遵循规范，杜绝数值失衡与战力崩坏。**

---

## 一、体系总览与设计理念

1. **前后端与 LLM 职责分离**
   - **前端职责**：负责全部数值运算（气血/内力计算、战力加权、境界系数缩放、装备百分比折算、功法特性补全、晋升与突破消耗）。
   - **LLM / 变量职责**：只做离散化、轻量级的状态与事实记录（如人物境界名、功法掌握程度、当前所在位置、装备穿戴状态），严禁在正文或变量中手算复杂衍生数值。
2. **轻量变量与数据库补全**
   - 角色卡维护内置静态数据库（功法库、境界库、物品库、地图库）。
   - 运行时或事件中只需记录核心键（如 `"功法": { "降龙十八掌": { "掌握程度": "融会贯通" } }`），其余属性系数与特性由前端自动检索补全。

## 二、境界与修为体系架构

### 2.1 境界划分与阶位
武林境界分为 **7 大境界**，除不入流外，每个大境界细分 **4 个小境界**：

- **不入流**：寻常武夫、未得真传者，无小境界划分。
- **三流（初期 / 中期 / 后期 / 圆满）**：初入江湖，打通基础经脉，身手优于常人。
- **二流（初期 / 中期 / 后期 / 圆满）**：一地好手，内力小成，已有独当一面的实力。
- **一流（初期 / 中期 / 后期 / 圆满）**：名门精锐、江湖成名高手，内力深厚。
- **宗师（初期 / 中期 / 后期 / 圆满）**：开山立派之辈，武学融会贯通，登堂入室。
- **绝顶（初期 / 中期 / 后期 / 圆满）**：天下五绝、一派至尊，站在时代巅峰。
- **陆地神仙（初期 / 中期 / 后期 / 圆满）**：近乎神话的传奇人物（如达摩、张三丰）。

### 2.2 境界定位与战力乘数机制
- **境界是绝对基石**：境界代表内力深浅与生命层次的本质差距。低境界即使掌握神功，在绝对境界压制面前也难以正面匹敌。
- **境界保底机制**：前端对每个境界设定了基础气血、内力与属性保底。即便角色没有录入内功，系统也会自动根据其境界提供对应档位的基准战力与续航，因此无内功描写的角色**严禁脑补杂牌内功**。

## 三、人物属性规则与分配规范

<属性规则>

### 3.1 属性定义
人物基础天赋由五维构成：
- **臂力**：物理力量、负重与刚猛招式伤害。
- **根骨**：气血上限、经脉强度、体质与抗击打能力。
- **机敏**：身法速度、闪避身法与先手反应。
- **洞察**：观察力、破绽捕捉、招式拆解与命中率。
- **悟性**：武学领悟能力、招式进阶速度与破解玄机。

### 3.2 数值范围与等级描述

| 数值范围 | 等级描述  | 适用角色                          |
| :------- | :-------- | :-------------------------------- |
| 0 - 4    | 愚钝/残缺 | 有明显缺陷的角色、普通百姓的弱项  |
| 5 - 8    | 普通      | 普通人、配角、低阶弟子            |
| 9 - 12   | 人才      | 有一定天赋的角色                  |
| 13 - 16  | 天才      | 主要角色、门派高手                |
| 17 - 20  | 妖孽      | 顶尖高手、主角（仅限最突出的1项） |

### 3.3 属性分配核心原则（⚠️ 突出差异化，避免平均化）

1. **拉开差距**：每个人物的最高属性与最低属性之间差距**至少 5 点，最好 8 点以上**。绝不允许五项属性差距在 3 点以内。
2. **压低整体**：属性代表天赋，大多数人只在 1~2 项上突出，其余应偏低。普通人平均值应在 5~7，江湖好手平均值在 8~10，只有绝世高手平均值才能到 13 以上。
3. **突出特色**：根据人物性格和原著描写，选定 1~2 项作为突出属性（高于其他项 5 点以上），其余属性应明显偏低。
4. **17~20 极少使用**：只有主角或绝世高手的最突出单项才能达到 17+。

### 3.4 参考示例

- **普通农夫/百姓**：`臂力8, 根骨7, 机敏4, 洞察3, 悟性3`（平均 5，差距 5）
- **普通门派弟子（三流）**：`臂力9, 根骨8, 机敏6, 洞察5, 悟性4`（平均 6.4，差距 5）
- **江湖好手（二流）**：`臂力12, 根骨10, 机敏7, 洞察5, 悟性6`（平均 8，差距 7）
- **门派精英（一流）**：`臂力8, 根骨14, 机敏6, 洞察12, 悟性9`（平均 9.8，差距 8）
- **郭靖（天赋愚钝但根骨极佳）**：`臂力10, 根骨14, 机敏6, 悟性5, 洞察8`（差距 9）
- **杨过（天资聪颖但年幼体弱）**：`臂力4, 根骨12, 机敏16, 悟性18, 洞察14`（差距 14）
- **黄蓉（绝顶聪明但体质一般）**：`臂力5, 根骨7, 机敏17, 悟性16, 洞察15`（差距 12）

❌ **错误示例（绝对禁止）**：
- `臂力12, 根骨13, 机敏14, 洞察14, 悟性13` —— 差距仅 2 点，过于平均。
- `臂力9, 根骨11, 机敏9, 悟性10, 洞察9` —— 不入流角色属性虚高且差距仅 2 点。

</属性规则>

## 四、功法体系与轻量化填写规范

<功法规则>

### 4.1 功法体系结构
- **功法分类**：内功、外功、轻功、武技（细分为：剑法 / 刀法 / 拳掌 / 指法 / 暗器 / 枪戟 / 棍锤）。
- **功法品阶（6 级）**：`粗浅 → 传家 → 上乘 → 镇派 → 绝世 → 传说`。
- **品阶决定特性数量**：
  - 粗浅（0 特性）
  - 传家（1 特性：出神入化解锁）
  - 上乘（2 特性：炉火纯青、出神入化解锁）
  - 镇派（3 特性：融会贯通及以上解锁）
  - 绝世（4 特性：略有小成及以上解锁）
  - 传说（5 特性：各层级均有专属特性）
- **掌握程度（5 级）**：
  `初窥门径 → 略有小成 → 融会贯通 → 炉火纯青 → 出神入化`

### 4.2 角色卡变量填写核心原则
1. **无功法角色**：普通人可直接填空对象 `{}`。
2. **只有武技的角色**：只填武技，严禁凭空补充内功。
3. **高境界但无内功描写**：无需补充内功，前端会自动应用境界保底属性。

### 4.3 示例代码
```json
// 1. 普通村民
"功法": {}

// 2. 只会枪法的好汉
"功法": {
  "杨家枪": { "掌握程度": "略有小成" }
}

// 3. 欧阳锋（只填写核心招牌，其余依此类推）
"功法": {
  "蛤蟆功": { "掌握程度": "出神入化" }
}
```

</功法规则>

## 五、物品与行囊体系架构

### 5.1 四大物品类型
- **装备**：穿戴后提供百分比属性修正，不消耗数量。分为 4 个部位：`武器 / 护甲 / 鞋履 / 饰品`。
- **药品**：消耗后生效，包含 4 种功效类型：`回复 / 临时增幅 / 永久增幅 / 特殊`。
- **秘籍**：功法载体，持有即可参悟，**不直接填写属性修正**（属性与特性完全绑定功法数据库）。
- **杂物**：信物、材料、财货、残页、令牌、任务工具，仅承载剧情效力，不参与属性结算。

### 5.2 属性修正规则
- **统一百分比点**：属性修正纯写数字，单位为百分比（如 `10` 代表 `+10%`，严禁写成 `"10%"` 或 `0.1`）。
- **合法词条限制**：仅允许 `臂力 / 根骨 / 机敏 / 洞察 / 气血 / 内力`。禁止出现暴击、吸血、悟性、风姿等未接入系统词条。

## 六、各类品各品阶的叙事表现力标尺

> 在大模型生成正文或撰写事件时，必须严格对照此标尺，防止笔力失控、战力膨胀或修仙化。

### 6.1 人物境界表现力

| 境界 | 叙事表现标尺 |
| :--- | :----------- |
| **不入流** | 受过基础训练，仍属常人范畴，严重依赖体力、合手兵器与人数优势；面对江湖好手毫无招架之力。 |
| **三流** | 正式迈入江湖，身手敏捷、气力充沛，能稳定击败普通壮汉，可应付数名寻常匪徒。 |
| **二流** | 一地好手、门派中坚；内力、轻功或成名招式已有显著威力，能在地方江湖立足扬名。 |
| **一流** | 江湖成名高手，内力深厚，招式精微，可随心压制多名低阶武者，往往担任门派堂主、长老或掌门。 |
| **宗师** | 具备开宗立派的武学见识，技法、心法与内力形成完整自洽体系，飞花摘叶皆可伤人。 |
| **绝顶** | 一个时代的武林泰斗（如天下五绝），寻常一流高手难以依靠人数取胜，举手投足牵动武林大势。 |
| **陆地神仙** | 武道化境的传奇人物。**写实限定**：依然受人体、地形、耐力与因果约束，绝非神仙，**严禁描写为飞升、元神出窍、时间凝固或撕裂虚空**。 |

### 6.2 功法品阶表现力

| 品阶 | 稀有范围 | 叙事表现标尺 |
| :--- | :------- | :----------- |
| **粗浅** | 市井、门派制式 | 市井拳脚、军中散手、入门口诀。招式实用、直白，但变化极其有限，破绽明显，后劲不足。 |
| **传家** | 地方良品、家族私藏 | 小门派核心或家族不传之秘。有一项扎实的长处与清晰路数，防守稳健，但在大派绝学前稍显平庸。 |
| **上乘** | 知名大派、江湖成名技 | 名门高阶武学。专精鲜明，威力强劲，是二流迈入一流的根基；但往往也有明显的心性门槛或招式短板。 |
| **镇派** | 泰斗名门核心绝学 | 大门派最高完整传承（如武当太极、丐帮打狗棒）。体系圆融无碍，几无短板，威震江湖。 |
| **绝世** | 天下顶尖神功 | 凤毛麟角的旷世神功（如易筋经、九阳神功、独孤九剑）。拥有颠覆战局的独特机制，足以引发江湖血雨腥风。 |
| **传说** | 时代级遗留武学 | 传闻残卷（如太玄经、战神图录）。完整形态足以重塑武林格局，但仍立足于内力、经脉与物理招架，不可玄幻修真化。 |

### 6.3 功法掌握程度表现力

| 掌握程度 | 熟练度描绘与临敌表现 |
| :------- | :------------------- |
| **初窥门径** | 仅能勉强使出基本套路架势，出招生硬、衔接迟滞，面临突发变故时容易手忙脚乱。 |
| **略有小成** | 能稳定运用主要招式与基础内劲，已有一定临敌威力，但临场应变仍显机械死板。 |
| **融会贯通** | 能在生死实战中灵活组合招式，变招自如，并能利用地形与周遭环境弥补招式缺陷。 |
| **炉火纯青** | 招式出神入化近乎身体本能，能充分发挥功法的精微奥妙，核心威力尽显无遗。 |
| **出神入化** | 彻底洞悉武功精髓，得其意而忘其形，因人、因地、因势随意变化，化腐朽为神奇。 |

### 6.4 物品品阶表现力

| 品阶 | 对应稀有度 | 叙事表现标尺 |
| :--- | :--------- | :----------- |
| **凡品** | 市井常见 | 寻常铁匠打造或市井制式草药，实用但材料普通、带有磨损与瑕疵，**严禁描写神异光泽**。 |
| **精品** | 匠人精制 | 经过精心锻打或名医配制，有一处明确优点、良好手感或清晰的产地来历。 |
| **珍品** | 一地闻名 | 采用稀有矿脉、名匠锻造或大派秘方，外观有鲜明印记与可辨识特征，江湖中少量流通。 |
| **极品** | 大派珍藏 | 名宿珍藏、江湖难求，带独特锻造风格与战斗异象，通常伴随佩戴门槛、特定反噬或代价。 |
| **绝品** | 名动天下 | 屈指可数的传世神兵与圣药（如软猬甲），附带深厚的历史江湖声望，能直接影响旁人对角色的态度。 |
| **神品** | 举世唯一 | 时代级至宝与不可复制的奇物（如倚天屠龙、大还丹）。出世必伴随天地异象或重大江湖争端，必须写清约束与剧情后果。 |

### 6.5 物品大类的表现边界
- **装备**：表现为材质质感、锻造工艺、流派契合度与辨识度，不具备自主意识与玄幻神通。
- **药品**：表现为药香、药理、见效速度、风险及取得难度；高品阶药品亦非万能，不可无条件起死回生。
- **秘籍**：只作为武学书卷载体（绢帛、羊皮、线装本、残卷），其神异体现在文字图解所载的高深法门。
- **杂物**：表现为材质特殊性、信物权威、交易价值或特定机关剧情钥匙，严禁附带战斗数值。

## 七、地理层级结构与命名规范

### 7.1 层级结构（3~4 级静态物理层级）

地点必须采用**斜杠 `/` 分隔的 3~4 级静态物理路径**：

- **第 1 级：国家、政权或宏观世界大域**（如 `大宋`、`大金`、`大理国`、`蒙古`、`西夏`）。
- **第 2 级：省府、山脉水系或府县城镇**（如 `临安府`、`直隶省`、`北京城`、`终南山`、`无量山`、`嘉兴府`）。
  - ⚠️ **规范重点：省府与城镇合并为一级，不重复叠层**（例如写作 `大宋/临安府` 或 `大清/北京城`，严禁写成 `大宋/两浙路/临安府/杭州城`）。
- **第 3 级：门派、庄所、建筑府邸、严格活动区**（如 `牛家村`、`曲三酒馆`、`剑湖宫`、`皇宫`、`重阳宫`、`归云庄`）。
  - ⚠️ **规范重点**：前三级为项目地图与世界观的**严格活动区**，属于系统白名单范围，严禁模型随意杜撰。
- **第 4 级（可选）：具体建筑内部或微场景**（如 `尚膳监`、`曲三酒馆`、`比剑大厅`、`后山密洞`、`柴房`）。
  - 用于正文镜头焦点的微移动，不计入全局大地图寻路白名单。

### 7.2 核心要求
1. **静态物理空间/实体载体**：地点必须是明确存在的物理场所，严禁使用事件名、心理状态、剧情概念充当地点（❌ 错误：`临安府/遭遇刺客`、`华山/论剑现场`）。
2. **场景一致性与面对面规则**：只有第 4 级场景完全相同，人物才算处于同一现场；前三级相同仅代表处于同一宏观活动区，不代表面对面同场。

### 7.3 典型规范示例

- **4 级标准格式**：
  - `大清/北京城/皇宫/尚膳监`
  - `大宋/临安府/牛家村/曲三酒馆`
  - `大理国/无量山/剑湖宫/后山密洞`
- **3 级标准格式**：
  - `大理国/无量山/剑湖宫`
  - `大宋/终南山/重阳宫`
  - `大宋/临安府/牛家村`
