## 6. 统一事件模板

每个独立节点至少记录：

- 本地事件 ID；候选链标签（可选）
- 作品、章回/标题、原文起止行号、可回查锚点
- 事件名称、具体经过、地点、人物及其角色
- **发生时间**与**揭露时间**分开记录
- 前置事件、后续影响
- 事实性质：原文叙述 / 人物自述 / 转述或传闻 / 推断 / 待核
- 现有世界书正文差分及实际检查过的文件路径
- 跨书关联、待核事项

不确定的字段写“原文未明示/待核”，不得为了填字段而补造年份、地点、动机、血缘或顺序。相识、拜师、婚姻、背叛、出生、失散、死亡、隐瞒、揭露、传承等通常应拆成多个可连接节点，不要压缩成背景简介。

## 7. 差分六分类

1. 缺独立历史节点
2. 只有讲述/揭密场景
3. 只有最终结果，缺前因或过程
4. 部分已有，列清已覆盖与缺失节点
5. 完整记录，无需重复
6. 待核，证据不足

必须检查相关条目的正文，尤其事件详情、概要、后续事件、参与人物及适用的差分字段。关键词命中、看到标题、知道有条目都不算完成差分。

## 8. 批次保存与进度状态

每个执行窗口开始时先创建并保存三份 Markdown 文件：事件记录、逐章扫描日志、世界书正文差分。每完成一章或一批历史线立即更新文件，不能只留在聊天里。

状态含义：
- `未开始`：尚未阅读。
- `已定位`：只找到标题/关键词，不等于读过。
- `已阅读`：正文已完整扫描。
- `已提取`：已形成事件记录或写明排除理由。
- `已差分`：已检查实际世界书正文。
- `已复查`：完成遗漏复查并记下疑点。
- `已交付`：三份文件已保存并回交主窗口。
- `待核`：证据不足或存在矛盾。

逐章日志至少记录：作品、章节标题、行号起止、状态、已提取本地 ID、已检查的世界书正文文件、待核事项、下一步起点。
