### 事件拆分原则

1.  **发生时间与揭露时间分开**：某人在主线中讲述旧事，不代表旧事发生在讲述当天。
2.  **关系先于结果**：先建立相识、师承、婚姻、师门冲突等前因，再记录背叛、死亡、失散、复仇等结果。
3.  **一个节点只记一件主要变化**：例如"盗经---出逃---修炼---同门受罚---陈玄风死亡"应拆成多个有因果关系的节点。
4.  **跨书共用历史节点**：同一事件在不同小说中被回忆时，应指向同一个历史事件，而不是复制出两条互相矛盾的记录。
5.  **未知就保留未知**：原文未给出精确年月、地点、人物动机或亲缘关系时，不自行补造。
6.  **已有讲述事件不等于历史事件已经建档**：保留现有"讲述/揭密"场景；若旧事本身没有独立节点，再补历史节点。
7. **人物称谓按原文**：不以通行整理名替代原文。本文统一将画像中的人物写作“李秋水之妹（原文未名）”；黄药师之妻按原文称“黄夫人/冯氏/阿衡”，不将“李沧海”“冯衡”当作原文明确给出的姓名。

### 状态说明

-   **缺独立历史节点**：事件树中没有发现以该段过去事件为核心的独立事件标题。
-   **已有讲述或结果节点**：已有条目记录回忆、揭密或后果，但不等于历史发生过程已经拆分。
-   **部分已有**：部分实际事件已存在，后续只补缺失节点，不重复生成。
-   **待核原文细节**：主链可以识别，但精确时序、地点或某项关系仍须回到原文相邻段落核实。

**原文定位：** 第三十二回、第三十五至三十七回。

8.

## 三、《射雕英雄传》

### SD-01 黄裳遭遇仇杀与创作《九阴真经》

**原文定位：** 第十六回《九阴真经的由来》。

节点序列： 1. 黄裳因校勘道藏而接触道家典籍，并在过程中形成高深武学修为。
2. 他因与明教的冲突而遭遇报复，家人被害。 3.
黄裳退隐多年，研究敌手武功，试图找到破解之法。 4.
他将长期研究整理为《九阴真经》。 5.
真经问世后成为江湖争夺的核心，继续引发多代人物的冲突。

**差分判断：**
现有"九阴真经的由来"条目将多段经历压在一个事件中；应拆成"家人遭害---退隐复仇---创作真经---真经流传"等独立历史节点。

### SD-02 五绝争经与王重阳取得真经

**原文定位：** 第十六至十七回相关叙述。

节点序列： 1. 《九阴真经》引发武林高手争夺。 2.
五绝在华山论剑中争夺真经归属。 3. 王重阳胜出，取得真经，以平息武林纷争。
4. 王重阳去世后，欧阳锋企图趁机夺经。 5.
王重阳留下后手，重创欧阳锋；这场冲突影响了后续西毒与真经的历史。 6.
周伯通奉师兄遗命保管真经，开启下一段传承链。

**差分判断：**
当前条目提到华山论剑与欧阳锋夺经，但不应把争经、王重阳的安排、周伯通接手等多个历史节点混成一个。

### SD-03 周伯通、黄夫人与经文记忆

**原文定位：** 第十六至十七回相关叙述。

节点序列： 1. 周伯通携真经离开原有地点，试图隐藏经书。 2.
他与黄药师及黄夫人相遇，经书因一段约定而落到黄夫人手中。 3.
黄夫人凭借过目不忘的本领记住经文。 4.
真经原本与记忆下来的经文开始分离，形成后续争夺与误会。 5.
黄夫人去世后，黄药师的态度和桃花岛的师门关系发生变化。

**差分判断：**

**差分判断：**

### YT-09 成昆潜伏与六大门派围攻明教

## 六、《笑傲江湖》

### XAJ-01 《葵花宝典》的流传、误读与焚毁

**原文定位：** 第三十回《密议》。

节点序列： 1. 一名身份不详的前朝宫廷宦官创作《葵花宝典》。 2.
百余年前，宝典流入福建莆田少林寺，红叶禅师保管此书。 3.
华山弟子岳肃、蔡子峰前往莆田，私下阅读宝典。 4.
二人来不及通读全书，各自记下不同部分，回华山后发现两部分无法互相印证。
5. 两人对彼此产生怀疑，宝典的误读成为华山分裂的重要起点。 6.
红叶禅师得知私阅之事，派渡元禅师前往华山劝阻。 7.
渡元禅师从岳、蔡二人口述中记下部分武学，后来还俗。 8.
红叶禅师临终前焚毁原书，避免危险武学继续流传。

**差分判断：**
现有"密议"场景会讲述这段历史，但尚未发现独立拆分宝典创作、流传、私阅、误读、渡元离寺与原书焚毁的历史节点。

### XAJ-02 华山气宗、剑宗分裂与内斗

**原文定位：** 第十一回及第三十回。

节点序列： 1. 岳肃、蔡子峰分别记住《葵花宝典》的不同部分。 2.
两人对武学理解无法互相印证，逐渐形成各自的主张。 3.
华山派因此分为气宗与剑宗，内部争执持续多年。 4.
两宗最终发生武力冲突，剑宗失败并退出华山。 5.
二十五年前的宗门斗争改变了华山派的传承结构，后续掌门争夺一直受到影响。

**差分判断：**
需要把"宝典误读"和"宗门武力分裂"建成相连但不同的事件，不把数十年争斗压成一句背景。

### XAJ-03 渡元禅师、林远图与《辟邪剑谱》的形成

**原文定位：** 第三回、第三十回。

节点序列： 1. 渡元禅师奉红叶禅师之命前往华山，劝阻岳肃、蔡子峰修炼宝典。
2. 渡元从二人讲述中记下部分武学，却没有返回莆田少林寺。 3.
渡元还俗，改以林远图的身份行走江湖。 4.
林远图整理记忆中的武学，形成《辟邪剑谱》相关传承。 5.
林远图建立福威镖局，武学秘密进入林氏家族。 6.
后代林家保留剑谱，却未必掌握其真正修炼方法，最终为后续灾祸埋下伏笔。

**差分判断：**
未发现以林远图身世、还俗与剑谱形成过程为核心的独立历史节点。

### XAJ-04 林远图与青城派长青子的旧怨

**原文定位：** 第三回《救难》。

节点序列： 1. 长青子年轻时挑战林远图，败于辟邪剑法。 2.
长青子长期无法释怀，形成青城派对林氏的旧怨。 3.
长青子去世前留下与福威镖局相关的怨念或安排。 4.
余沧海继承师门旧怨，后来针对林家采取行动。 5.
青城派与福威镖局的冲突由此跨越数十年。

**差分判断：**
现有事件有余沧海袭击福威镖局等主线场景；长青子战败与旧怨传承应独立建档。

### XAJ-05 风清扬错过华山剑气之争

**原文定位：** 第八至十回有关风清扬的叙述。

节点序列： 1. 风清扬属于华山剑宗一脉。 2.
华山两宗发生决战前，风清扬被安排离开华山，未能参与关键冲突。 3.
风清扬返回后，剑宗已败并被逐出华山。 4.
风清扬对师门结果深感遗憾，选择隐居，不再介入华山日常事务。 5.
他后来将独孤九剑传给令狐冲，使旧一代宗门斗争影响到新一代人物。

**差分判断：**
风清扬传剑是主线事件；错过决战、剑宗失败与隐居的历史原因应单独记录。

### XAJ-06 任我行被东方不败夺权并囚禁

**原文定位：** 任我行重返江湖后的相关回忆与揭露。

节点序列： 1. 任我行曾担任日月神教教主。 2.
东方不败由教中重要人物逐步获得权力。 3.
东方不败夺取教主之位，将任我行囚禁在西湖地牢。 4.
任我行长期失去自由，日月神教在东方不败掌权下改变权力结构。 5.
任我行后来脱困，旧日教主与新任教主的权力冲突重新爆发。

**差分判断：**
现有主线包括任我行脱困与重夺权力；夺权、囚禁与教中权力更替的实际过程应独立拆分。

### XAJ-07 林氏家族、福威镖局与剑谱继承

**原文定位：** 第三回、第五回、第三十回。

节点序列： 1. 林远图建立福威镖局并将相关武学传承留给家族。 2.
后代林家持有剑谱，却未完全理解其武学内涵。 3.
林震南继承家业，福威镖局在江湖上形成名声。 4.
余沧海与木高峰等人因剑谱与旧怨觊觎林家。 5.
林平之经历家族覆灭后进入华山派，剑谱秘密继续影响岳不群、令狐冲等人。

**差分判断：**
林家被袭与林平之入华山已有主线事件；林远图到林震南的家族传承链仍应单独建立，并关联
XAJ-03、XAJ-04。

## 七、《鹿鼎记》

### LD-01 庄廷鑨《明史》与文字狱

**原文定位：** 第一回《纵横钩党清流祸》。

节点序列： 1. 庄廷鑨得到朱氏遗稿，产生编撰明史的念头。 2.
庄家组织文人整理、增补并刊行相关史书。 3.
书中涉及明代政治与清朝相关禁忌，引起官府追查。 4.
文字狱扩大，庄家与参与编书的文人受到严重牵连。 5.
此案形成小说开篇的政治背景，也解释江南文人和反清势力的处境。

**差分判断：**
开篇事件可能已经覆盖此案的一部分；先对照现有开篇事件，不重复已有节点，只补正文缺失的因果环节。

### LD-02 顺治、董鄂妃与五台山出家之谜

**原文定位：** 第六回及宫廷秘密揭露相关章节。

节点序列： 1. 顺治与董鄂妃的感情关系影响宫廷政治。 2.
董鄂妃去世后，顺治的精神状态与皇位关系发生重大变化。 3.
顺治离开宫廷，隐居五台山并以僧人身份生活。 4.
宫中少数人物掌握其真实去向，相关秘密成为皇权内部的危险信息。 5.
康熙后来逐步接触这段秘密，父皇生死与宫廷旧案相互关联。

**差分判断：**
现有场景会揭露顺治出家等秘密；董鄂妃之死、离宫、隐居与秘密保守应分别作为历史节点。

### LD-03 明末败亡、李自成、吴三桂与陈圆圆

**原文定位：** 第三十二回及陈圆圆相关叙述。

节点序列： 1. 李自成起兵并与明朝官军长期冲突。 2.
李自成攻入北京，明朝覆亡。 3. 吴三桂与李自成、陈圆圆之间的关系发生冲突。
4. 吴三桂转而与清军合作，明末政治格局由此发生重大转变。 5.
陈圆圆长期被视为引发吴三桂降清的原因之一，但原文也呈现她对自身遭遇的解释与申辩。
6. 这段旧事影响九难、吴三桂及多名人物的后续行动。

**差分判断：**
小说中有重述这段历史的场景，但不应把明末政治事件与陈圆圆个人经历混为一个事件。

### LD-04 郑成功、郑经与台湾继承冲突

**原文定位：** 第二十九、第四十四回相关叙述。

节点序列： 1. 郑成功从荷兰势力手中夺取台湾，建立反清的重要据点。 2.
郑成功与儿子郑经因家庭与继承问题产生严重冲突。 3.
郑成功曾下令处置郑经，部将未完全执行，父子关系和军中权力受到影响。 4.
郑成功去世后，郑经回师台湾并取得延平王地位。 5.
郑经长子郑克臧与次子郑克塽的继承问题引发新的权力斗争。 6.
冯锡范等人支持郑克塽，陈近南因维护郑氏旧义与天地会利益而受到排挤。 7.
郑克塽最终暗算陈近南，台湾郑氏与天地会的关系破裂。

**差分判断：**
现有结局场景讲述了郑氏继承旧事并记录陈近南之死；郑成功的命令、郑经回台、郑氏内部继承斗争应拆成独立历史节点。

### LD-05 天地会的形成与郑氏抗清网络

**原文定位：** 吴六奇、查伊璜与天地会相关叙述。

节点序列： 1. 郑成功的抗清事业留下未能随军退回台湾的旧部与关系网络。 2.
陈永华以陈近南之名成为天地会的重要领袖。 3.
天地会联络旧部与各地反清人士，在福建、浙江、广东等地发展。 4.
天地会各堂口逐渐形成自身的组织结构与香主选任关系。 5.
天地会与台湾郑氏既有合作，也因权力与利益产生矛盾。 6.
陈近南的死亡成为天地会内部与郑氏关系的重大转折。

**差分判断：**
现有条目可能记录天地会人物的主线行动，但组织形成、地方网络与郑氏关系应建立为可被多条事件引用的历史链。

### LD-06 神龙教旧部、洪安通与苏荃

**原文定位：** 第十五、二十回相关叙述。

节点序列： 1. 神龙教早已有一批追随洪安通的旧部。 2.
洪安通掌权后，门内权力与待遇逐渐发生变化。 3.
洪安通迎娶苏荃后，更倾向提拔年轻男女，旧部受到排挤。 4.
部分旧部担心被清算，最终出现反叛与求生行动。 5.
洪安通利用毒药、惩罚和教主权威控制教众，门派内部关系持续恶化。

**差分判断：**
主线已有神龙教内斗场景；若要补建历史节点，应把旧部被排挤、权力集中与反叛原因分开，而不是只记最终冲突。

### LD-07 九难师太的身世与复仇道路

**原文定位：** 九难相关回忆及明末宫廷旧事。

节点序列： 1. 九难原有明朝公主身份，与明朝灭亡和宫廷灾难相连。 2.
她经历宫廷覆灭与亲人死亡后幸存。 3.
她以出家人的身份生活，将复仇与反清目标结合。 4.
她收授或影响后续人物，使明末旧怨延续到康熙时期。 5.
她与李自成、吴三桂等人的旧事在后续剧情中再次交汇。

**差分判断：**
需要把她的真实身份、逃生过程、出家与后续复仇分开；具体每个节点的细节按原文核验。

### LD-08 阿珂与陈圆圆的母女关系

**原文定位：** 陈圆圆向韦小宝解释身世的相关章节。

节点序列： 1. 陈圆圆经历明末战争与个人关系变动。 2.
陈圆圆生下阿珂，母女后来分离。 3.
阿珂在其他环境中长大，对自己的身世缺乏完整认识。 4.
陈圆圆后来向韦小宝说明自己是阿珂的母亲。 5.
阿珂的身世改变了她与陈圆圆、吴三桂及明末旧事的关系认知。

**差分判断：**
原文明确支持母女关系；父亲身份和具体受孕、送养过程如未在对应段落中明确说明，不应在事件记录中自行填入。

### LD-09 吴三桂、陈圆圆与反清政治叙事

**原文定位：** 第三十二回及陈圆圆的自述。

节点序列： 1. 陈圆圆与吴三桂建立关系。 2.
李自成攻入北京及相关冲突改变了吴三桂的政治选择。 3.
吴三桂与清军合作后，陈圆圆被卷入关于降清原因的长期争论。 4.

**差分判断：** 本链与 LD-03
有关联，但重点是陈圆圆个人经历及其在后世政治叙事中的角色；避免把人物自述直接当成全知视角的客观定论。
