# 事件链节奏归一审计

本表以 `src/事件脚本/generated/event-data/manifest.json` 中真实 `后续事件` 图为准，共审计 **930** 条边。

## 分类结果

- 连续：599
- 过渡：155
- 间歇：91
- 待人工确认：85
- 高置信自动调整候选：200
- 候选当前伪空隙合计：364 小时

## 归一原则

1. **连续**：A 的结束就是 B 的开始；高置信且无分支/汇合风险时，批量归零外部间隔。
2. **过渡**：赶路、等待、休息、短程移动等属于真实过程，保留现有过渡耗时。
3. **间歇**：真正自由行动期或长期跳转；作为时间锚点，不让前面连续链的压缩继续向后累积。
4. **待人工确认**：不自动改动。
5. 调整连续链时保持每个事件原有持续时长；只移动事件整体时间窗。
6. 一旦遇到过渡、间歇、待确认或分支/汇合节点，自动传播停止。
