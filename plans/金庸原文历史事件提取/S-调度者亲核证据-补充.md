# S7 · 康敏（马夫人）线的检索陷阱（调度者亲核）

## 现象
- `康敏` 在《天龙八部》全文命中 **1 次**（行 10233）。
- `马夫人` 命中 **240 次**（首现行 6259/6309/6315，末现行 18620）。
- 若按人名检索，整条「康敏陷害乔峰」链会被完全漏掉。

## 那唯一一次「康敏」出现的语境（行 10233）
小镜湖畔，秦红棉对阮星竹说：
> “现下我要去找那姓康的贱婢。你可知道她的所在？”
> 阮星竹：「那康……**康敏**这贱人，嗯，可不知在哪里。妹子找到了她，你帮我在她身上多刺几刀。」

→ 这里只交代了**两位受害者（秦红棉、阮星竹）对康敏的仇恨与寻仇意图**，
  并且明确「不知在哪里」——即康敏此时已失踪。

## 对提取工作的意义
1. 康敏线必须用「马夫人」检索，并同时注意「马大元之妻」「丐帮马夫人」等称谓。
2. 秦红棉、阮星竹对康敏的敌意是**另一条因果**（段正淳情史 + 康敏挑拨），
   与「康敏陷害乔峰」不是同一条链，不可混为一条。
   它属于「段正淳与多名女性的关系」大链（天龙第四十七回前后）。
3. 行 10233 同时是「阮星竹与阿朱、阿紫分离」的旁证：
   阮星竹原话「生了女儿不照看，任由我们娘儿俩孤苦伶仃的」。

## 交叉提醒
《天龙八部》里同一人物的称谓分裂还有：
- 萧峰 / 乔峰（同一人，身份揭露前后异称）
- 段延庆 / 恶贯满盈 / 青袍客
- 叶二娘 / 无恶不作
- 虚竹 / 梦郎
检索时必须成组使用，否则「某关键词 0 命中」会被误判为「原文无此事」。

## S10 · 明教—阳顶天—成昆线（调度者预核，供倚天批次使用）

## 关键词分布（实测）
- `阳顶天` 倚天 **33** 次，首现行 **7136**
- `成昆` 倚天 **131** 次
- `黛绮丝` 倚天 **40** 次
- `谢逊` 倚天 **816** 次

## 已核实的三层事实（带行号）

**1. 教主传承断裂的制度性原因（倚天 7140，灭绝师太口述）**
   「魔教历代教主，都以'圣火令'作为传代的信物，可是到了第三十一代教主手中，
    天夺其魄，圣火令不知如何地竟会失落，第三十二代、第三十三代两代教主有权无令，
    这教主便做得颇为勉强。」
   → 圣火令在**第三十一代**失落，此后两代「有权无令」。
     这是理解阳顶天（第三十三代）权威不足、教内不服的**制度前提**，
     不能只写「阳顶天死后教内大乱」而不写这一层。

**2. 阳顶天之死与继承真空（倚天 7136、7140）**
   7136：「魔教自从第三十三代教主阳顶天死后，便没了教主。左右光明使者，四大护教法王，
          五散人，以及金、木、水、火、土五旗掌旗使，谁都觊觎这教主之位，自相争夺残杀，魔教便此中衰。」
   7140：「阳顶天突然死去，实不知是中毒还是受人暗算，不及指定继承之人。」
   → 注意：**灭绝师太的版本说「不知是中毒还是受人暗算」**，
     这是「江湖传闻层」，与后文成昆自述的真实死因（走火入魔）不同。
     两者必须分层记录，不可混为一条。

**3. 张无忌对魔教的认知是零散听来的（倚天 7138）**
   「张无忌自幼便听到魔教之名……问到义父时，他不是呆呆出神，便是突然暴怒」
   → 说明谢逊的旧事在主线前期是**被压抑的空白**，这正是需要从原文另找揭密段的理由。

## 提取提示
- 必须区分三层叙述：**灭绝师太的传闻版** / **成昆的自述版** / **阳顶天遗书的自陈版**。
  三者对同一事件的说法不同，是不可合并的证据层级。
- 成昆与师妹、师妹嫁阳顶天、二人秘道幽会、阳顶天走火暴毙——须按原文逐段核实，
  并注意这一段在成昆自述中是**他为自己罪行辩护的叙述**，不是客观叙述。
- 黛绮丝（金花婆婆）、韩千叶、小昭身世线独立成链。

## S11 · 更正：S1/S6/S7 的「六部 0 命中」表述有误（由 A1 指出并复核）

**错误表述**：我在 S1 写「`沧海` 在六部合计命中 0 次」。
**实际情况（复核确认）**：

| 书 | `沧海` 命中 | 实际所指 |
|---|---|---|
| 天龙八部 | **0** | — |
| 笑傲江湖 | **278** | 几乎全部是青城派掌门 **余沧海** |
| 射雕英雄传 | 1 | 行 14747 丘处机诗「……沧海近」（《长春真人西游记》引诗） |
| 倚天屠龙记 | 1 | 行 838 成语「沧海一栗」 |

**正确表述**：`李沧海`／`沧海` 作为**人名**在六部中不存在；
`沧海` 作为**字串**只在《天龙八部》为 0 次，其余五部是「余沧海」等无关命中。

这条错误本身有教学价值：**字串命中 ≠ 人物命中**。
若后续 agent 拿笑傲的 278 次「沧海」去串《天龙》的逍遥派线，会造出完全不存在的跨书关联。
因此：
- 「李秋水之妹」在六部原文中**确实无名**（这一点不变）。
- 但推理依据必须写成「《天龙八部》全文无『沧海』，故原文未给此名」，
  不能写成「六部 0 命中」。

## 顺带修正的同类风险
- `冯衡`：仍需按六部逐一验证，不能只据一部下结论。
- 任何「0 命中 ⇒ 原文无此人」的推论，都必须**先确认该字串不是常用词/他人名的一部分**。

### 必须注意的三点
1. **「葵花宝典」→「辟邪剑谱」的转化点在 10–13 环**：渡元所记得的只是**打了折扣的二手经文**
   （「岳蔡二人所记的，本已不多，经过这么一转述，不免又打了折扣」），
   他以此自创的七十二路辟邪剑法，与原本《葵花宝典》**不是同一部书**。
   任何把两者等同的写法都是错的。
2. **华山剑气之争的起因是「分读一半对不上」，不是单纯的武学理念之争。**
   这一点是用户点名的重点，原文给得极明确（12971）。
3. 这一段全部是**方证的口述**（含「据说」），属人物自述/传闻层；
   凡「据说」处不可写成客观叙述。

## S20 · 风清扬为何错过华山剑气之争（调度者逐行核验，笑傲 13001）

### 原文（冲虚对令狐冲讲述）
> 「当年武林中传说，华山两宗火并之时，风老前辈刚好在江南娶亲，得讯之后赶回华山，
> 剑宗好手已然伤亡殆尽，一败涂地。否则以他剑法之精，倘若参与斗剑，气宗无论如何不能占到上风。
> 风老前辈随即发觉，江南娶亲云云，原来是一场大骗局，
> 他那岳丈暗中受了华山气宗之托，买了个妓女来冒充小姐，将他羁绊在江南。
> 风老前辈重回江南岳家，他的假岳丈全家早已逃得不知去向。
> 江湖上都说，风老前辈恼怒羞愧，就此自刎而死。」

### 关键判断
1. **这不是「恰好错过」，而是气宗精心设计的骗局**：
   岳丈受气宗之托 → 买妓女冒充小姐 → 把风清扬羁绊在江南 → 剑气火并时他赶不回来。
   若概括成「风清扬因事外出未能参战」，就把整个阴谋抹掉了。
2. **江湖传言他自刎而死**（「江湖上都说」）——但他实际隐居华山后洞。
   所以这一句是**传闻层，且被事实否定**。卡片必须标「传闻」并注明实际不符。
3. 「二十五年前，剑宗一败涂地」为岳不群所述（行 4534），可与本条对勘定时间。

### 连带需要单独建卡的节点
- 气宗买通风清扬岳丈设局（阴谋本身，1329前的过去事件）
- 华山剑气火并（二十五年前）
- 剑宗伤亡殆尽、退出华山、岳不群执掌门户（4534）
- 封不平、成不忧等剑宗弃徒归来夺位（当下事件，非旧事）
- 风清扬隐居思过崖后洞、立誓不再与人动手（3867）

### 提取提示
- 行 3867 风清扬亲口：「我当年……曾立下重誓，有生之年，决不再与人当真动手」
  ——这是理解他隐居不出的**主观原因**，与行 13001 的**外部阴谋**是两层，都要保留。
- 风清扬属「剑宗」（11774 令狐冲确认、8769 任我行言），这决定了他对气宗的态度。

## S22 · 更正与补充：欧阳锋—欧阳克父子关系的真正直证在《射雕》第二十一回

### 事实
《射雕英雄传》**第 7832 行**（第二十一回「千头万绪」，行 7516–7936）原文：

这个说法**不准确**：

## S26 · 任我行传《葵花宝典》给东方不败的真实用意（笑傲 9387–9393）

### 原文
> 任我行：「那东方不败却来大献殷勤，劝我不可烦恼。这一来，我更加中了他的奸计，
> 竟将本教的秘籍《葵花宝典》传了给他。」（9387）

> 任我行：「多年以来，《葵花宝典》一直是日月神教的镇教之宝，
> **历来均是上代教主传给下一代教主**。其时我修习吸星大法废寝忘食，甚么事都不放在心上，
> 便想将教主之位传给东方不败。**将《葵花宝典》传给他，原是向他表示得十分明白，
> 不久之后，我便会以教主之位相授。**」（9393）

### 这条为什么重要（纠正常见误解）
1. **不是「设局除掉东方不败」**。原文明确：传宝典是**「表示得十分明白」要传位**，
   是栽培/示意，不是陷阱。任我行自己说「我更加中了他的奸计」——他是被骗的一方。
2. 任我行当时**沉迷修习吸星大法**，「什么事都不放在心上」，这是夺位得以成功的条件。
3. 《葵花宝典》在日月神教的制度地位：**镇教之宝，上代教主传下一代教主**（9393）。
   这与 S14 的少林源流是两个不同的流传系统。

### 已核事实表
| 项 | 内容 | 出处 |
|---|---|---|
| 宝典在日月神教的地位 | 镇教之宝，历来上代教主传下代 | 9393 |
| 任我行传书动机 | 表示将传教主之位 | 9393 |
| 东方不败的手段 | 「大献殷勤，劝我不可烦恼」，使任我行「中了他的奸计」 | 9387 |
| 任我行当时状态 | 修习吸星大法废寝忘食 | 9393 |
| 任我行的内因 | 吸星大法一经修习「便再也无法罢手」（9479） | 9479 |

### 提取提示
- 必须拆成：任我行沉迷吸星大法 → 东方不败献殷勤 → 任我行传《葵花宝典》示意传位 →
  东方不败自宫练功 → 十二年之前任我行失踪 → 东方不败篡位（S25）。
- 「自宫练功」这一环需回原文核实是否明写、在何处写。
- **禁止**把这条写成「任我行用宝典设局害东方不败」——原文说的是相反方向。

## S27 · 李莫愁—陆展元关系的原文全部信息量（只有两句）

### 原文（神雕 184，武三娘对陆立鼎夫妇）
> 「令兄陆大爷十余年前曾去大理。那魔头赤练仙子李莫愁现下武林中人闻名丧胆，
> 可是十多年前却是个美貌温柔的好女子，那时也并未出家。也是前生的冤孽，
> 她与令兄相见之后，**就种下了情苗**。后来**经过许多纠葛变故**，令兄与令嫂何沅君成了亲。」

### 结论：必须承认的原文空白
原文对「李莫愁与陆展元如何相识、如何定情、如何破裂」的全部交代，
就是**「种下了情苗」+「许多纠葛变故」**两句概括。

因此：
- ✅ 可写：十余年前陆展元赴大理；当时李莫愁是「美貌温柔的好女子」且未出家；
