# 摘录逐字校验（调度层执行，可复现）

## 为什么做
事件卡的可信度来自「摘录是原文逐字」。二手摘录会让整份资料无法人工复核，
也会在后续生成世界书时把改写当事实写进去。

## 校验器
`verify_excerpts.py`，用法：
```
python verify_excerpts.py <md文件> 原文UTF8/<小说>.txt [其它小说.txt ...]
```
做法：
1. 从每张卡的 `- 原文摘录:` 行抽出全部成对中文引号内文本；
2. 按「……」分段，每段 ≥8 字；
3. 逐段在 UTF-8 语料中做**子串匹配**；
4. 合法写法：单段连续原文，或 `①"…"（行号）②"…"（行号）` 多段分引；
5. 内层嵌套引号 ‘ ’ 规范化后比对。

## 教训（已写入子任务规格）
- 把「摘录必须能在原文子串匹配」作为交付门槛，而不是交付后再抽查。
- 叙述者旁白与人物引语必须区分，不能为凑引号而改写视角。
