# 金庸六部原文 · 过去事件提取 · 方法约定

## 0. 本目录是什么

本目录是「从六部小说完整原文系统提取过去事件」的工作区与交付区。
现存的两类素材**只用于差分，不作为提取依据**：

- 世界书条目：`世界书/金庸群侠传1/世界书/*.yaml`（1151 条）
- 预加入事件：`信息/武侠卡的预加入内容/预加入事件/**/*.json`（1278 条）
- 合计 2354 条，已抽取为 `现有条目索引.json`。

## 1. 语料与坐标

原始 txt 为 GB18030 编码，`read` 工具直读会报 invalid UTF-8。
本目录已生成 UTF-8 副本，**所有行号以 UTF-8 副本为准**：

- `原文UTF8/天龙八部.txt`（22333 行，50 章）
- `原文UTF8/射雕英雄传.txt`（40 章）
- `原文UTF8/神雕侠侣.txt`（40 章）
- `原文UTF8/倚天屠龙记.txt`（40 章）
- `原文UTF8/笑傲江湖.txt`（40 章）
- `原文UTF8/鹿鼎记.txt`（50 章）
- 合计 260 章、635.8 万字。

`章节索引.tsv` 字段：`book|seq|chapter|title|startLine|endLine|chars`，
用于把任意行号换算成「第几回 什么标题」。

## 2. 什么算「过去事件」

判定顺序：

1. 该事件在原文的**叙事时间**上早于当前主线（不是「现在正在打」）。
2. 它被以下方式带出：他人回忆、人物自述、秘密揭露、身世说明、门派传说、书册遗刻、旁人议论。
3. 它有可独立识别的行为主体、时间或时序、因果。

**必须区分两个东西**（用户明确要求）：

- 「某人现在讲述/揭密」= **现在**发生的事件；
- 「当年真正发生的事」= **过去事件**。
  两者可各建一条，但不得混为同一条。

## 3. 事件卡格式（唯一交付格式）

每张卡必须逐字来自原文，禁止用现有条目的压缩表述回填。字段如下：

```
### EV-<书简称>-<四位序号> · <事件名>
- 原文位置: 《书名》<回次> <回目>｜行 <起>-<止>（命中行 <行号>）
- 原文摘录: “<逐字摘录，≤120 字，允许用……省略中间>”
- 发生时间: 原文表述（如“三十年前”“我年轻时”）｜推定年: <年或未知>（高/中/低置信；依据）
- 地点: 原文地点表述 → 三级路径（可推定才写，否则写“原文未明”）
- 涉及人物: A、B、C
- 关系变化: A→B 由 X 变为 Y（无则写“无”）
- 事件经过: 2–6 句，只写原文支持的内容
- 前因: 指向其它事件 ID，或写原文陈述
- 后果: 指向其它事件 ID，或写原文陈述
- 线索性质: 客观叙述 / 人物自述 / 传闻 / 揭密 / 推断
- 跨书引用: 无 / 《某书》某回（写明关联点）
- 与现有条目差分: 完全缺失 / 只有回忆或揭密场景 / 只有最终结果缺前因与中间过程 / 部分已有（列出条目名）/ 已完整记录 / 证据不足暂不能确定
- 待核: 无 / <具体待核点>
```

硬约束：

- **不编造**年份、地点、动机、亲缘、顺序。原文没有就写「原文未明」或「待核」。
- 摘录必须是原文逐字，用于人工复核；不得改写。
- 行号必须真实可查。
- 一个复杂过程要拆成多个有因果的事件节点（如：拜师 → 盗经 → 叛逃 → 修炼 → 同门破裂 → 死亡 → 复仇），**不许压缩成一句话**。
- 同一事件跨书出现，用同一张卡并在「跨书引用」里挂另一本书；不得各建一套互相矛盾的卡。

## 4. 差分口径

对每个历史节点，以**事件正文**（不是标题）判断：

| 状态 | 含义 |
|---|---|
| 完全缺失 | 2354 条里没有任何条目记载该过去事件 |
| 只有回忆/揭密场景 | 只记了「某人讲述这件事」的当下场景，没记当年发生的事 |
| 只有最终结果 | 记了结果（如某人死了），没记前因与中间过程 |
| 部分已有 | 已有关键节点但缺中间节点，需列出已有条目名 |
| 已完整记录 | 不需要重复创建 |
| 证据不足 | 原文依据不够，暂不能确定 |

判定时必须读现有条目正文：用 `现有条目索引.json` 检索 `key / cast / summary / detailHead`，
命中后再打开对应 yaml/json 读全文。

## 5. 已知陷阱

1. 现有条目平均每条只写百余字摘要，且集中在主线当下，**最容易丢掉「距离主线较远的回忆」**。
2. 用人物名检索会漏，必须同时检索称谓、别号、门派、事件词。已实测的两个例子：
   - 「康敏」在《天龙八部》原文只出现 1 次，通篇称「马夫人」。
   - 「冯衡」在六部原文**命中 0 次**；黄药师之妻通称「黄夫人」「冯氏」
     （墓碑「桃花岛女主冯氏埋香之冢」，射雕行 6229）。
   推论：任何「某关键词 0 命中」都不能直接判定该人物不存在于原文。
3. 章节标题扫描 ≠ 已读全文。任何「已核对」声明都必须能给出具体行号。
