# 阅读指引（给使用者）

本目录是「从六部小说完整原文系统提取过去事件」的工作与交付区。
按下面顺序读，能最快接上进度。

## 一、先读这四份

| 文件 | 作用 |
|---|---|
| `00-方法与本轮范围.md` | 什么算「过去事件」、事件卡字段、差分口径、已知陷阱 |
| `03-现有条目基线缺陷清单.md` | 现有 2354 条条目里**被原文证伪**的具体错误（含行号） |
| `04-事件总表.md` | 各批次完成度 + 我亲核的 21 条历史链索引 |
| `06-未完成与限制说明.md` | 哪些**还没做**，别把它当成已完成 |

## 二、事件卡在哪

`批次A/`～`批次G/`，每份文件都是同一套格式：

```
### EV-<书>-<序号> · 事件名
- 原文位置 / 原文摘录 / 发生时间 / 地点 / 涉及人物 / 关系变化
- 事件经过 / 前因 / 后果 / 线索性质 / 跨书引用 / 与现有条目差分 / 待核
```

书简称：天龙 / 射雕 / 神雕 / 倚天 / 笑傲 / 鹿鼎。序号按书独立，段位预先分配给各批次避免冲突。

## 三、如何自己复核

1. **原文行号**：`原文UTF8/<书名>.txt` 是权威副本（GB18030 原文件已转码）。
   用 `章节索引.tsv` 把行号换算成「第几回 什么标题」。
2. **摘录是否逐字**：
   ```
   python verify_excerpts.py <某个md> 原文UTF8/<对应小说>.txt
   ```
   要求 PASS = 总卡数。**严格口径，不做归一化**。
3. **差分是否属实**：`查询现有条目.ps1` 可按关键词检索 2354 条现有条目并回读原文正文。

## 四、我（调度层）亲核的证据

`S-调度者亲核证据.md` + `S-调度者亲核证据-补充.md`，共 S1–S21 条，
每条都带我逐行读过并记录的行号。**这些不是转述，是可以直接引用的原文事实。**

其中三条纠错尤其重要：
- **S1/S11**：「李沧海」不是原文用语；且我最初写「六部 0 命中」是错的
  （笑傲 278 次「沧海」全是余沧海），已更正。
- **S6/S12**：「冯衡」六部 0 次；原文用「黄夫人/冯氏/阿衡」；
  且「冯氏」在《鹿鼎记》另有 6 处指别人。
- **S8/S18**：现有条目把「苏星河战死」「成昆暗算阳顶天」当事实写，
  原文分别是「被毒害」与「成昆否认、阳顶天自己死的」。

## 五、这批资料能做什么

- 按「前因/后果」字段直接串成长期事件链（每个节点都有原文行号可回溯）。
- 按「与现有条目差分」字段决定哪些要新建世界书条目、哪些只需补节点。
- 按「线索性质」字段区分客观叙述与人物自述/传闻，避免把角色偏见写成史实。
