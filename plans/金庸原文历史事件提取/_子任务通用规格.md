# 子任务通用规格（所有提取代理必读）

## 语料
- `原文UTF8/<书名>.txt` 是 UTF-8 副本，**行号唯一权威**。原始 `信息/武侠卡的预加入内容/小说原文/*.txt` 是 GB18030，不要直接 read。
- `章节索引.tsv` 每行：`book|seq|chapter|title|startLine|endLine|chars`。用它把行号换算成回次。
- 读取手段：`grep` 定位人名/关键词 → `read`（带 offset/limit，一次 150–400 行）精读该段。
- 禁止只用 grep 命中行就下结论：必须 read 命中行前后至少 60 行，读懂上下文。

## 差分基线（只用于差分，不作为提取依据）

- 命中后再打开原始文件读全文：
  - 世界书：`世界书/金庸群侠传1/世界书/<key>.yaml`
  - 预加入事件：`信息/武侠卡的预加入内容/预加入事件/<书>/<key>.json`
- 判断依据是**事件正文**，不是标题。

- 后果: <事件ID 或 原文陈述>

## 硬规则
1. **不编造**：年份、地点、动机、亲缘、顺序，原文没有就写「原文未明」或列入待核。
2. 摘录必须逐字原文，行号必须真实。
   交付前必须跑 `python verify_excerpts.py <你的md> 原文UTF8/<小说>.txt`，
   要求 PASS = 总卡数、FAIL 0，并把结果行贴进回报。
   叙述者旁白不得加人物引号冒充人物引语。
3. 拆细不压缩：一个历史过程拆成多个有因果的原子事件节点。
   反例：「梅超风被师父赶走，后与郭靖为敌」→ 错。
   正例：拜师 → 与陈玄风相恋 → 盗《九阴真经》下卷 → 逃离桃花岛 → 陈玄风被郭靖所杀 → 梅超风失明 → ……
4. 严格区分「现在讲述/揭密」与「当年发生的事」。两者可各建一条卡，不得混。
5. 用户点名的人物只是样例，**不得把范围缩窄到他们**。任务书给你的章节范围里，所有值得记录的过去事件都要提取。
6. 人物称谓多样：必须同时检索名、号、绰号、门派称谓（例：《天龙》里康敏几乎只称「马夫人」）。
7. 不要修改世界书、预加入事件、src 下任何文件。只写本任务目录内的输出文件。

## 可用的现成工具（本目录已备好）

- `章节索引.tsv` —— 行号→回次换算
- `覆盖表-<书名>.md` —— 该书的章节覆盖表骨架，逐章填「已读/未读 + 条数」
- `旧事线索扫描.json` —— 6985 条含回忆/身世/秘密/传闻标记的原文行（字段 book/line/chapter/seq/title/markers/text），
  用来快速定位「某人讲述旧事」的段落，**但不能替代通读**。
- `查询现有条目.ps1` —— 差分查询，例：
  `pwsh -NoProfile -Command "& './查询现有条目.ps1' -Keyword @('童姥','李秋水') -Full"`
  不加 `-Full` 只看摘要，加 `-Full` 会打开原始 yaml/json 打印事件详情。
  注意：必须用上面这种 `[Console]::OutputEncoding` 或 `pwsh -Command` 形式，否则中文参数会乱码。

## 硬规则补充（S28 教训，所有批次必守）
1. **禁止全量断言**：「全书唯一」「原文从未交代」「向来无人」等，
   除非已做全书检索并给出检索式与命中数。
2. 一切「未交代 / 未见」必须限定范围：「在行 X–Y 范围内未见」，
   不得写成「原文未点明」。
3. 人物等同若原文未直说（如「曲三=曲灵风」），只能写「证据链指向」，不得写成事实。
4. **校验器全绿不等于没问题**（S38）：
   - 内层引号会截断 `“([^”]+)”` 类正则，造成假通过；应取「首个上引号→末个下引号」整段再按 …… 分段。
   - 「命中行」必须是摘录**首段**真正所在的行，旁证写「并参」且不得排在前面。
   - 禁止用宽区间（如 4810-4946，136 行跨多个不相邻证据点）蒙混；各处证据写各自窗口。
