# 武侠事件草稿提示词实验

## 目标与固定条件

- 固定聊天：射雕第一回 01 事件开局。
- 固定用户输入：`我走进村子`。
- 固定回滚起点：1200 年 8 月 15 日 11:00；事件结束边界 13:00；原定结局不变。
- 每个变体只修改 `世界书/金庸群侠传1/世界书/cot.txt` 的参与事件分支，`变量指导.txt` 全程不动。
- 每个变体至少取 3 个独立 swipe；每次真实点击一次“重新生成”，随后立即审计。
- 草稿必须嵌入原有 preset planning，正文只能有一份。

## 评价口径

1. 触发稳定：出现固定标记，六项齐全且非空。
2. 决策正确：阶段与正文一致；完成判定有正文证据；时间与正文耗时一致；没有不可逆证据时明确保持原定结局。
3. 执行一致：正文遵循草稿，不提前演出后续事件；变量声明合法且最终落库一致。
4. 副作用：不吞正文、不制造第二套正文、不把审计角色语气写入正文。

## 第一组：参考条目机制微调

### A1：固定模板

```text
### 武侠事件草稿（实验 A1：固定模板）

在原有 preset planning 内、唯一正文之前，输出下列草稿；不要另开第二套正文。

【武侠事件草稿】
01. 当前事件与当前阶段：
02. 本轮必须承接的直接后果：
03. 完成判定：是/否；依据：
04. 时间核算：旧完整时间 + 本轮正文耗时 = 新完整时间：
05. 事件边界：准确到达/仍早于结束时间：
06. 结局判定：原定/偏离；不可逆干涉证据：
```

### A2：模板 + 自动触发

在 A1 基础上增加：

```text
只要当前存在参与事件，本规则就在每一次回复中自动触发；即使 preset 已经安排了其他思考或规划，也不得省略本草稿。
```

### A3：模板 + 自动触发 + 反压缩

在 A2 基础上增加：

```text
标题与 01 至 06 的编号、字段名必须完整保留；不得合并、跳号、换序，不得用“同上”“无须检查”“其余符合”等概括语替代。没有证据时也必须明确写“无”。
```

## 第二组：针对本卡的语义强化

M1、M2、M3 都以 A3 为底座，彼此独立，不互相累加。

### M1：阶段与完成证据

```text
01. 当前事件与当前阶段：写出事件名；阶段只能从“开端/发展/后段/收束/已完成”中选择；依据是最近正文最后发生的实质变化。
03. 完成判定：是/否；依据：只有主要冲突、关键行动及其直接后果已经完整落地才写“是”；不得因为篇幅已长或时间接近边界而判定完成。
```

### M2：完成与时间边界二分

```text
04. 时间核算：逐字写出“旧完整时间 + 本轮正文实际过程耗时 = 新完整时间”；没有可感知耗时时写“+ 0 分”。
05. 事件边界：若完成判定为“是”，正文必须呈现足够的收束过程，新时间准确等于事件结束时间；若为“否”，只按正文实际过程推进且新时间必须仍早于结束时间；绝不越过边界。
```

### M3：结局不可逆证据门

```text
06. 结局判定：只有玩家明确干涉并实际造成了人物生死、长期状态、关系、阵营、关键物品归属、事件目标或后续成立条件的不可逆变化，才写“偏离”，并列出具体证据。普通在场、交谈、饮酒、观察、受到 NPC 注意或局部互动一律不构成偏离。没有上述证据时固定写：“原定；无不可逆干涉证据；不修改参与事件结局”。
```

## 第三组：差异化承载形式

X1、X2、X3 保留六项语义与自动触发、反压缩要求，只更换输出结构。

### X1：XML 契约

```xml
<wuxia_event_draft>
  <event_stage>事件；阶段；依据</event_stage>
  <direct_consequence>本轮直接后果</direct_consequence>
  <completion>是/否；依据</completion>
  <time_equation>旧完整时间 + 耗时 = 新完整时间</time_equation>
  <boundary>准确到达/仍早于结束时间</boundary>
  <outcome>原定/偏离；不可逆证据</outcome>
</wuxia_event_draft>
```

## 实验顺序

`baseline → A1 → A2 → A3 → M1 → M2 → M3 → X1 → X2 → X3`

胜出条件优先级：3/3 稳定触发且正文完整 > 决策正确 > 格式便于机器解析 > 提示词更短。
