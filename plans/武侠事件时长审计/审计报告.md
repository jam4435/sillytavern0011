# 武侠事件条目时长审计

## 结论

本次递归审计 `世界书` 下文件名含“事件条目”的 630 个事件：

| 指标                               | 数量 |
| ---------------------------------- | ---: |
| 成功解析                           |  630 |
| 解析失败                           |    0 |
| 原始标注时长不超过 2 小时          |  567 |
| 三个并行分片初判：明确过短         |  118 |
| 三个并行分片初判：较可能过短       |    4 |
| 初次事件边界复核暂存待查           |   16 |
| 补充边界复核后：单条时长明确过短   |  104 |
| 补充边界复核后：单条时长较可能过短 |    4 |

因此，“事件详情所需叙事时间明显长于事件时间窗”的保守问题数修订为
**104 条**；若把没有精确时间词、但存在明显长途移动的 4 条也计入，单条时长候选总数是 **108 条**。

按作品划分：

| 作品 | 保守确认 | 较可能 |
| ---- | -------: | -----: |
| 射雕 |       26 |      2 |
| 神雕 |       78 |      2 |

保守结果中，标注时长不超过 2 小时的有 95 条确认项和 4 条较可能项，共 99 条。其余 9 条虽然原时间窗超过 2 小时，仍短于详情明确写出的数日、数月或半年。

## 用户报告条目

`射雕第7回-03-黑松林解围` 是明确问题：

- 标注时间窗：1219-10-20 16:00 至 18:00，共 2 小时。
- 详情先写侯通海在客店约郭靖“次日”赴黑松林，随后才写赴约和黄蓉解围。
- 这不是回忆或背景介绍，而是同一条详情内的连续因果过程，必然跨到翌日。

## 判定口径

并行子任务只拿到提取后的 `触发条件`、`事件结束时间`、`事件详情`，各自复核 210 条。初判完成后又按更严格的事件边界复核：

- 保留：本条当前动作明确跨夜、跨日、持续数月，或单个动作已超过标注时长。
- 暂存待查：条目开头单独用于承接上一条的“次日/次晨”，转入相邻事件间隔审计。
- 暂存待查：`已经`、`连日来`、`传了大半年` 等既往状态，核对其应由当前事件、上一事件、并行叙事还是事件间留白承载。
- 单条时长初判暂不计入：仅计划“明日”行动、但本条并未实际叙述到明日；这类条目随后纳入“未来计划向后审计”，沿后续剧情核对是否按计划推进。
- 降为“较可能”：没有精确时间词，但“朝行晚宿”等远距离移动不可能在一两小时内完成。

这个口径刻意偏保守；104 是单条事件窗口的明确矛盾项，不是所有可能需要重新编排时间线的条目总数。

## 跨事件间隔补充审计

补充审计计算了同一作品内 628 组相邻事件从“上一事件结束”到“当前事件触发”的留白：

| 相邻留白               | 数量 | 占 628 组 |
| ---------------------- | ---: | --------: |
| 不超过 2 小时          |  369 |     58.8% |
| 不超过 6 小时（累计）  |  393 |     62.6% |
| 不超过 24 小时（累计） |  476 |     75.8% |
| 不超过 3 日（累计）    |  534 |     85.0% |

神雕的聚集更明显：373 组相邻事件中有 251 组只隔 2 小时以内，占 67.3%；射雕为 118/255，占 46.3%。间隔短本身不必然是错误，但它使“次晨、数日、半年、长途转场”等叙事锚点频繁失真。

从 630 条中筛出 109 个显式时间锚点，并对初次暂存的 16 条另做边界专项复核后，得到：

| 跨事件问题类型           | 明确 | 较可能 |
| ------------------------ | ---: | -----: |
| 直接相邻留白不足         |   10 |      2 |
| 修复前一长事件后必须顺延 |    4 |      — |

4 条依赖顺延中有 1 条同时属于直接留白不足，因此两类明确问题合计涉及 13 个不同事件。

典型直接冲突：

- `射雕第36回-04-郭靖重返蒙古`：文本写寻找黄蓉半年，实际只留约 70.5 日。
- `射雕第37回-05-西毒脱困`：上一条刚把欧阳锋困住，本条写被困数日后脱困，实际只隔 1 小时。
- `神雕第2回-14-柯镇恶中毒返店`：文本明确次日一早，字段仍在同夜且只隔 1 小时。
- `神雕第22回-02-杨过醒转`：文本写服药后将养半日，上一事件结束到醒转只隔 1 小时。

典型依赖顺延：

- `神雕第4回-11-全真小较` 必须排在前条“数月只授口诀”的长期过程之后。
- `神雕第9回-07-龙驹寨夜遇刺客` 必须随前条“次晨起程、随后两日行旅”整体后移。

在加入未来计划向后审计前，把单条时长、直接跨事件冲突和依赖顺延去重后，有 **115 个明确需要调整的事件文件**；另有
**5 个仅较可能、尚需结合连续章节确认的事件文件**。

## 未来计划向后审计

脚本另从 630 条中筛出 101 个“明日、次日、三日后、半年后”等向后时间锚点，并同时提取当前事件结束时间、下一事件、显式
`后续事件` 指向及对应间隔。

原始分类中有 6 条明确冲突、2 条较可能冲突；沿后续最多五条查找真正的计划兑现事件后，只有 2 条保留为明确冲突：

- `神雕第11回-09-郭靖重逢杨过`：黄蓉说明日为英雄大宴正日，真正开宴到 `第12回-05`，时间字段已晚了三日。
- `神雕第22回-04-黄蓉得知杨过中毒真相`：战书约定明日回拜，真正的金轮来袭在 `第22回-06`，字段仍只推进了同日四小时。

其他候选中：

| 分类                     | 数量 |
| ------------------------ | ---: |
| 后续时间满足计划         |    9 |
| 时间词已在本条内部兑现   |   59 |
| 计划被剧情取消或改变     |    5 |
| 回忆、条件句或泛指未来   |   20 |
| 初判冲突但沿链复核后排除 |    6 |

两个明确向后冲突中，`神雕第11回-09` 已在单条时长问题中出现，`神雕第22回-04`
是新增事件。把向前承接、单条持续时间、向后计划和依赖顺延全部去重后，最终结果为：

- **116 个明确需要调整的事件文件**
- **5 个仅较可能的事件文件**

## 存档兼容性提示

老存档中"已触发 / 已过期"事件状态基于旧时间线。修复后同一存档继续游玩，可能出现：已触发过的事件因时间后移而再次可触发、或未触发事件被跳过。**建议新开档**；旧档继续玩则波及面集中在当前进度附近被顺延的区段（详见 `applied-changes.json`）。
