# 武侠卡内思维链受控对照实验（2026-08-11）

## 实验条件

- 固定用户输入：`我走进村子`
- 固定参与事件：`射雕第一回01-郭杨邀饮说书人`
- 事件窗口：1200/8/15 11:00～13:00
- 每个变体整体替换完整 `cot`，推送后重载测试页；第一份计数样本的 `main-input` 必须出现版本独有标记。
- 每个变体取得 3 个可审计的独立 regenerate swipe，不新增 user 楼层。
- 计分对象为原始 `main-output`；同时检查可见正文、变量时间和事件结局状态。

## 变体定义

### A1：流程替代人格（前组单变量）

保持基线的自动触发、`<logic_check>`、连续 01～08、禁止跳项和八条事件规则，仅把“三重人格”改为“三段核验流程”，用于检验人格包装是否必要。

### B1：武侠事件证据链（中组卡片专用）

保留参考提示词的完整骨架和三重人格，把八项改写为连续性、干涉、阶段、完成条件、场景收束、时间边界、结局证据、后续隔离；每项强制 `判定/本轮证据/必要修正` 三行。

### C1：状态机双审计（后组差异化结构）

取消人格、铁律问答和 01～08，改为 S0～S6 状态机与独立审计闸门；每个状态要求 `EVIDENCE/DECISION`，仍保留单一 `<logic_check>` 作为前端隐藏接口。

## 可归因结论

1. **人格不是稳定触发关键。** A1 去除人格设定后，标签和连续 01～08 仍为 3/3；人格/毒舌裁决更像风格包装，不是触发必要条件。
2. **自动触发条件、固定标签和强制顺序是目前最可信的核心。** 基线与 A1 都稳定保持标签和连续编号；C1 保留自动触发与固定标签后也能 3/3 触发，说明参考提示词的表面人格并非唯一机制。
3. **连续数字编号比语义状态名更稳定。** A1/B1 的 01～08 都为 3/3；C1 的 S0～S6 只有 2/3，另一次把状态名压掉但保留了七组内容。
4. **强制字段能稳定提升详细度。** B1 的 `判定/本轮证据/必要修正` 达到 3/3，明显优于基线与 A1；但复杂格式也带来一次双标签和可见自纠错泄漏。
5. **状态机是可行替代思路，但尚不够稳。** C1 能 3/3 触发并正确处理阶段、时间和 ORIGINAL 结局，证明与参考结构差异很大的方案也能工作；当前短板是状态名遗漏和一次正文污染旁证。
6. **时间与结局逻辑在三种结构下都正确。** 所有严格计数样本均在 11:00～13:00 内推进，未提前触发后续事件，事件结局均保持原定；最终快照为 1200/8/15 11:03，当前事件仍进行中，结局状态原定。

## 下一步保留与淘汰

- 保留：参与事件存在时自动触发、单一固定 `<logic_check>`、连续 01～08、禁止跳号/合并/概括、每项必须给本轮证据、阶段/完成条件/时间边界/结局证据/后续隔离。
- 暂不依赖：人格名称、性格语气、毒舌裁决；它们不是触发必要条件。
- 暂不直接采用：纯 S0～S6 状态机编号；其语义结构可吸收进 01～08，但当前标签名完整性只有 2/3。
- 下一轮建议：以 A1 的稳定外壳为基线，只加入 B1 的单一字段约束——每项必须包含“判定 + 一句本轮证据”，去掉“必要修正”空字段与二次自审措辞，测试能否同时获得 3/3 详细度和 3/3 正常正文。
