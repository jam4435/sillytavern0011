# ==============================================================================
# tavern_sync.mjs 角色卡 / 世界书 / 预设 同步与打包指令指南
# ==============================================================================

tavern_sync.mjs 是项目与酒馆（SillyTavern）进行数据同步的核心工具。
它通过读取根目录下的 `tavern_sync.yaml` 配置文件，管理所有的角色卡、世界书和预设。

你既可以使用 `node tavern_sync.mjs <子命令>`，也可以使用简写 `pnpm sync <子命令>`。

------------------------------------------------------------------------------
二、 单独处理世界书的核心指令
------------------------------------------------------------------------------
1. 本地离线打包（无需连接酒馆）：
   node tavern_sync.mjs bundle 金庸群侠传1
   作用：直接读取 `世界书/金庸群侠传1/` 下的所有条目文件，合并打包生成 `世界书/金庸群侠传1.json`。

2. 单独推送到酒馆：
   node tavern_sync.mjs push 金庸群侠传1 -f
   作用：将本地的世界书配置和条目直接推送到正在运行的酒馆网页中。

3. 从酒馆拉取到本地：
   node tavern_sync.mjs pull 金庸群侠传1 -f
   作用：从酒馆读取最新的世界书，拆分保存为本地的 index.yaml 及条目文件。

4. 单独监听并实时同步：
   node tavern_sync.mjs watch 金庸群侠传1 -f
   作用：常驻运行，只要本地修改了金庸群侠传1的条目文件，就会自动实时推送到酒馆。

5. 本项目专属世界书自动化同步工具（推荐）：
   pnpm sync:worldbook
   作用：自动检查规范化 JSON、分配 6 位数字 UID、排序并重建 4 大分类目录（射雕/神雕/天龙/奇遇），最后自动调用 tavern_sync 打包。

------------------------------------------------------------------------------
三、 单独处理角色卡的核心指令
------------------------------------------------------------------------------
1. 本地离线打包角色卡（生成 PNG 图片）：
   node tavern_sync.mjs bundle CK领主RPG
   node tavern_sync.mjs bundle nba2k
   node tavern_sync.mjs bundle 金庸群侠传
   node tavern_sync.mjs bundle JM帝国
   作用：将本地拆分的 `index.yaml`、`正则/`、`脚本/`、`世界书/` 打包成可直接导入酒馆的 `.png` 角色卡。

2. 单独推送到酒馆：
   node tavern_sync.mjs push CK领主RPG -f
   node tavern_sync.mjs push nba2k -f
   作用：直接把本地的角色卡数据更新到酒馆当前已加载的角色中。

3. 从酒馆拉取角色卡到本地：
   node tavern_sync.mjs pull CK领主RPG -f
   作用：把酒馆中最新的角色卡拆分同步到本地对应文件夹。

4. 单独监听某个角色卡：
   node tavern_sync.mjs watch CK领主RPG -f

5. 本项目专属角色卡构建脚本：
   - CK领主RPG（前端编译 + 角色卡打包）：
     node scripts/build-ck-card.mjs && node tavern_sync.mjs bundle CK领主RPG

------------------------------------------------------------------------------
四、 全局与常用辅助命令
------------------------------------------------------------------------------
1. 查看所有已配置项目：
   node tavern_sync.mjs list

2. 一次性打包全部角色卡/世界书/预设：
   node tavern_sync.mjs bundle all

3. 监听全部项目并自动推送：
   node tavern_sync.mjs watch all -f

4. 检查/更新 tavern_sync 工具版本：
   node tavern_sync.mjs update

------------------------------------------------------------------------------
五、 参数说明与注意事项
------------------------------------------------------------------------------
- `-f` / `--force`：强制覆盖。当本地与酒馆端条目数量/UID 有差异，或者酒馆中尚未创建该配置时必须加 `-f`。
- `-i` / `--inline`：内嵌模式。拉取时不拆分外链文件，尽量保持在单个 YAML 内。
- 连接问题：`push` / `pull` / `watch` 需要酒馆页面连接本机的 6620 端口。如果提示等待连接，请打开酒馆页面并确保酒馆助手脚本库中的同步脚本处于启用状态。
- `bundle` 命令是纯本地文件操作，不需要打开酒馆网页即可瞬间完成打包。
